## P1. Ошибки, меняющие данные и сдаваемый результат

**1. Загрузка получает зачёт с повреждёнными заказами.** Добавление к эталону шага `load` цикла `for row in orders: row["amount"] = 0` принято. Число строк, типы и счётчик пропусков сохранились, выручка этих строк стала нулевой. В `loader` вместо `result.append(row)` можно вернуть только поля `amount` и `date` каждой строки. Проверка проходит, хотя чтение `order_id` в следующем шаге даёт `KeyError`. В `kpi` добавление перед эталоном `clean[:] = clean[:1]` тоже засчитано. Оно выдаёт 1 заказ, 260 ₽ и средний чек 260 ₽. Проверяющий код считает ожидание по уже изменённому учеником списку. В `revenue-col` обнуление первых трёх полей каждой рассчитанной строки также принято. **Приёмка** — сравнить полные записи с независимым чтением исходного CSV, фиксировать исходные данные до пользовательской программы, сохранять поля при добавлении столбца. Проверить путь и содержимое на втором файле с другими строками. [Загрузка в проекте](../../../content/ch01/14-project.md#L86) · [KPI](../../../content/ch01/14-project.md#L209) · [Функция загрузки](../../../content/ch01/13-files.md#L581) · [Вычисляемый столбец](../../../content/ch01/07-tables.md#L433).

**2. Приёмка CSV сравнивает слова, разделённые пробелами.** Запись всего текста `city,revenue Пермь,1450 Казань,600 Тюмень,715` в одну строку принята. `list(csv.DictReader(f))` даёт пустой список, поскольку единственная строка стала заголовком. Проверка отклоняет полноценный CSV с тем же буквальным заголовком `city,revenue` и строками вида `"Пермь",1450`, который можно создать параметром `quoting=csv.QUOTE_NONNUMERIC` только для строк данных. Соседняя задача `count-rows` вычисляет эталон через физические переводы строки. Кавычки вокруг названия напитка с переносом строки дают 41 логическую запись, эталон ожидает 42. Этот случай проверен на временной копии, в поставляемом CSV такого поля нет. **Приёмка** — разобрать вход и выход средствами `csv.reader` с `newline=""`, сравнить заголовок, длину каждой записи, значения и порядок. Включить перенос внутри поля, название с пробелом, экранированную запятую и однострочную подделку. [Запись отчёта](../../../content/ch01/13-files.md#L489) · [Подсчёт строк](../../../content/ch01/13-files.md#L362) · [Python, модуль csv](https://docs.python.org/3.14/library/csv.html).

**3. Принятый файл руководителю оставляет два вопроса открытыми.** В постановке запрошены популярные напитки и день недели с наибольшей выручкой. ### Повторить пересчёт из корня репозитория

```python
from collections import Counter
from datetime import date
from pathlib import Path
import csv

with Path("site/data/orders.csv").open(encoding="utf-8", newline="") as f:
    rows = list(csv.DictReader(f))

bad, good, unique = [], [], {}
for line, row in enumerate(rows, 2):
    try:
        amount = int(row["amount"])
    except ValueError:
        bad.append((line, row["order_id"], row["amount"]))
        continue
    order = {**row, "amount": amount, "date": date.fromisoformat(row["date"])}
    good.append(order)
    unique.setdefault(order["order_id"], order)

cities, drinks, weekdays = Counter(), Counter(), Counter()
for o in unique.values():
    cities[o["city"]] += o["amount"]
    drinks[o["drink"]] += 1
    weekdays[o["date"].weekday()] += o["amount"]

print(len(rows), len(good), len(unique), bad)
print(sum(o["amount"] for o in good), sum(cities.values()))
print(cities, sorted(drinks.items(), key=lambda item: (-item[1], item[0])))
print(sorted(weekdays.items()), sum(cities.values()) / len(unique))
```

## P3. Уточнения теории и границ применимости

- В Python степень группируется справа. `2 ** 3 ** 2 == 512`, тогда как `(2 ** 3) ** 2 == 64`. При целочисленном делении `-7 // 2 == -4`, PostgreSQL для целых даёт −3. Уточнить направления округления, включая отрицательные корректировки и возвраты. [Урок 2](../../../content/ch01/02-numbers.md#L116) · [Python, приоритеты](https://docs.python.org/3.14/reference/expressions.html#operator-precedence) · [PostgreSQL, арифметика](https://www.postgresql.org/docs/18/functions-math.html).
- Для шага 1 длина среза равна разности границ, если `0 <= a <= b <= len(s)`. У `"abc"[1:50]` длина 2, у `"abc"[2:1]` — 0. В `price-parse` две независимые замены пробела и десятичной запятой можно выполнить в любом порядке до `float`. [Урок 3, срезы](../../../content/ch01/03-strings.md#L81) · [Разбор цены](../../../content/ch01/03-strings.md#L454) · [Python, операции с последовательностями](https://docs.python.org/3.14/library/stdtypes.html#common-sequence-operations).
- Значение условия `if` проверяется на истинность, результат выражения может иметь тип `str`, `list` и другие. Например, `if "Пермь":` допустимо. В итоговом вопросе про `if revenue = plan:` выбранный ответ верен, исправить пояснение и сослаться на `if name:` из главы. [Тест](../../../content/ch01/test.md#L73) · [Python, проверка истинности](https://docs.python.org/3.14/library/stdtypes.html#truth-value-testing).
- Ключ словаря должен быть хешируемым. Кортеж из строк пригоден, кортеж с вложенным списком — нет. `count_by` обещает обработать «любой список», но `count_by([["Раф"]])` даёт `TypeError`. Простой счёт уникальных в Python включает `None`: `len(set(["Пермь", None])) == 2`, а SQL `COUNT(DISTINCT city)` при тех же данных даёт 1, так как пропускает NULL. [Составные ключи](../../../content/ch01/10-tuples-sets.md#L97) · [DISTINCT](../../../content/ch01/10-tuples-sets.md#L116) · [count-by](../../../content/ch01/09-functions.md#L662) · [Python, hashable](https://docs.python.org/3.14/glossary.html#term-hashable) · [PostgreSQL, агрегаты](https://www.postgresql.org/docs/18/sql-expressions.html#SYNTAX-AGGREGATES).
- В уроке PEP 8 смешаны рекомендации языка и локальный стиль упражнения. Значение параметра по умолчанию без аннотации (`def rub(x, decimals=0)`) тоже пишется слитно. Аннотированный параметр с умолчанием пишется с пробелами. PEP 8 задаёт 79 символов как базовый максимум, допускает согласованный командой предел до 99, не требует ровно четырёх пробелов во всякой строке продолжения и допускает оба положения переноса относительно бинарного оператора. Упражнение с явно заданными 79 символами можно сохранить. [Урок 9б](../../../content/ch01/09b-style.md#L46) · [PEP 8](https://peps.python.org/pep-0008/).
- Определение `csv.DictReader` как «списка словарей» смешивает ленивый объект и материализованный список. В показанном примере `next(reader)` извлекает одну запись, а `list(reader)` исчерпывает оставшиеся. Предупреждение, что отсутствие `encoding="utf-8"` обязательно портит русские буквы в Windows, тоже слишком категорично. В UTF-8-режиме файл читается успешно, начиная с Python 3.15 режим включён по умолчанию. Его можно переопределить. Оставить явную кодировку как контракт файла. [Урок 13](../../../content/ch01/13-files.md#L206) · [Python, DictReader](https://docs.python.org/3.14/library/csv.html#csv.DictReader) · [PEP 686](https://peps.python.org/pep-0686/).
- В исходном SVG числовой оси необработанный знак `<` в `title`. `xml.etree.ElementTree.parse("content/figures/range-check.svg")` сообщает ошибку XML, строка 2, столбец 41. Это влияет на самостоятельное открытие файла как SVG и XML-инструменты. Отображение схемы при встраивании в HTML требует отдельной проверки. Записать `&lt;` в заголовке.

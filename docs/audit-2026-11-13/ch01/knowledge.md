# Ученик после главы 1

Эту карточку можно передать агенту-ученику при продолжении курса с новой сессии. Основание — собственные ответы и код прохождения 13 ноября 2026 года. В будущей сессии открывай также введение и материалы только заказанной главы.

| Навык | Что уже удавалось сделать по материалам основного маршрута |
|---|---|
| Чтение программ | Проследить выполнение сверху вниз. Связать тип исключения и номер строки с конкретным выражением. Различить вывод функции и возвращаемое значение. |
| Числа и текст | Из переменных вычислить выручку, проценты и средний чек. Пользоваться срезами, f-строками и методами строк. Узнать случай, когда числу нужен явный переход из текста. |
| Строки таблицы и группы | Перенести знакомые из SQL фильтрацию и группировку на списки, циклы, условия и словари. Для среднего правильно выбрать знаменатель. |
| Функции и коллекции | Написать функцию с параметрами, собрать значения по ключу. Применять множества для уникальности, сортировку и ключ сортировки для рейтинга. |
| Работа с выгрузкой | Прочитать CSV, преобразовать суммы и даты, посчитать ошибочные строки, удалить повтор заказа, сверить число записей и записать итог в файл. В задаче на самостоятельную загрузку дат использованы первая подсказка и раздел «Даты» того же урока. |
| Проект | Связать восемь собственных шагов на сентябрьской выгрузке. Отличить число заказов от выручки. Объяснить, почему результаты до и после удаления дубля различаются. |

Углубления со звёздочкой тоже пройдены. Среди применённых приёмов — средние по группам с двумя накопителями и трёхдневное окно из сдвинутых списков. Перевод строки в текстовом файле был знаком до курса. В следующей главе отмечай, когда для базового задания потребовался именно дополнительный приём.

Опыт относится к одной учебной выгрузке и агентному прохождению. В начале следующей практики проверяй перенос навыка на новых входных данных. Текущая граница курса для этой роли — завершённая первая глава.

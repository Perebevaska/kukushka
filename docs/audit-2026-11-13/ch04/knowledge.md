# Карточка ученика после глав 1–4

Начинал с SQL и Excel, фрагментарного Python и без опыта в DS. Первые три главы дали Python для небольших задач, pandas и SQL для аналитики, очистку со сверкой строк, повторяемые блокноты и привычку проверять знаменатель до интерпретации.

| После четвёртой главы могу | На чём проверил |
|---|---|
| Выбирать график по вопросу и подписывать его | Нарисовал линии выручки, рейтинги и метки, гистограммы с общими корзинами, ящики, scatter, hexbin и тепловые карты. В блокноте по доставкам семь графиков, каждый с осями и выводом. |
| Различать типичный уровень, обещание и разброс | Посчитал медиану, P80, P90, IQR и стандартное отклонение с разными делителями. Из P80 получил кандидат на срок обещания для сопоставимых маршрутов. |
| Сравнивать даты и возвращаемость | Исключил неполные недели там, где сравниваются недельные итоги. Сверил месяцы жизни и удержание в SQL и pandas. Рассчитал DAU, WAU, MAU и долю активных дней. |
| Проверять вывод из среза | Добавил численность, сравнил внутри типов курьеров; у дальних маршрутов обнаружил изменение направления связи для велокурьеров. Различаю календарное совпадение, наблюдаемую ассоциацию и эффект изменения правила. |
| Проверять метрику разными способами | Построил воронку предзаказа по уникальным сессиям, сравнил с подсчётом событий. Сопоставил корреляцию по значениям и по рангам. Округляю после вычитания, если в условии явно не задан другой порядок. |
| Сдать графический отчёт | Прошёл от проверки входных данных до пилотного предложения, указал размеры групп у своих находок, проверил функцию на новом периоде и перезапустил блокнот с чистого ядра. |

Для итогового интервью сохранить три наблюдения. Изменение порядка округления здесь изменило оценку ответа. Сравнение выручки ещё не отвечает на вопрос об окупаемости акции. Меньшая доля поздних доставок на дальних маршрутах перестала быть общим выводом после просмотра состава курьеров. Для последующих глав полезно отдельно проверить перенос идей о вероятности и неопределённости на новых данных. Текущая граница — глава 4.

## Воспроизведение, визуальная проверка и актуальность

Из корня репозитория, с экспортом, подготовленным штатным сборщиком:

```sh

```

Первая команда заново считает числа из пяти поставляемых CSV стандартной библиотекой Python. Вторая исполняет 21 целевую пробу через тот же Python-harness, что на сайте. Необязательный следующий аргумент — путь к существующей временной папке для PNG. Среда исполнения проб — Node 26.8.1, Pyodide 314.0.7, Python 3.14.2, pandas 3.0.2, Matplotlib 3.10.8. Штатная команда — `node tools/verify.mjs /tmp/ku-audit/tasks.json ch04/`; в журнале координатора результат «проверено: 215, проблем: 0». Справка pandas описывает метки и порядок колонок сводной, а Matplotlib возвращает из hist границы и счётчики для проверки рисунка. Эти API есть в комплектной версии и использованы в пробах. [pandas.pivot_table](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.pivot_table.html) · [Matplotlib.hist](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.hist.html)

Просмотрены PNG эталонной тепловой карты когорт и шести недельных рядов по кофейням, а также принятого недельного графика после подмены данных нулями. На карте видна треугольная граница доступных месяцев и процентная шкала. У отдельных точек единая вертикальная шкала, названия точек и даты читаются. На подменённом графике легенда и заголовок сохранились при двух горизонтальных нулевых рядах. Отдельный опыт с `Series.plot.bar` отклоняется в `pandas-plot`; условие там явно просит форму `plot(kind="bar")`, поэтому в список ошибочных отказов этот опыт не включён. Просмотр этих изображений не оценивает все клиентские экраны и цветовое восприятие аудитории.

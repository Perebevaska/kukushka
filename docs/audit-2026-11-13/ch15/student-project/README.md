# Удержание корпоративных клиентов «Зерно для офиса»

Направление B2B выбирает до 150 офисов на квартал для звонка со скидкой. Я собрал квартальные срезы из пяти таблиц SQLite и ранжировал действующих клиентов по ожидаемой прибыли контакта. На IV квартал 2026 года положительной оказалась оценка для 65 из 1 027 офисов. При удержании половины тех, кто собирался уйти, их суммарная ожидаемая прибыль составляет 443 403 ₽; 31 офис в списке находится в Уфе.

## Результаты и ограничения

- Обучал модели на трёх квартальных срезах, держал все строки одного клиента в одном фолде. Из логистической регрессии, бустинга и kNN по среднему ROC-AUC выбрал логистическую регрессию. На следующем квартале ROC-AUC составил 0,836, average precision — 0,530.
- Исторический список на 30 июня содержит 66 офисов, из которых 34 затем расторгли договор. Подстановка фактических меток и заданного эффекта звонка даёт 260 021 ₽, правило крупнейшего падения выручки — −227 324 ₽ за 150 звонков, обзвон всех — −2 446 569 ₽. Для этих же 66 офисов при доле спасённых 30 %, 50 % и 70 % расчёт даёт 58 010 ₽, 260 021 ₽ и 462 033 ₽ соответственно. Если заново отбирать офисы при каждом предположении, получаются списки из 34, 66 и 97 строк. Результативность самих звонков в этих данных не измерялась.
- У малых офисов «Стандарта» и клиентов в Уфе отток повышен. Доставку и тарифные условия стоит проверить отдельными пилотами. В верхней пятой части тестовой выборки средний прогноз равен 30,0 %, фактический отток составил 41,5 %. Недооценка риска ограничивает число звонков и снижает оценку прибыли. Группировка событий не устанавливает причины. Для проверки предсказанных денег нужны созревшие результаты квартала и контрольная группа без звонка.

## Воспроизведение

Нужны Python 3.12 и предоставленная учебная база office.db. Поместите её в data/office.db. История заказов для этой версии заканчивается 30 сентября 2026 года. Рабочие команды в корне проекта:

```sh
python -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python score.py --cutoff 2026-09-30
```

Повторный вызов записывает один CSV за ту же дату. Можно указать другой путь к базе через `--db` и имя выходного файла через `--out`. В CSV четыре столбца: идентификатор офиса, город, вероятность ухода и ожидаемая прибыль. Отбор выполняется до округления, по положительной прибыли и затем по убыванию, с лимитом 150. Для следующего квартала сначала нужна новая выгрузка полного периода.

[Блокнот](final_project.ipynb) содержит исследование, проверку на утечку, три графика, тест гипотезы, модели и экономику. Он исполняется сверху вниз из корня с чистого ядра. Публичный `check_notebook.py` из архива курса проверяет оформление и исполнение. [Признаки](src/features.py) общие для обучения и применения. [Паспорт](models/office_churn/1.0/passport.json) фиксирует типы, порядок признаков, параметры экономики, отпечаток базы и версии среды. Рядом лежат конвейер и двадцать контрольных строк. [Список звонков](reports/call_list_2026-09-30.csv) сформирован из сохранённого конвейера.

Стек: Python, SQLite, pandas, NumPy, scikit-learn, SciPy и Matplotlib. Данные синтетические, локальная копия базы исключена из Git.

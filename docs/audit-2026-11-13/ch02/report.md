## Что получает руководитель

Осенняя выгрузка содержит 2 089 заказов на **710 195 ₽** за сентябрь — ноябрь, шесть кофеен с продажами. Выручка по месяцам — 220 241, 233 756 и 256 198 ₽. В ноябре выручка выросла к октябрю на 9,6%, одновременно увеличились число заказов и средний чек. Впервые внутри трёхмесячной выгрузки в октябре появились 50 карт, в ноябре ещё девять. У 842 заказов отсутствует ID карты. Из этих строк нельзя определить число впервые пришедших людей. Корректное решение по осенним гипотезам требует подписать единицу, период и границы наблюдения. Согласовать постановку с вычислением: «Есть ли кофейня, которая входит в обе группы лидеров?» На новой таблице, где две точки делят максимум мест, ученик перечисляет всех лидеров, проверяет пересечение и не выдаёт его за зависимость по всем точкам.

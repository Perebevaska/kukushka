# Кому предложить абонемент «Зерно+»

Директору по лояльности нужно выбрать получателей осенней рассылки. Один контакт стоит 150 ₽, продажа абонемента приносит 1 600 ₽ маржи за три месяца. Модель обучена на июльском пилоте по данным, доступным до 1 июля 2026 года.

В пилоте купили 11,0 % из 1 800 получателей и 2,5 % из 600 гостей контроля. Для широкой рассылки это −14 ₽ на контакт. На кросс-валидации средний ROC-AUC логистической регрессии составил 0,827, на отложенных 450 гостях — 0,868.

При пороге 0,08 в список входят 792 из 1 987 активных гостей вне пилота. У них чаще бывают утренние заказы в будни и реже встречается доставка. Ожидаемая дополнительная маржа **138 160 ₽ за три месяца**, после вычета ожидаемых органических покупок. Только неопределённость контрольной доли даёт диапазон 91 939–167 056 ₽. У рассылки всем оценка составляет 5 940 ₽.

## Воспроизведение

1. Возьмите файл базы final1.db из каталога site/data архива курса и поместите его в data/ рядом с final-project.ipynb.
2. Создайте окружение Python 3.12 и установите пакеты командой pip install -r requirements.txt.
3. Запустите jupyter lab, откройте final-project.ipynb и выполните Restart Kernel and Run All Cells. Список кандидатов будет в data/autumn-candidates.csv.

Блокнот выводит версии библиотек, собственную таблицу качества четырёх моделей, денежные кривые и срезы по городам и возрасту. Данные и адресный список исключены из Git.

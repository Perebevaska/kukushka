# Как я прошёл главу 3

Я начал с опыта SQL/Excel и собственных решений первых двух глав. Прочитал введение и прошёл десять уроков в порядке курса. Все 93 задачи приняты, 92 с первой отправки. Всего было 95 отправок. Среди задач 27 разминок, 41 базовая, 15 повышенного уровня и 10 со звёздочкой. Из 20 предсказаний вывода верно ответил на 19, из 17 встроенных вопросов — на 17, на итоговом тесте — 13 из 13. Свои ответы давал перед проверкой. Отдельные подсказки и готовые решения не открывал.

## Что я делал в каждом уроке

| Урок | Результат и опора |
|---|---|
| 01-inspect | Осмотрел типы, пропуски, варианты городов и повторные карты. Отличил идентификатор от количественного признака. Перенёс знакомый по Excel осмотр вариантов значений в повторяемый отчёт на pandas. |
| 02-missing | Сравнил средние по известным балансам и после заполнения нулём. Сверил итоги после группировки заказов по карте, отдельно сохранил группу без карты. Разобрал разницу между наблюдаемой долей пропусков по группам и предположением о механизме их появления. |
| 03-types | Прочитал кассовую выгрузку с запятой в дробной части, превратил скидку в долю, нашёл исходные значения, потерянные при переводе в число. Ошибся при смешанном формате дат. После сообщения проверки переписал разбор и перенёс исправление в расчёт возраста. |
| 03b-excel | Прочитал листы отдельно, нашёл строки с названиями столбцов, убрал «Итого» и сверил его с собственным расчётом по кофейням. В задаче со звёздочкой нашёл разную высоту шапки на двух листах по метке «Код». |
| 04-duplicates | Разделил полную копию строки и повторную анкету. Привёл к единому виду ключ, выбрал свежую версию по дате, оценил завышение кассовой выручки из-за дублей. Из плоской выгрузки собрал справочник с учётом смены управляющих. |
| 05-strings | Сопоставил написания городов и напитков, восстановил коды точек, нашёл жалобы по нескольким вариантам слов. Проверка формата телефона и отрезание десяти цифр дали одинаковый результат на моей выгрузке, хотя на номере с добавочным они ведут себя по-разному. |
| 06-categories | Разложил интервалы через cut с явной стороной границы. Для верхней четверти расходов опирался на смысл квартиля и опыт SQL из второй главы. При укрупнении редких источников сохранил отдельную роль пропусков. |
| 07-anomalies | Разделил необычные заказы, заслуживающие проверки, и невозможные значения. Посчитал границы по межквартильному размаху, собрал тикет о заглушках рождения по данным. Для поиска анкет до открытия точки присоединил минимальную дату из справочника. |
| 08-pipeline | Разделил работу на функции. Проверил журнал числа строк, допустимые значения, сохранение CSV и повторное чтение дат. На январской выгрузке расширил обработку названий города. |
| 09-project | Решил восемь шагов и перенёс свой код в блокнот для маркетинга. Гостей без заказов сохранил при расчёте выручки на анкету. Деньги по возрасту сравнил только для активных с известной группой, для городов посчитал отдельный знаменатель из заказов с двумя известными городами. |

## Результат проекта

Из 307 строк осталось 293 анкеты после удаления 8 полных дублей и 6 повторных анкет. Заказы были у 88,7 % гостей. Для возраста пригодны 85,7 % анкет, медиана среди них — 39 лет. У активного гостя в среднем 1 646 ₽ за осень. Для 1 183 заказов известны оба города, в 85,1 % таких заказов город покупки совпал с городом анкеты.

Собрал собственный guests.ipynb с таблицами, выводом по каждому вопросу, журналом потерь, проверками и тремя тикетами о датах и бонусах. Сохранил очищенную выгрузку в локальной папке данных. Исполнил блокнот с нового ядра и сохранил выводы. Опубликованный check_notebook.py повторил выполнение и вернул 0 исправлений, 0 замечаний. Затем подставил в первую ячейку другое имя файла с тем же содержимым. На новом ядре итоговый словарь совпал. Изменения правил для января проверял в задании january, а повтор всего проектного отчёта проверял на переименованной копии осеннего файла.

Сохранил блокнот и README в отдельном локальном репозитории. Сырые и очищенные CSV исключены через .gitignore. Публичную публикацию на GitHub в этой симуляции не выполнял.

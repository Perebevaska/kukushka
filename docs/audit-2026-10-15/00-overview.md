## Как улучшить обучение без разрастания программы

1. **Сделать минимальный результат каждой главы проверяемым.** Описать: что ученик собирает, на каких новых данных это работает, какие ошибки данных должен объяснить. Обязательный отчёт должен включать все обещанные бизнес-результаты; технически сложные расширения можно оставить star.
2. **Перенести корректирующие действия в обязательную практику.** Если показывается выбор по test ради наглядности, ученик должен обязательно выполнить тот же шаг через validation, а не только прочитать оговорку или решить необязательную задачу.
3. **Добавить короткую независимую работу вместо части повторов.** После изолированных шагов с подготовленными переменными дать новую выгрузку и сборку без скрытого готового состояния. Проверять устойчивость функции к новым входам и качество вывода, а не запоминание эталонных чисел.
4. **Калибровать время по конкретным затруднениям.** В новых пробных прохождениях отдельно измерять чтение, самостоятельное решение, помощь, установку и проект. Указанные в README авторские замеры двух прохождений полезны, но не заменяют проверку на разных новичках.
5. **Встроить выпуск в проверочный процесс.** Формат, эталоны, неправильные решения, generated-файлы, миграции, браузер и доступность должны проверяться до публикации. Для сред хранить точные версии и дату прогона.

## Рекомендуемая последовательность работ

**Итерация 1 — точность и сохранность:** миграции, клавиатура, экономические критерии, ложноположительные проверки, подтверждённые ошибки формулировок и текущий LLM API.

**Итерация 2 — измерение навыка:** обязательный честный выбор порога, полный артефакт главы, пограничные случаи и независимые новые данные. Ввести общую рубрику: постановка → доступность данных → baseline → проверка → экономика → ограничения → воспроизводимость.

**Итерация 3 — поддержка курса:** release-check, матрица сред, точные зависимости, контроль доступности и новые замеры прохождения. Расширять тематический состав после подтверждения, что текущий основной путь усваивается.

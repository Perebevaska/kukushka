2. **P2. Требование while проверяется поиском слова.** [content/ch01/exam-1.md:170–171](</Users/dmitriikormin/Documents/Projects/ds-course/content/ch01/exam-1.md:170>): решение `# while` с `years = 6` прошло дополнительную проверку. 3. **P2. Объяснение форматирования противоречит проверке.** [content/ch01/14-project.md:420](</Users/dmitriikormin/Documents/Projects/ds-course/content/ch01/14-project.md:420>) обещает, что `f"{x:,}"` сам ставит пробелы. Поведение подтверждает [спецификация форматирования Python](https://docs.python.org/3.14/library/string.html#format-specification-mini-language).

4. **P2. Устаревшее правило кавычек.** [content/ch01/07-tables.md:239](</Users/dmitriikormin/Documents/Projects/ds-course/content/ch01/07-tables.md:239>) утверждает, что одинаковые кавычки внутри выражения f-строки завершат внешнюю строку. Для Python 3.12+ это неверно: ограничение снято PEP701. Пример с разными кавычками корректен; представить его как выбор читаемости. [Официальное описание изменения](https://docs.python.org/3.14/whatsnew/3.12.html#pep-701-syntactic-formalization-of-f-strings). В остальном выбранные основы языка актуальны для Python 3.14 браузерной среды.

## Приёмка

- Все344 существующие проверки снова проходят.
- Комментарий while, мёртвый цикл и захардкоженный ответ не засчитываются; корректный алгоритм работает на новых параметрах.

- Буквальный пример форматирования даёт требуемые пробелы; текст о кавычках соответствует Python 3.12+.

## Ограничения

Браузерный smoke-тест не заменяет полное прохождение. Нулевые ошибки эталонов не исключают ложноположительные проверки. Педагогическая эффективность и фактическое время требуют наблюдения за целевой аудиторией.

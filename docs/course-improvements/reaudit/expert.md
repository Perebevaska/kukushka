# Предметная перепроверка 15 глав

15 ноября 2026 года. В 16 карточках эксперт сопоставил условие, объяснение и вердикт для 35 конкретных программ. В обоих рантаймах из 18 правильных программ приняты 15, из 17 ошибочных отклонены 8. В остальных случаях три правильных ответа получили отказ, девять ошибочных — зачёт. Это целевой поиск по заданиям с вычислением, функцией или отчётом. Долю ошибок на всём курсе по такой выборке оценить нельзя.

За основу взято изменённое рабочее дерево поверх `454a62c`, SHA-256 экспорта `064d90ff887e7ef449676077629cf3bfae5ffdd91af7433c5f59b756bffc4eda`. Эталонный общий прогон и исторические сдачи учитываются отдельно. У эксперта 35 запусков в CPython 3.12.14 (pandas 3.0.6, NumPy 2.4.6, scikit-learn 1.8.0) и тех же 35 в поставляемом Pyodide 314.0.7 через Node 26.8.1. Оба исполняли `site/assets/harness.py`, исходные файлы задачи и её setup/check. Каждый запуск получал отдельную копию входов. Все 70 программ завершились, вердикты совпали попарно. Ученический интерфейс в эти 70 запусков не входит. Поля `expected` и `description` заданы в пробах до исполнения. Поля `passed`, `message`, `stdout` фиксируют ответ курса. [CPython](expert-native.jsonl) · [Pyodide](expert-pyodide.jsonl) · [Программы](expert_probes.py) · [Исполнитель Pyodide](expert_pyodide.mjs)

В таблице «+» обозначает зачёт, «−» — отказ. Первым указан ожидаемый по условию результат, после стрелки — полученный в обеих средах. Ссылки ведут к исходному уроку. Разделы теории и данные указаны для конкретных проб.

## Воспроизведение и границы

В корне проекта подготовьте экспорт командой из [регламента аудита](../../course-audit.md). Подставьте путь к нему и используйте Python с пакетами для исполняемых уроков. Для быстрого повтора одной главы передайте, например, `ch07` после имени экспорта. Режим `--emit` показывает весь код варианта до исполнения.

```sh
python docs/course-improvements/reaudit/expert_probes.py /tmp/tasks.json
python docs/course-improvements/reaudit/expert_probes.py --emit /tmp/tasks.json > /tmp/expert-input.jsonl
node docs/course-improvements/reaudit/expert_pyodide.mjs /tmp/tasks.json /tmp/expert-input.jsonl
```

Короткие выборки глав 1, 5, 11, 13 и 14 заданы прямо в заданиях. Учебные файлы доставок, оттока, мест, продаж, почасовых заказов и инцидентов создаёт [генератор курса](../../../tools/gen_data.py). Они позволяют воспроизвести числа и ветви принятия решения. По ним нельзя заключить, что звонки предотвращают отток, а стоимость ошибки модели соответствует расходам конкретной кофейни. Правила защиты сервиса проверялись на учебном журнале и отдельных строках, без запуска Docker. Реальные отзывы не размечались. Самостоятельность человека и темп первого обучения требуют наблюдения на новом материале. [Очередь внешних проверок](../remaining.md)

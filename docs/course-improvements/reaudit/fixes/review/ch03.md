# Глава 3. Независимая приёмка

T02 закрыто. Поиск «Код» на двух листах проходит в текущем Pyodide при разной высоте, константы 3/4 отклонены после независимых вставок двух и одной строки.

Ученик получил реальный отказ с min_count=1 на EKB-1. После перехода на сумму внесённых ячеек получил зачёт. В итоговом условии явно дан смысл нуля и для девяти пустых месяцев. Для другого режима учёта пустая сумма могла бы быть неизвестной.

**Проверка теста.** В c2 отсутствие ремонтов и отсутствие сумм счёта дают разные основания для восстановления средней. В c9 левая замкнутая граница относит 25 к [25,35). Сверены условия, четыре варианта и объяснения ключа для всех 13 вопросов. Единственный верный максимум длины до редакции — 12, после — 4. Для минимума соответственно 0 и 4. Исключены blockquote и метки ответа, пробелы нормализованы, равенство длин не даёт гарантированного выбора.

# Глава 14. Независимая приёмка

Повтор Pyodide дал IoU=0 для двух разнесённых рамок. Программа, перемножившая два отрицательных перекрытия, выдала 1/7 и отвергнута, несмотря на неизменные шесть исходных значений.

В alerts класс модели 0 и флаг ручного журнала 1 обозначают пустоту. Ученик считал непрерывные наблюдения отдельно для каждой ячейки и разрывал серию при пропуске кадра. В переносе отделил исходные кадры до аугментации.

**Проверка теста.** В c8 циклический сдвиг подменил бы серую границу другой частью изображения. В c13 IoU пересечения 50 и объединения 150 равен 1/3. Сверены условия, четыре варианта и объяснения ключа для всех 15 вопросов. Единственный верный максимум длины до редакции — 13, после — 5. Для минимума соответственно 0 и 1. Исключены blockquote и метки ответа, пробелы нормализованы, равенство длин не даёт гарантированного выбора.

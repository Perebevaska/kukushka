- **M02-01 — принято**. Сравнение чеков заказов с картой и без неё отделено от изменения чека после выдачи карты. В осеннем отчёте порог H4 равен 5%, а в SQL-проекте управляющая спрашивает об эффекте при почти одинаковых средних.
- **M02-02 — принято**. Пример A,B → B,C оставляет два активных ID и меняет состав. В общем числе есть анонимные заказы, поэтому из него нельзя восстановить приток людей.
- **M02-03 — принято**. Описаны оба способа оформить вывод. При повторном чистом запуске ученического блокнота проверка приняла исполненный Markdown(conclusion) с исходно очищенными выходами.
- **M02-04 — принято**. Максимум в сетевой сводной задаёт вопрос о конкретном дне и точке. Для назначения смен ученик должен открыть локальный срез.
- **M02-05 — принято**. Во введении названы 18 основных и пять дополнительных тем. Дневник приводит отдельные результаты по обоим маршрутам.
- **M02-06 — принято**. В объяснении квиза merge разобраны 0, 1 и 2 пустых ключа справа. Только два совпадения размножают заказ.

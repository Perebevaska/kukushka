# Повтор карточки «Выручка по любому полю»

Дата: 14 ноября 2026. Новый чистый профиль Chrome, настоящий интерфейс контрольной на порту 54801. Проверена только карточка revenue-by.

## Ожидание до отправки

Моя цель — сдать функцию группировки сумм по переданному полю без внешних данных. В текущем условии прямо написано: «Для сдачи достаточно определения функции. Данные и вызовы ниже можно использовать для самопроверки». Поэтому теперь ясно, что пример ниже необязателен. Кнопка «Проверить» находится непосредственно под редактором, связь действия с проверкой решения очевидна.

Отправлю то же определение, которое раньше было отвергнуто. Ожидаю словарь сумм по city или drink; пустой список оставит result пустым и вернёт {}. В функции нет зависимости от глобального orders. Ожидаю «Верно» без добавления демонстрационных данных и print. Сомнений, что именно сдавать, после чтения условия нет.

## Отправленный код

```python
def revenue_by(orders,field):
    result={}
    for o in orders:
        k=o[field]
        result[k]=result.get(k,0)+o["amount"]
    return result
```

Одна отправка, вердикт: **«Верно.»** В редакторе оставлено только определение функции; глобальные orders и демонстрационные print не добавлял. Пустого экранного вывода ожидал: функция сама ничего не печатает. Принятие подтверждено видимым вердиктом контрольной.

# Ученик: глава 08

## Своя стратегия до подсказок

Основной маршрут после главы 8 понятен: артефакт модели и CRM-проект главы 15. Главы 9–14 обозначены тематическими углублениями, их можно выбирать по рабочей задаче. Это явно прочитано во введении; не обязательно проходить все 9–14, чтобы продолжить основной путь.

В финальном проекте до открытия подсказок/решения написан свой код «Честные деньги рекомендации». Стратегия: out-of-fold оценки обучающей части; для каждого порога вычесть ожидаемые органические покупки из сопоставимого отобранного контроля; выбрать максимум дополнительной маржи; заново применить final к контролю и кандидатам. Пустую контрольную подгруппу нельзя объявлять нулевой органикой — такой порог пропускаю. Сумма вероятностей — ожидаемые покупки, не гарантированный результат. Стратегия и весь код записаны в JSONL до клика; кнопки подсказок/решения не открыты.

## Фактическая попытка

Задача 11 финального проекта проверена: «Отлично, задача решена». Получено: порог .08; отобрано 791; органика .057; ожидаемых покупок 205.9; наивная прибыль 210749 ₽; с поправкой 138723 ₽; рассылка всем 6296 ₽. Только после этого прочитан появившийся разбор: контроль над порогом 245 человек/14 покупок мал, использован для выбора и итога. Рекомендация — сохранить контроль в следующем запуске и измерить дополнительный эффект непосредственно. Прогноз покупки не равен индивидуальному эффекту предложения.

В проекте автоматов до действий прочитано противоречие: условие и заготовка требуют 300 уникальных адресов без возвращения, вводный текст утверждал, что нужен бутстрэп с возвращением. Сообщено автору. За основу собственной будущей попытки принят явный конечный реестр и условие карточки. Квизы/карточки автоматов пока не нажаты; никакой результат им не приписан.

Остальные шаги четырёхчасового финала не перепройдены целиком: проверялось изменённое самостоятельное решение и видимый маршрут. Исходники/эталоны не читались. Заготовка построения data/oof взята только из видимого редактора.

При возврате перечитано исправленное объяснение конечного реестра: в сценарии 300 уникальных адресов из известных 375, затем 40 разных мест, выбор без возвращения. Для ещё неизвестных похожих объектов модель с возвращением — другая постановка. Теперь текст и условие согласованы, прежнего препятствия больше нет. Саму карточку риска автоматов не отправлял.

Впервые отвечен вопрос театра: (12 − 10) × 500 − 1500 = −500 ₽ дополнительного результата на 100 получателей. Ответ записан до клика, «Верно».

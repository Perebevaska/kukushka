# Приёмка главы 6. Первые модели машинного обучения

## Качество подачи учебного материала

Правило, модель и рабочий список теперь сопоставляются при одном бюджете. Ученику удалось объяснить, почему склонность к уходу ещё не показывает, кого вернёт бонус. [Оценки по пяти критериям и решения по каждому M-ID](methodist.md)

## Пути улучшения подачи

Оставить сравнение при равных 60 местах. Для нового периода попросить заранее записать порядок при совпавших баллах и показать, сколько реальных уходов покрывает список после созревания метки. Отдельная гипотеза для пилота — понимает ли человек разницу между риском ухода и эффектом бонуса до подсказки.

## Чем проверили

- **Студент.** Ученик получил глубину 5 по валидации, сравнил 60 мест против 60 и локально составил декабрьский список. Два теоретических квиза исключены из независимого результата после случайного чтения скрытых пояснений. [Дневник повторного прохождения](student-retest.md)
- **Рецензент.** Подмена модели и выдача гостей с самым низким риском отклонены. В учебном shop-rate сохранился расчёт с собственной меткой строки, безопасная OOF-схема вынесена в другой урок. [Повторные предметные пробы](review.md#приёмка-обновлённой-редакции)
- **Методист.** Прослежены последовательность объяснения, условия сдачи и обратная связь. Вопрос про выбор глубины дерева на почте содержит четыре разобранных варианта. - **Редактор и автор заданий.** [Изменения в уроках](editor.md). Авторские расчёты и контрпримеры приведены в [ведомости проверок](checks.md).

## Исполнение плана

Видно, на какую дату требуется прогноз и какие признаки доступны. Глубина дерева выбирается на валидации. Финальная выборка служит для независимой оценки. Отдельный файл даёт свежие признаки получателей.

На валидации глубина 5 дала accuracy 0,812, а глубина 12 — 0,777, хотя её обучающая точность выше. В проекте для текущего списка не используются churned и card_blocked.

## Что осталось

В упражнении shop-rate учебное среднее по точке всё ещё включает значение целевой переменной самой строки. Для рабочего признака понадобится расчёт вне фолда, показанный отдельно. Два теоретических квиза с преждевременно показанными пояснениями исключены из независимой оценки.

## Сверка повторного аудита 15 ноября

При раздельной сортировке ID кофеен и рассчитанных долей ошибочны 376 из 461 тестовой строки. Проверка принимает результат. Свежая самостоятельная работа — `09-project/depth`, зачёт с первой попытки.

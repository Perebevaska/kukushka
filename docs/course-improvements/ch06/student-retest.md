# Ученик: глава 06

## Выполнено

На видимом графике внутренней валидации до расчёта выбрана глубина 5, а финальную оценку предложено получать на оставленной окончательной четверти после фиксации глубины. Свой код карточки «Подобрать глубину» прошёл: максимум 0.81159, глубина 5, «Отлично, задача решена». Разделены обучение, выбор и окончательная проверка.

По видимым учебным файлам проверен один новый список: исторический лес (100 деревьев, leaf=3) обучен на train без card_blocked; на историческом тесте модель отобрала 60 контактов с долей уходов 0.95, правило равного бюджета — 60 с 0.86667. Тестовая accuracy 0.89833. Новый срез guests_current.csv имеет дату 2026-12-01 и не содержит churned. По нему получен список 240 из 2400 гостей на 10% бюджета. Персональные ID списка остались в собственной временной папке, не публикуются в отчёте.

Результат означает риск по исторической модели, а не доказанный будущий уход и не тех, кого бонус обязательно вернёт. Октябрьский список не выдаётся за актуальный декабрьский. Цель/ожидание и полный свой код записаны до исполнения в JSONL. Новый список выполнен локально на учебных файлах, отдельного браузерного зачёта ему не заявляется.

## Ограничение чистоты

Один диагностический вызов allTextContents по теоретическим .quiz-c в 03-tree и 08-validation случайно вернул скрытые пояснения ответов. Это немедленно сообщено ведущему; способ прекращён, далее только innerText видимых элементов. Эти два квиза не считаются независимым ученическим прохождением. Код изменённой карточки глубины и нового среза написан самостоятельно; он опирается на видимый график/условия и свои знания, не на скрытый код проверок.

Общая трудность: первые запуски sklearn иногда ещё показывают загрузку библиотек; положительный результат глубины зафиксирован только после видимого вердикта. Итоговый тест главы целиком не проходился.

На завершающей серии впервые отвечен переносный вопрос 12 о почте: глубину выбирать по валидации, затем один раз оценить на финальной части. «Верно». Именно этот вопрос со скрытыми пояснениями ранее не читался.

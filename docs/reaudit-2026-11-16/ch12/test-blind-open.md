# Независимый ответ на открытый вопрос

Нет. Все прогнозы на следующий день выпускаются сегодня в 18:00, поэтому для каждого прогнозируемого часа допустимы только сведения, доступные к сегодняшним 18:00. Фактическое число заказов за 17:00 завтрашнего дня появится уже после выпуска прогноза и будет утечкой будущего. Оно могло бы стать признаком отдельного обновлённого прогноза завтра после 17:00, но это другой режим прогнозирования.

# Собственные ожидания до чтения отчётов и запуска

Версия b3291d4. Прочитаны публичные тексты исходной главы из закрытого ученического пакета, видимый README и регламент. Фактические ответы проверок и свежие заключения ещё не открывались. Условия ниже сформулированы до исполнения программ. Для 11 строк отправляем код в проверку карточки. В четырёх отдельно помеченных контролях используем тот же runtime и setup с собственным критерием. Эти четыре строки не являются сдачами в тренажёр.

Порядок целых подписанных строк и столбцов не меняет их смысл. Сортировка из условия обязательна для top3 и списка leaking. Для рабочих часов применяем маску 07–22 включительно, единицу человек на рабочем нуле и нуль работников вне смены. На июльской валидации модель для 1 июля замораживается не позже 30 июня 20:00, а сравнение кандидатов для 1 августа заканчивается 31 июля 19:00. При заново выпущенной задаче граница июльской оценки зависит от публично объявленного момента решения. Объём доступных исторических меток различаем с будущим горизонтом на 24 целевых часа без y. В старом условии шага grid явно требовалась оценка на августе и одновременно план обещал одно окончательное открытие. Поэтому здесь независимо проверяем правило внутри фолда, а раннее измерение рассматриваем как противоречие в публичных материалах.

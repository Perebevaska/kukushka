# Ожидания до расчёта
По каждому из трёх рабочих часов вычислю needed=max(1,ceil(спрос/мощность)); нулевой спрос оставит одного дежурного. Для постоянных планов 2 и 3 отдельно суммирую max(needed-plan,0) и max(plan-needed,0), затем стоимость 180*дефицит+100*избыток. При изменении только мощности 6→5 ожидаю, что 11 заказов пересекут границу двух сотрудников; цены, состав сравниваемых планов и все три часа сохраняются. Выбор проверю по полной сумме стоимости, а не по одному дефицитному часу или слову «квантиль».

Письмо проверю по собственному CSV повторного расчёта: число строк для RMSE должно быть подписано отдельно от числа рабочих часов для short/coverage и сумм бариста-часов; кадровые часы отберу по явной маске 07–22. Исходное письмо было отправлено на редакторскую проверку, новая подпись знаменателей — правка после полученного отзыва, а не моё независимое обнаружение.

# Проверка доступности июльских ответов до первого августовского выпуска

Записано до нового вычисления. Сохраняем исходный отдельный результат на 744 июльских часах. Обучать июльские модели можно на 2 756 строках по 30 июня 19:00 включительно. Для выбора семейства в 20:00 31 июля известны 740 июльских ответов с 1 июля 00:00 по 31 июля 19:00; последние четыре часа этого дня в оценку не входят. Кандидаты, веса и даты задаются заранее. Искусственная порча только этих четырёх июльских меток должна оставлять оценки четырёх моделей и ранжирование четырёх сезонных ориентиров на 740 часах прежними. Для полного июля должна измениться их ошибка. Если победитель не изменится, это не разрешает использовать неизвестные метки. Абсолютные значения новых метрик фиксирует последующий расчёт.

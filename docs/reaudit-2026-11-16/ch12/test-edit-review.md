## Подготовленная редакция дистракторов c8/c11/c12

17 ноября, до передачи новой ревизии студенту, координатор расширил разрешение внутри тех же девяти вопросов. В c8 заменены два слабых варианта, в c11 — три; в c12 — вариант про безусловное превосходство правил. Для согласованности выбора c11 теперь спрашивает о роли августовских ответов, c12 — о корректном выводе. Ключи, их позиции и смысл сохранены; revisions остаются v5, поскольку этот выпуск ещё не передан ученику. c1/c2/c7/c13 не тронуты.

| Вариант | Правдоподобная рабочая ошибка | Почему ответ ошибочен |
|---|---|---|
| c8.2: модель за август, ориентир за июль | Аналитик берёт уже готовые метрики из разных отчётов | Меняются спрос и трудность периода; разницу нельзя приписать методу. Сравнивать надо на одинаковых часах и одной метрике. |
| c8.3: ориентир вместо фактической цели (сохранён) | Готовую колонку прогноза принимают за y | Получается воспроизведение ориентира, а не обучение прогнозировать фактические заказы. |
| c8.4: подбор по выигрышу на итоговом тесте | Любое улучшение относительно baseline считают достаточным для очередного тюнинга | Итоговые ответы участвуют в выборе, и оценка выбранного решения теряет независимость. Для выбора есть валидация. |
| c11.2: дообучение на всех августовских ответах перед оценкой | Перед финальным отчётом объединяют все доступные в файле данные | В обучение попадут ответы самих оцениваемых часов до выпуска соответствующих прогнозов. Слово «всех» исключает защитимое прочтение об обновлении только по уже завершённому прошлому. |
| c11.3: выбрать на августе лучший июльский набор | Выбор среди готовых моделей не считают подбором | Выбор победителя по августу тоже использует итоговые ответы; неизменность готовых наборов не спасает оценку. |

| c12.2: меньший RMSE гарантирует меньше нехватки (сохранён) | Общую точность подменяют частотой недобора | Симметричная квадратичная ошибка не ограничивает число односторонних недоборов после округления. |
| c12.3: две метрики доказывают переобучение (сохранён) | Разнонаправленные метрики принимают за диагноз | По двум агрегатам нельзя установить процесс обучения; у метрик разные цели. |

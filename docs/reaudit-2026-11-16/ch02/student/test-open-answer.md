# Ответ до выбора вариантов
Нельзя присваивать выручку по позиции: строки справочника переставлены. Соединю справочник с агрегатом по коду магазина через left merge с validate='one_to_one', предварительно проверив уникальность кода в обоих наборах. Либо set_index('shop_id') у агрегата и shops['shop_id'].map(revenue). После соединения проверю число строк и отсутствующие соответствия; ноль заменяет отсутствие только если известно, что магазин работал без заказов. Индексные подписи Series тоже можно использовать через join, но сортировка сама по себе не определяет соответствие.

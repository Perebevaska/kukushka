# Самостоятельный перенос на другой состав доставок

Источник: deliveries_branch.csv, отдельная синтетическая выгрузка; всего 1741, пригодных 1706. Название целевой группы не переносил из первого проекта.

Выбрал по максимальной наблюдаемой доле опозданий группу **авто**: 481/566 = 85.0%. Остальные группы:

         sum  size      mean
courier                     
авто     481   566  0.849823
пеший    103   268  0.384328
вело     113   872  0.129587

При одном обещании **45 минут** выбранная группа имеет 254/278 опозданий (91.4%); остальные типы вместе 87/649 (13.4%). Значит, общий разрыв не снимается одним сравнением обещания. Срез с числителями и знаменателями:

Для подгруппы авто, обещание 45, п80 факта 61.0 мин; округление вверх до пяти — **65 мин**. На исходных маршрутах в этот срок уложились бы 257/278 (92.4%). Это сценарий изменения честности обещания, а не ускорение доставки и не прогноз выручки.

Предлагаю пилот 65-минутного обещания в сопоставимых маршрутах этой группы, распределив предложение случайно внутри обещания, расстояния и часа. Главная мера — своевременность ≥80%; одновременно измерять конверсию, отказы и маржу. Если в пилоте доля своевременных ниже 80%, либо конверсия и маржа ухудшаются настолько, что бизнес-результат отрицателен, предложение не масштабировать. Нужны интервалы неопределённости, размер и срок пилота из следующей главы.

Ограничение: synthetic данные другого состава, прежние названия не гарантируют прежние процессы. Курьер, час, погода и маршрут могут смешиваться; выбор по максимальной доле оптимистично выделяет крайность. При одинаковом обещании ещё не одинаковые маршруты. Нельзя обвинять тип курьера причинно.

## Приоритетные карточки плана

`funnel-platform`: иной расчёт через `groupby(...).nunique().unstack()` принят; обратный порядок целых групп принят; перестановка одних платформ/периодов отклонена. На другом входе со сменой платформ корректный расчёт даёт `lost=-5` и принимается, фиксированное `104` отвергается. Знак и смысл отрицательной оценки раскрывает эксперт в тексте урока. Дополнительная найденная проблема — только усечение дробного `lost`, C04-13.

`walkers`: иной способ выбора лидера принят; перестановки целых строк/столбцов `pv` приняты, одних подписей — отклонены. Проверен новый состав с лидером авто: динамическое решение принято, фиксированный выбор пеших отвергнут (`walk_p80=29.8` вместо `40`). Отдельная синтетическая ничья: у трёх групп ровно 50 % опозданий, квантили и медианы различаются; вход начинается с пеших. Алфавитный выбор авто принят (`walk_p80=32.8`), `groupby(sort=False).idxmax()` с выбором первого встретившегося пешего отвергнут (`44.2`). Исправления этого check не потребовались.

Новая ранее не проверявшаяся карточка — **sticky-city**. Выбрана по содержательному основанию: после исправления календарей `sticky`/`wau-full` прежний отчёт явно оставлял городскую агрегацию без независимой пробы. Проверяет тот же навык на паре дата×город, где пропуск может затронуть один столбец, а не всю сеть. На исходных данных нулевого дня нет; контрпример — контролируемая выгрузка с полностью наблюдаемым днём без покупок, а не гипотеза о сбое источника.


Первые две команды берут сохранённые исходные check/setup, последние — текущие экспортированные проверки. Для Pyodide перед `--after` должен существовать `tasks-after.json`, который создаёт native-команда. Полные исходные/конечные реплики сохранены, а не восстановлены по тексту assert.

Исторический oracle `title` раньше называл верной обратную последовательность без инверсии оси, хотя условие требовало убывания. В `tools/checks/ch04_acceptance.py` верная проба теперь включает `invert_xaxis()`, и добавлена отрицательная без инверсии. Это **исправление прежнего неверного ожидания**, не незаметное изменение доказательства. Неизменный исходный экспорт и новые программы позволяют повторить обе стороны.

При проектировании двух первых проб обнаружены ограничения самих проб: обратная подпись городов меняла местами равные 13.9 %, а удаление только верхнего диапазона времени не изменяло итоговые ранги. Эти случаи не объявлены дефектами. Для подмены городов добавлена циклическая перестановка с неравными значениями, для Spearman — восьмистрочная таблица с внутренними пропусками расстояния. Первоначальный набор и журналы сохранены как `probes-initial.json`, `native-initial.log`, `pyodide-initial.log`; окончательный набор повторён целиком с неизменными исходными checks и с исправленными checks. Ожидаемый вердикт каждого нового случая записан до его запуска.

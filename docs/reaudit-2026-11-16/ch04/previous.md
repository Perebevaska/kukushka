## Найденные координатором остатки

1. **Календарный знаменатель wau-full.** В `content/ch04/05c-dau-mau.md` диагностика проверки всё ещё советует `g["date"].nunique()` и «разные даты ... nunique() по date». Это число дат с покупками, тогда как условие, hint и решение правильно требуют отдельный полный календарь. На текущем CSV результаты совпадают; при нулевом дне совет возвращает старый дефект M04-06/E04-09. Минимальная правка — оба сообщения направить к сумме единиц календаря по неделям. Доложено основному координатору немедленно. При завершающем перечитывании обнаружена параллельная правка: теперь проверка выравнивает недели по ключу и сообщение требует календарь с 1 января по 30 июня, включая даты без заказов. Текстовый остаток устранён; в финальном пакете рецензента все три пробы для полностью наблюдавшейся недели без единого заказа дали ожидаемый вердикт.
2. **Один день против пары дней.** В `content/ch04/05-time.md` правильный вариант встроенного quiz говорит «пара дней» для последней недели. Период заканчивается в понедельник 30 ноября 2026: там один день, что верно указано в окружающем объяснении. В финальной редакции указан один день; ученик правильно ответил на обновлённый вопрос. Для 05c другая выгрузка заканчивается во вторник 30 июня: края 4 и 2 дня, 27 недель и 25 полных — верны. Недели двух наборов не смешиваются.

Этот раздел фиксирует наблюдение на момент сверки; последующая правка другим агентом требует обновить SHA и регистр, а не молча считать прежнее наблюдение актуальным.

```sh

python3 docs/reaudit-2026-11-16/ch04/technical/aggregate_coverage.py --export /tmp/ch04-fresh.json
```

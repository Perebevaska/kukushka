# Слепые открытые ответы: глава 11

Записаны после чтения только questions-only.md; варианты, ключи, уроки и отчёты не читались.

1. Логистическая регрессия: сигмоида линейной комбинации признаков и смещения даёт вероятность бинарного класса.
2. Вычисляет градиенты потери по параметрам сети по цепному правилу от выхода к входу. Само изменение весов — отдельный шаг оптимизатора.
3. Это независимая численная проверка аналитического градиента/backprop: сравнивая компоненты на небольшом примере, можно обнаружить ошибки производных или реализации. Нужен разумный h из-за округления и ошибки аппроксимации.
4. Масштаб инициализации: стандартное нормальное распределение без учёта fan-in может взрывать активации глубокой сети. Для ReLU использовать He (стандартное отклонение sqrt(2/fan-in)); дополнительно проверить устойчивую реализацию потери с логитами, но первый адресуемый дефект — инициализация.
5. Сила L2-регуляризации весов: больший alpha усиливает штраф и ограничивает сложность; это не learning rate.
6. Чтобы признаки сопоставимых масштабов не создавали плохо обусловленную оптимизацию: обучение градиентным методом устойчивее и быстрее, меньше насыщение активаций. Масштабировщик учат только на обучающей части.
7. Вычисляет градиенты скалярной loss по графу и накапливает их в .grad листовых тензоров с requires_grad. Не обновляет параметры.
8. Пять сырых логитов, CrossEntropyLoss, целевая категория — индекс класса. Softmax отдельно перед такой потерей не нужен; при предсказании выбирается argmax.
9. 2000/100 = 20 шагов за эпоху; за 5 эпох — 100 шагов.
10. Случайно обнуляет часть активаций на обучении, препятствуя совместной подстройке нейронов и снижая переобучение. На оценке выключается; это регуляризация, не гарантия улучшения.
11. Нужны истинные и предсказанные последовательности цифр, сгруппированные по каждому номеру; доля номеров со всеми шестью верными цифрами. По одной маргинальной точности цифр точную долю не восстановить без знания совместных ошибок. При независимости можно лишь оценить произведением вероятностей.
12. Разумный исходный ориентир для обычной таблицы — бустинг, но выбор подтверждать одинаковым честным разбиением/валидацией и подходящей метрикой. Нейросеть сравнивают при достаточном объёме, специальных представлениях или иных основаниях; универсального победителя нет.

# Пакет ученика главы11

Главный отчёт — report.md. Ход и ошибки — progress.md, findings.md, diary.md, knowledge.md. Сырые первые попытки — поурочные *.input.jsonl, фактический feedback — *.feedback.jsonl; исправления названы отдельно. summary.json считает91 отправку и89 уникальных ID.

- native-extra.ipynb: выполненная копия extra, собственный эксперимент16 нейронов и реальные упражнения PyTorch. native-check-final-full.txt — полный officialchecker0/0.
- native_transfer/: загрузка выбранной сети без обучения,16 контрольных прогнозов в минутах, описание входа и состояния.
- digits-project.ipynb: самостоятельное сравнение, выбор до финала и очередь до меток. digits-check-final.txt — полный officialchecker0/0.
- digits_transfer/: отдельная сохранённая модель, решение до меток, контрольные вероятности, метрики и predict.py.
- test-open-answer.md: открытый ответ, записанный до вариантов; archive-transfer-answer.md — самостоятельный перенос на архив.

Для воспроизведения блокнотов нужна среда numpy,pandas,matplotlib,scipy,scikit-learn1.8.0,torch2.15.0,joblib,nbclient. Блокноты используют CPU; native задаёт1 поток torch и interop. CSV в data/ — копии разрешённых входов. Скрипты prepare*.py — первоначальная подготовка артефактов; готовые блокноты после адресных исправлений являются финальной версией.

Заморозка: после сообщения «готов» пакет не изменяется до проверки получателем. FREEZE.sha256 содержит контрольные суммы финальных файлов. Получателю достаточно скопировать соответствующую папку transfer; запуск predict.py по умолчанию сверяет16 контрольных прогнозов, без fit. Для своих запросов прочитайте контракт в README соответствующей папки.

# Отдельный перенос: архив

Q1: оценить ручную проверку целой записи с инвентарным номером, а не только распознавание отдельных цифр.
Q2: у меня есть опора из очереди телефонов, но архив — другая единица работы: одному инвентарному номеру может соответствовать несколько фрагментов скана и проверяемых символов.
Q3: нужны ID целой архивной записи/документа, набор и порядок позиций символов в ней, исходное изображение номера целиком, эталонная строка и автоматическая строка до вмешательства, правило очереди и сохранённое до эталонов решение о проверке, отметка фактической проверки оператором, его исправленная строка, время проверки и результат контрольного сравнения. Если одному документу соответствует несколько номеров, нужен ещё ID номера внутри документа.

На отложенных записях считаю полностью правильные строки до оператора и после него, ошибки, оставшиеся в непроверенных записях, число уникальных карточек и суммарное время оператора. Сохраняю начальные нули и одинаковые правила формата. Риск зависит от цены пропущенной ошибки; по одной только точности цифр нельзя назвать ни точность записи, ни экономию ручной работы. Дедупликация очереди по ID не означает, что оператор исправил все ошибки карточки — это нужно измерить.

Ответ самостоятельный, без обратной связи по этому переносу на момент записи.

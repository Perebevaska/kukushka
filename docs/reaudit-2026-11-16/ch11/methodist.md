## Пути улучшения подачи

**N11-M01 · P1. Отделить выбор параметров от итоговой оценки во всех соседних примерах MLP.** В разделе о кривых пример делает `partial_fit` и следит за «AUC тест» каждую эпоху. В `depth` буквально требуется «AUC на тесте … и best — ключ лучшей». В `alpha-sweep` внутреннюю валидацию заготовка называет `X_test`. Старый разбор считает лучшим округлённое 0,910, хотя условие и код уже считают по другому разбиению. В подсказке `epoch-gap` остался `auc_test`. Этот набор сигналов учит использовать финальные ответы при следующем выборе архитектуры. Редакция рядом с первой таблицей и каждым выбором: «Отложите финальные строки. Для каждого кандидата внесите в таблицу AUC внутренней валидации. По ней выберите настройку и запишите её. Затем оцените выбранную процедуру на финальных строках». Во всей цепочке назвать промежуточные массивы `X_validation`, `y_validation`, согласовать заголовки рисунков, подписи, подсказки, условия и числовой разбор с реальной процедурой.

# Полная передача цифр

Модель скопирована из моего прежнего проекта без повторного обучения. Это KNeighborsClassifier, выбранный ранее по validation. Правило confidence и очередь из decision_before_labels.json сохранены до прежнего открытия итоговых меток и сейчас не изменены.

Полные входы: clean_request.npy и blur_request.npy — каждый (450,64). request_ids.csv связывает position (0..449) с original_index в sklearn load_digits. В evaluation.csv те же два ключа, а также итоговые метки и прежняя оценка. Для предсказания метки не нужны. Строки пикселей соответствуют request_ids.csv строго по позиции.

64 признака идут по строкам изображения 8×8: x0..x7 — первая строка, x8..x15 — вторая. Диапазон 0..1: исходную яркость 0..16 уже разделили на 16. Повторно делить и обучать scaler не нужно. Blur — gaussian_filter sigma=.65, mode=constant, cval=0 отдельно на каждой картинке. Точный процесс восстановления из собственного проекта сохранён в reconstruct_requests.py. Он проверил первые 16 clean входов и все исходные ID против прежних файлов.

Команда проверки без обучения из этой папки:

    OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 /private/tmp/ku-audit/nb-env/bin/python replay.py

replay.py загружает digits_model.joblib и оба полных запроса, рассчитывает вероятности и классы для всех строк и очередь 37 цифр: сортировка по максимальной вероятности по возрастанию, затем по position по возрастанию. Результаты clean_replayed.csv / blur_replayed.csv и *_proba.npy позволяют сверить все строки. Проверяет другую разбивку по 17 и перестановку с восстановлением порядка. На моём повторе максимальные расхождения 0; полная blur очередь и прогноз совпали с прежним решением. predict.py поддерживает старый короткий пример и произвольный запрос (n,64).

Проверяется отдельная цифра. Телефонные номера, сегментация и работа оператора здесь не представлены. Восьмизначные строки надо сравнивать целиком на реальных отложенных документах. Версии модели указаны в metadata.json; прежний учебный результат не доказывает качество на настоящих анкетах.

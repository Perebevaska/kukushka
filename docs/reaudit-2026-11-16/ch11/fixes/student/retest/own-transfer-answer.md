# Открытый ответ до вариантов

На отложенных документах сохраняю ID документа и номера, позиции цифр, эталонную восьмизначную строку и предсказанную строку с сохранением ведущих нулей. Для каждой строки сравниваю сразу все восемь позиций: признак успеха равен 1 только при полном совпадении. Доля полностью правильных кодов — сумма этих признаков / число проверенных кодов. Не перемножаю точности цифр: ошибки внутри документа могут зависеть от почерка, скана и сегментации. Отдельно проверяю качество сегментации и порядок символов. Для доверительного интервала пересэмплирую документы, если в одном документе несколько кодов.

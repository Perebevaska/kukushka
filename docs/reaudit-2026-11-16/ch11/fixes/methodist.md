В браузерной задаче с MLP ученик показал уверенную ошибку на валидационной позиции 55 (истина 6, прогноз 4, уверенность 0,981). До открытия меток он сохранил 37 позиций по возрастанию максимальной вероятности, при равенстве — по позиции. Из 32 ошибок финальной партии 12 попали в очередь, 20 остались вне неё. Позиция 25 — предъявленный конкретный пропуск. На другом учебном наборе с 11 заказами пять признаков и пары по ID сохранились во всех четырёх пакетах размером 3/3/3/2. Сдвиг только меток обнаружен при тех же размерах. Отдельная численная проверка выявила ошибку знака в производной.

# Передача digits

Свой проект — digits-project.ipynb. Запуск `python predict.py` загружает сохранённую модель безfit и сверяет 16 прогнозов; `python predict.py request.npy` принимает(n,64)яркости 0..1,развёрнутые по строкам 8×8. Сначала делите исходныеpixels0..16 на 16; не стандартизуйте заново. Модель поддерживает 10 классовdigits,это не готовый распознаватель целого документа.

`decision_before_labels.json` фиксирует выбранную поvalidation модель и очередь 37 цифр дооткрытияфинальныхметок. `evaluation.csv` — оценкапослефиксации; `metrics.json` —accuracyчистая/размытая и ошибкивнеочереди. Входыcontrolне содержатметок.

Для других размеров/фона нужны отдельная подготовка и независимаяпроверка. Телефоннуюточность по этим цифрам не вычисляю. Использованы sklearn1.8.0,numpy средыnative; точныеверсиивoutputпервойячейки.

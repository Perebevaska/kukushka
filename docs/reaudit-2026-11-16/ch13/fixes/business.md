**Внешний M13-01 — открыт.** Владелец следующего действия — управляющая сетью совместно с руководителем поддержки или ответственным за данные отзывов. Им предстоит организовать отбор реальных отзывов из обоих периодов и независимую человеческую разметку по единой инструкции, включая тексты без сигнала. Отдельно зафиксировать пропуски, разбирать расхождения, посчитать числители, знаменатели и неопределённость разницы. Для оценки *обоснованных* претензий нужны правила проверки по заказу и учёт случаев, когда подтверждение недоступно. Для гипотезы об опозданиях можно сравнить их количество со всеми доставками соответствующих точек в те же недели.

При первой bridge записал код в первый из двух редакторов на карточке, а кнопка запустила нетронутую заготовку во втором. Система вернула оценённый отказ «Не нашёл переменную weekly». Эта попытка сохранена. Диагностика DOM выявила два CodeMirror, из них только один внутри `.task-ui`, первый редактор относится к примеру. После выбора редактора задачи и контрольного чтения текста тот же код, SHA256 `54948a3300fb28c8ea8e0f48e371b7342706d04b60b58220d44cd27990370383`, принят без подсказок и транспортных отказов. В результате показаны KZN-2, 5 октября, 0,425 и столбчатый график с девятью понедельниками. Сопоставил оба текста программ побайтово. Ученик не менял вычисления или способ построения. Первая попытка относится к ошибке адресации средства ввода; она не даёт основания для ещё одного дефекта курса. Обе отправки отделены от основного журнала из 43 оценок, число уникальных адресно проверенных ID осталось 42.

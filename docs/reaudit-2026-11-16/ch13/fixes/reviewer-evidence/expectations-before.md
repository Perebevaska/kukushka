# Независимые ожидания до чтения новых отчётов

Исходный экспорт 563d774, 25 программ. Каждая программа зафиксирована целиком. В качестве контролируемой основы использованы исходные авторские решения. Преобразования и ожидания ниже выбраны до их исполнения и чтения других проб. Новый человеческий эталон для реального потока этими программами не создаётся.

| ID | Задание | Ожидание | Основание |
|---|---|---|---|
| R01 | parse-llm | зачёт | Произвольные строковые ID сохраняют порядок ответов. |
| R02 | parse-llm | отказ | Первые два валидных ответа поменялись местами при прежнем числе ошибок. |
| R03 | parse-llm | отказ | Функция возвращает годный результат лишь для восьми знакомых строк. |
| R04 | clean | зачёт | Нормализатор обрабатывает новое слово с Ё, цифрами и переносами. |
| R05 | clean | отказ | Правильная показанная строка, но функция возвращает исходный ответ для другого текста. |
| R06 | topics | зачёт | Переставлены строки и столбцы с их метками. Каждая ячейка осталась у тех же тем. |
| R07 | topics | отказ | Те же числа, но переименованы только столбцы. Ошибки приписаны другим темам. |
| R08 | top-words | зачёт | Сортировка индекса Series сохраняет пару слово–коэффициент. |
| R09 | top-words | отказ | Два внутренних коэффициента обменялись словами, списки из пяти и «не» сохранены. |
| R10 | lsa | зачёт | Смена знака одной общей координаты сохраняет косинусы для каждого ID. |
| R11 | lsa | отказ | Обратный порядок строк нарушает связь review_id с эмбеддингом. Длины единичные и записанные соседи прежние. |
| R12 | weekly | зачёт | Ту же динамику выбранной точки показывает отдельная линия средствами matplotlib. |
| R13 | weekly | отказ | Меняется одна показанная ордината выбранной точки, числовая таблица сохранена. |
| R14 | recall95 | зачёт | Перестановка наблюдений итогового теста целиком сохраняет измерение при пороге из validation. |
| R15 | recall95 | отказ | В финальном расчёте вместо 600 итоговых строк повторно использованы 600 валидационных строк. |
| R16 | llm-same | зачёт | Переворот целых пар по review_id оставляет разногласия и интервал неизменными. |
| R17 | llm-same | отказ | Циклический сдвиг результатов только одной системы сохраняет accuracy, разрушает парность. |
| R18 | why | зачёт | Строки тем переставлены вместе с метками, цитаты и исходные ID сохранены. |
| R19 | why | отказ | Тексты оставлены на местах, ID двух цитат переставлены. |
| R20 | adjust | зачёт | Обратный порядок каждой входной таблицы сохраняет объединение по ключу, числители и знаменатели. |
| R21 | adjust | отказ | После сдвига только ключей разметки метки принадлежат другим отзывам. |
| R22 | adjust | отказ | Для всех последующих расчётов 3 октября ошибочно включено в «после». |
| R23 | adjust | отказ | Один отзыв выбранной точки отсутствует в обеих производных таблицах. |
| R24 | adjust | отказ | В каждом периоде доля модели выдана за долю синтетических жалоб. |
| R25 | adjust | отказ | Пропущен период до границы. |

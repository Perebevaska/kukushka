**Спорные исходные ожидания.** №44 «ошибка» и эталон дали 146 на одном файле. Extra0 подтверждает неразличимость ответа: зачёт не свидетельствует о дефекте этой проверки на этом входе. №228 присвоил метки по позиции, исходные файлы уже упорядочены по тем же ID. На них числа не позволяют различить алгоритмы. После перестановки только gold правильное соединение и позиционный ответ различаются (extra3/4), здесь важен именно такой повтор. Шесть изменённых программ Parsons проверили исполнитель вне набора строк интерфейса: их нельзя считать шестью воспроизводимыми ошибками ученика. У №98 отличие численно существует, это отдельный вопрос заявленной точности задания.

**Границы приёмки.** До повтора после изменений нельзя присвоить «исправлено» всем замечаниям по предложенному патчу. Нужны обе среды для исходного кода и отдельно для изменившихся контрактов, видимые карточки и блокнот, новые адресные попытки ученика, письмо по пересобранному брифу и независимое чтение этого письма. Ученик настоящего первичного прохода дал корректные расчёты и своё письмо. В нём отсутствовали оба численных знаменателя.

# Дополнение знаний после одной closure

- Публичное условие теперь прямо рекомендует matplotlib ax.bar вместо pandas bar для DatetimeIndex в браузере. Сам выбор точки/недели остаётся задачей ученика.
- График можно сделать читаемее, поставив ticks на фактические понедельники, форматируя их датами и поворачивая подписи. Это намерение моего кода; в этой попытке изображения не было.
- Реальный feedback имеет приоритет над ожиданием: хотя программа содержит weekly, проверка сообщила, что её нет. Причина неизвестна. Нельзя объявить программу принятой или описать не возвращённый PNG.
- Эта попытка относится к прежнему ID и не увеличивает 42 уникальные цели. Отдельный неудачный срез не переписывает прошлые принятые результаты.

Перечитал текущие README и weekly.md. Новый публичный пример явно показывает прямой matplotlib ax.bar и предупреждает о возможном ValueError pandas bar с DatetimeIndex. Это понятное уточнение: способ построения отделён от самостоятельного выбора точки. В своей программе рассчитываю weekly и месячный прирост из текущего n, выбираю focus_shop, затем использую опубликованный ax.bar. Добавил отдельные читаемые подписи всех понедельников и шкалу долей 0..1.

Фактическая реакция единственной попытки — false: «Не нашёл переменную weekly. Создайте её — имя должно совпадать точно». Почему вычисленное имя недоступно проверке, по публичному ответу определить нельзя; предположения о внутренней причине не делаю.

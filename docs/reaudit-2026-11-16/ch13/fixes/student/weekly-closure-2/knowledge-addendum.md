# Дополнение после принятой closure

- Тот же расчёт weekly может быть корректно показан прямым matplotlib ax.bar; фактические понедельники удобно явно задать ticks, повернуть даты и подписать доли0..1.
- Совпадение code перед двумя отправками и различие реальных реакций сохраняются раздельно. Нельзя исправлять старое событие задним числом.
- Причина первого false известна из диагностики координатора, не из моего исходного анализа: существовали редактор примера и редактор задачи. Повтор неизменённого решения после исправления автоматизации принят.
- Полученный график поддерживает выбор KZN-2 с5октября для дальнейшего разбора: доли повышены и в следующих неделях, объёмы сохранены. Он не устанавливает истинные жалобы или причину без независимых данных.
- Повтор existingID не создаёт новую уникальную цель. Исторические срезы, raw и показатели нужно сохранять с их отдельным происхождением.

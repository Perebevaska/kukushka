# Дополнение к собственной карточке знаний

- Все прежние знания сохранены; это адресный повтор знакомой главы.
- Порог выбираю на X_validation/y_validation. После фиксации отдельно получаю p_test по X_test и test_recall/test_flagged по y_test; одинаковая длина массивов не означает одинаковые ID.
- above_reference: неокруглённая нижняя граница ОДНОЙ accuracy выше константы. paired_lower: интервал средней ПАРНОЙ разницы правильности на общих текстах; это разные вопросы.
- У рейтинга, синтетической complaint и реальной обоснованной жалобы разные источники. Уверенность модели не раскрывает мотива гостя, копия topic в gold не становится независимой экспертизой.
- Постоянная поправка сохраняет знак прироста только при TPR>FPR. При TPR<FPR знак обратный; при равенстве доля не восстанавливается. Изменение версии классификатора требует общей шкалы и проверки ошибок обоих периодов.
- Пример поддержки:100/1000→140/1000 сигналов не доказывает рост истинных жалоб. При100истинных,TPR.8,FP20→60 получаются те же сигналы; операционное кадровое решение требует реальной нагрузки и цены другой очереди.
- Письмо должно сохранять обе даты, включение границы, числители и знаменатели всех отзывов, затем отдельные числители/знаменатели тем среди сигналов. Для KZN-2:162/440→222/372,доставка39/162→129/222.
- Каждая цитата подтверждает конкретную ситуацию, может нести несколько тем и не оценивает распространённость среди гостей. Пролитый кофе не равен доказанному опозданию.
- Учебный masked mean для rubert-tiny2 и авторский CLS — разные способы. Прежние результаты masked mean не являются результатами CLS. ±по каждой серии фолдов не заменяет парную оценку различий.
- Runtime-ошибка pandas-графика устранима прямым matplotlib; сохранённая ошибка не становится автоматически дефектом курса.
- Исторические outputs extra надо подписывать как прежнее исполнение; новое чтение prose не является новым inference.

# Собственные находки ученика

## CH13-ST01 — условие recall95 не перечисляет требуемые проверкой переменные

Опора: публичный 03-classify.md, task recall95, первая input и feedback. До отправки ожидал thr, precision_at, n_flagged, precision_05, recall_05 — именно они названы в задании. Реальная реакция: «Не нашёл переменную test_recall. Создайте её — имя должно совпадать точно». После добавления test_recall и test_precision следующая реакция потребовала test_flagged; после его добавления задача принята. Эти три имени отсутствуют в публичном условии. Подсказка 1 предлагает recall_score(y_test,p>=t), хотя видимая заготовка p=model.predict_proba(X_validation)[:,1]. Это риск смешать внутреннюю валидацию с тестом. Рекомендация: перечислить все результаты тестовой оценки и прямо указать, что порог выбирают только на внутренней валидации; синхронизировать подсказку. Это фактическая преграда сдачи, не гипотетическая эмоция ученика. Одна UI подсказка была использована после собственной попытки.

## CH13-ST02 — моя ошибка ключа при сравнении LLM

В llm-same выбрал r.drop(check.index), не проверив соответствие числового индекса ID. Feedback: acc_model=.825 вместо около .755 и явное указание исключать по review_id. Исправил на ~r.review_id.isin(check.review_id), принято без подсказки. Это ошибка моего решения; сообщение проверки помогло восстановиться. Полезный перенос из главы12: принадлежность строк по ключам важнее совпадения позиций.

## CH13-ST03 — гипотеза чтения цитат требует сохранить несколько тем

Независимый проект: выбранная тема доставки действительно присутствует в пяти верхних цитатах, но три содержат ещё кофе/обслуживание/еду. Поэтому рост доли основной темы доставки среди сигналов (.241→.581) не означает, что исчезли другие жалобы. В письме это только гипотеза для операционной проверки. Ограничение одной темы объяснено уроком, это усвоенное ограничение постановки, не дефект курса.

## CH13-ST04 — перенос старых рейтинговых меток не эквивалентен жалобам

Свой расчёт KZN-2 с5октября: модельные .3682/.5968, поправка старым тестом .378/.637; по синтетическим complaint .3659/.5968 и TPR/FPR1/.0036→1/0. Совпадение поправки с complaint на тех же строках — алгебра, не независимая проверка. Знак фиксированной линейной поправки не проверяет перенос. Новая независимая разметка обоих периодов нужна до переноса на живой поток. Это подтверждение полезной части урока.

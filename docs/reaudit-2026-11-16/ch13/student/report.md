## Самостоятельный проект

project-template.ipynb создан из публичного шаблона и действительно исполнен отдельным Python-процессом в чистом namespace, последовательно сверху вниз. Все 5 code-ячеек содержат stdout, реальный PNG присоединён к соответствующей ячейке. Это не nbclient/Jupyter PASS: попытка nbclient остановилась на запрете loopback bind; полный лог сохранён отдельно. Собственные начальные ошибки генератора и проблема сокета не приписываются курсу. Статическая публичная проверка --no-run сначала нашла отсутствие заключительного markdown после расчёта поправки; после добавления вывода результат 0 ошибок / 0 предупреждений. Это отдельная проверка оформления, не бизнес-эталон. Скрытый режим --project не вызывался.

Данные скопированы только из разрешённого публичного пакета. 2400 размеченных и 4800 новых отзывов; дублей ID и пропусков нет, одинаковые тексты сохранены. Обе модели — TF-IDF слов и биграмм + логистическая регрессия. Accuracy тональности 0.943 против most_frequent 0.538; тем 0.820 против 0.293, macro-F1 0.794. Контроль по полным группам текста: 592 отзыва, accuracy тональности 0.953, тем 0.816, macro-F1 0.794. У случайного теста тем повторяющиеся фразы дают macro-F1 1.000, новые 0.761: перенос на новые формулировки отдельно важен.

Самостоятельный выбор сделан по рассчитанному максимальному приросту между месяцами: KZN-2, 0.371 → 0.564, +19.3 п.п. Максимальный уровень октября — TMN-1 (0.609), это другой критерий. Недельный скачок KZN-2 — 5 октября, 0.347 → 0.596 при 89 отзывах в неделе скачка; последующие недели 0.620, 0.555, 0.643. График реально открыт. По выбранной границе до/после: 440 / 372 отзыва, модельные сигналы 162 / 222, то есть 36.8% / 59.7%. Доставка среди модельных сигналов выросла 24.1% → 58.1%; у остальных точек 18.1% → 16.3%. Знаменатели различаются и явно подписаны.

Сохранены own-scored.csv, own-monthly.csv, own-weekly.csv, own-quotes.csv, own-audit.csv и own-letter.md. Пять цитат связаны с исходными ID N-54090, N-53971, N-53673, N-54519, N-54719; все содержат проблемы доставки, несколько — также кофе, обслуживания или еды. Трасса N-54090 проходит через исходный текст, p_neg 0.9546, neg 1, тему доставки, неделю 19 октября и тот же ID в письме. Поэтому основная тема не исчерпывает отзыв, а письмо предлагает проверить операционные журналы, не объявляет причину доказанной.

Старый рейтинговый тест TPR 0.917 / FPR 0.034 даёт условные поправки 0.378 / 0.637. Новые синтетические complaint: 161/440 = 0.3659 и 222/372 = 0.5968; TPR/FPR 1/0.0036 и 1/0. Эти метки созданы генератором, это не работа живого аннотатора. Совпадение поправки с долей меток на тех же строках не проверяет будущую неделю. Единица — отзыв, уникальные гости и доля всех посетителей неизвестны. Творческий контрпример из поддержки домашнего интернета записан в creative-before.md до расчёта своего проекта.

## Дополнительные блокноты

Оба публичных extra прочитаны и все их code-ячейки реально исполнены с сохранёнными outputs. Изменены только пути DATA/CACHE в своих копиях, режим offline и число потоков. Исходная модель cointegrated/rubert-tiny2 сохранена; AutoTokenizer и AutoModel загружены парой с local_files_only=True, HF_HUB_OFFLINE=1, без скачивания или платного API. Использован разрешённый локальный кэш. OMP/OPENBLAS/MKL и torch intra/inter-op — по одному потоку, только одна вычислительная задача одновременно.

pymorphy3 2.0.6: 19257 токенов, 491 слово, 450 лемм, совпадение таблицы лемм 1.0, кэш 491 misses / 18766 hits; F1 слов, лемм и основ 0.940 ± 0.015. Реально проверены «чай матча» / «после матча»: обе поверхностные формы дают «матч», known=True; глобальная замена повредит спортивному контексту.

Transformer с torch 2.15.0 / transformers 5.23.0: все 2400 отзывов → E (2400, 312), нормы 1. Пулинг с маской против naive для короткого отзыва имеет косинус 0.925; alone/batch максимальная разница 5.96e-8. Общие пятифолдовые проверки: embeddings F1 0.930 ± 0.016, TF-IDF 0.940 ± 0.015. Все пять запросов поиска реально исполнены. «Курьер опоздал» находит «Доставка опоздала», «долго везли заказ» ведёт к перепутанному заказу, «не дорого» — к «Слишком дорого». Фактическая выдача подтверждает ограничение поиска. Второе чтение кэша проверено с encode_fn, который бы упал при cache miss; изменение fingerprint после правки текста тоже проверено.

Текстовые самостоятельные задания extra (CLS-сравнение, дополнительные варианты лемм, KMeans для 4800 новых отзывов и прочие пункты «Попробуйте сами») прочитаны, отдельно не исполнялись. word2vec/gensim, LM Studio и живой SDK API не запускались. Подготовленные LLM-ответы задач не выдаются за live API или независимую человеческую разметку.

## Обучаемость и рекомендации

Для такого ученика первое самостоятельное завершение главы качественно оцениваю как возможное. Аналогии с SQL, видимые формы матриц, словари исключений и поэтапный проект помогают связать действия с результатом. Существенная фактическая преграда — recall95: публичное условие не перечисляет требуемые test_recall/test_precision/test_flagged, а hint использует y_test при p от X_validation. Приоритет — синхронизировать условие, starter, hint и проверку, явно оставить выбор порога только на валидации. Полная цепочка доказательств в CH13-ST01.

llm-same показала мою ошибку связывания по индексу и полезную конкретную реакцию проверки: по review_id. Это не отдельный дефект курса. Точное копирование Parsons-строк было достаточным для восстановления транспорта. За исключением recall95 новых доказанных блокеров не обнаружил. Повторные тексты, качество одной темы, разница рейтинга и жалобы, пределы эмбеддингов и условность поправки разобраны в материале и действительно проявились в самостоятельных расчётах.

# Реально просмотренные изображения

Все 19 PNG открыты через view_image из публичного пакета. Наблюдения относятся к видимым схемам, не к одному alt-тексту.

| PNG | Что увидел и усвоил |
|---|---|
| text-pipeline | «не» и «но» сохранены зелёными, сомнительные леммы меню выделены жёлтым. |
| bag-order | Два разных порядка дают одну строку из четырёх единиц. |
| stem-vs-lemma | Красное «приве» склеивает чужие слова, жёлтый «привё» не склеивается с «приве»; леммы соединяют правильные формы. |
| sparse-matrix | Девять ненулевых клеток из 24 выписаны справа координатами и значениями. |
| ngram-window | Три слова и две пары, «не приду» выделена отдельно. |
| tfidf-steps | Счётчики → умножение на idf → единичная длина; в третьей строке вкусный 0.93 и кофе 0.36. |
| vec-fit-transform | Тестовое «остыл» за границами обученного словаря, без нового fit. |
| text-logreg-contrib | «но» имеет вклад +2.12, итог z=1.76 и P=0.85. |
| nb-toy | Сглаженные вероятности по двум классам и произведения .005/.030 ведут к классу 1. |
| kappa-toy | Восемь совпадений из десяти, случайное .68, каппа .375. |
| bow-vs-emb | Перпендикулярные словные столбцы слева и близкие направления латте/капучино справа. |
| embeddings | Кластеры напитков, доставки и оценочных слов в схематических двух измерениях. |
| mean-pool-search | Усреднение двух векторов запроса, нормировка, три сходства E@q; латте ближе всего. |
| lsa-shapes | 2400×485 → 2400×50 и components 50×485, около 71% разброса. |
| skipgram-window | Окно ±1 даёт шесть направленных настоящих пар; курьер/чизкейк показана случайной. |
| bert-pipeline | У латте UNK; короткая строка дополнена PAD, маска исключает их из пулинга. |
| masked-pool | Два истинных токена дают (2,2), вместе с двумя заполнителями — (1.25,0). |
| llm-label-flow | После JSON идут валидация меток и отдельный учёт неудачных ответов. |
| share-adjust | Из 1000 примеров видны 90 TP и 45 FP, наблюдаемые .135 превращаются поправкой в .10. |

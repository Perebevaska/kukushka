# Самостоятельный перенос до расчёта проекта

В домене поддержки домашнего интернета «не отключается» означает стабильную связь, а «не подключается» — сбой. Униграммы сохранят «не», но общий шаблон отрицания не задаёт тональность. Если после обновления интерфейса люди чаще пишут «не тормозит», постоянный FPR может не переноситься. Проверил бы контрастную пару и отдельно размеченные периоды до/после, сохранив знаменатель обращений, а не всех абонентов. Этот контрпример придумал до расчёта таблицы кофейни, готового образца для него не использовал.

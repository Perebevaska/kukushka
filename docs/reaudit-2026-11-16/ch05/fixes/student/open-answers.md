# Открытые ответы после исправлений

1. **Симуляция совпала с формулой независимых доставок.** Проверена согласованность двух вычислений внутри модели с заданными p и независимостью, в пределах симуляционного шума. Независимость реальных доставок этим не установлена: я сам заложил её в генератор. Для реальных доставок нужны наблюдения и проверка зависимости, например группировки по сменам и погоде.

2. **95%-й ДИ конкретной выборки руководителю.** «Среднее по выборке — 37.8 минуты; 95%-й доверительный интервал для среднего, рассчитанный t-методом, — 36.6…39.0 минуты». Числа здесь — иллюстрация формулировки. 95% описывает покрытие метода при повторных выборках при его предпосылках, а не вероятность фиксированного среднего в уже построенном интервале и не долю доставок внутри границ.

3. **Рост пуша с ДИ [0.52;3.56] п.п., полезный порог 2 п.п., отписки неизвестны.** Есть статистические основания для положительного прироста, но ещё не подтверждено, что он достигает полезного порога 2 п.п.: интервал допускает и 0.52. Полный запуск только по этим числам не обоснован. Запрошу отписки и знаменатели по назначенным группам за тот же период, проверю согласованный предел их ухудшения. Если логов нет или требуется уточнить прирост, согласую новый независимый этап с объёмом, метриками, пределами и датой анализа заранее; не буду продолжать текущий тест до удобного p. Порог полезности — бизнес-критерий; MDE — характеристика обнаружения эффекта с выбранной мощностью, эти числа могут различаться.

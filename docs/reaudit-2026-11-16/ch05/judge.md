# Слепое сравнение ответов по главе 5

**Выбираю A.** Оба ответа правильно решают, расширять ли новый срок доставки. Преимущество A проявляется в объяснении руководителю, что именно улучшилось. Доля опозданий снизилась среди оформленных заказов. Поскольку вариант назначали сессиям, изменение обещанного срока могло повлиять и на то, кто оформил заказ. A называет это возможным объяснением и ограничивает деловой вывод условиями эксперимента. B верно указывает знаменатель, но оставляет эту оговорку за рамками ответа.

| Проверка | Результат |
| --- | --- |
| Правило до округления | Оба варианта верны. При SRM p = 0,42 правило не останавливает эксперимент. Эффект −8,1 п.п. при p = 0,003 удовлетворяет условию по опозданиям. У X нижняя граница на 0,04 ₽ выше порога, значит, внедрять. У Y нижняя граница на 0,04 ₽ ниже порога, а верхняя выше, значит, решение неопределённо. Оба сохраняют исходные границы и применяют округление при отображении. |
| Единица назначения | Оба считают выручку по всем назначенным сессиям, включая нулевые. Для школы оба учитывают назначение по классам и зависимость результатов учеников внутри класса. A дополнительно указывает, что распределение по группам проверяют по плану назначения классов. |
| Защитная метрика | Оба допускают снижение выручки даже для X. A точнее объясняет, какой убыток исключает интервал при принятом уровне доверия. В Y данные совместимы как с приемлемым эффектом, так и с превышением лимита потерь. |
| Следующее действие | В обоих ответах видны отдельные решения по X и Y и условия пересмотра Y. Из B стоит взять явное указание на новый независимый эксперимент с заранее заданными сроком и размером. У A формулировка «новое измерение» оставляет открытым вопрос, будут ли повторно использованы прежние данные. |

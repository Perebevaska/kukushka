## Слепое сравнение двух выводов

Предметный эксперт и деловой критик получили один бриф. У X интервал выручки [−9,96; +7,84], у Y [−10,04; +7,76] ₽. Снижение опозданий значимо, SRM не даёт сигнала нарушения, δ=10 ₽ установлен до анализа. Оба автора верно получили «внедрять» для X и «неопределённо» для Y до округления. Судья выбрал **A**, поскольку ответ точнее ограничивает деловой вывод изменением состава заказавших и описывает независимую единицу при назначении по классам. Из B сохранена рекомендация заранее назначить срок и объём нового независимого этапа. Классовый пример вынесен в отдельный открытый вопрос проекта.

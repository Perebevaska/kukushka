# Новая программа для целых классов

До выбора теста определяю, что сравнивается: средний итоговый балл, изменение балла или доля достигших стандарта. H0 формулируется для выбранного параметра. Если программу назначают целым классам, единица рандомизации — **класс**. Ученики внутри класса связаны общими учителем, расписанием, взаимодействием и средой; один класс с 30 учениками не дает 30 независимых назначений.

Для понятного начального анализа сравню классовые средние (или среднее изменение балла на класс) между назначенными группами; независимые наблюдения — классы. Если цель — средний эффект на ученика, заранее задам веса классов и применю кластерный/многоуровневый анализ с неопределённостью на уровне классов. Большие классы иначе неявно изменят целевую совокупность. План мощности должен учитывать число классов и внутриклассовую корреляцию. При одном классе в каждой группе отделить эффект программы от эффекта класса/учителя нельзя.

Если программа назначалась без случайного распределения, само различие классовых средних не устанавливает причинный эффект: нужны исходный уровень и обоснование сопоставимости. Нельзя просто запустить обычный тест по ученикам, объявив их независимыми, даже при очень большом общем числе учеников.

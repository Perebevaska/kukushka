# Сверка прежних замечаний главы 7

Исходный SHA текущего прохода — `6a82748`. Первоначальные экспертные ID названы E7-01…06. Реестр содержит два S07, шесть E7 и шесть M07. Поздние T05/T06/M07 из приёмки 15 ноября приведены отдельно. Каждый требует решения независимого рецензента по текущей редакции.

| ID | Место и критерий приёмки |
|---|---|
| S07-01 | Вероятность леса — среднее вероятностей деревьев. Жёсткое голосование является частным случаем. Ранжирование и predict при p=0,5 различаются по правилу ничьей. |
| S07-02 | Проект grid: число договоров во всём фолде и среди выбранных лидов имеют разные знаменатели. Выбор AUC и охват при фиксированном бюджете обосновываются на общих фолдах. |
| E7-01 | RateBy: own-target не попадает в обучающий код через fit_transform, включая singleton и fallback. Новые категории кодируются только по доступному train. |
| E7-02 | profit/honest-t: выручка, маржинальный доход и стоимость бонуса названы в своих единицах. Изменение переменных затрат меняет порог. |
| E7-03 | Исследование исходов отделено от финальной временной партии. Метка созревает через 30 дней, признаки доступны к заданному моменту. Причина пропуска/медленного ответа требует отдельного доказательства. |
| E7-04 | Одинаковая мощность двух очередей задаётся целым k. Округлённая доля не уменьшает очередь. Веса классов могут изменить порядок рисков. |
| E7-05 | SD модели между фолдами не даёт проверки равенства моделей. Используются парные разницы; one-SE назван практической эвристикой. |
| E7-06 | Переданные объекты: порядок колонок, сырой Pipeline, полные CV-результаты, настоящий сохранённый файл модели и форма ROC/диагонали. |
| M07-01 | metric/final: одинаковый целый бюджет, ключи обеих очередей, последнее место при ничьей. |
| M07-02 | time/speed: связь скорости ответа и конверсии отделена от эффекта ускорения. |
| M07-03 | raw→Pipeline→predict: новая строка с сырой датой и ранее неизвестной категорией проходит без ручной предобработки. |
| M07-04 | cv-table: парность фолдов, заранее названная практически полезная разница, отсутствие вывода о равенстве по отдельным SD. |
| M07-05 | Порог и class_weight: recall при снижении порога не убывает, precision пересчитывается; веса могут менять ранжирование. |
| M07-06 | Проект: temporal split, зрелость меток, критерий выбора и будущее действие. Ретроспективная концентрация договоров отделена от эффекта сопровождения. |
| T05 и T06, 15 ноября | Принимаются полная и сокращённая ROC, ошибки существенных углов и внутренних точек диагонали отклоняются. Геометрически эквивалентные дополнительные точки не считаются ошибкой. |
| M07, 15 ноября | Из 750 заявок правило выбирает 166, пересчёт через округлённую долю давал 165. Критерий задаётся целым числом с одинаковым правилом ничьих. |
| Итоговый тест | Все 13 условий и 52 объяснения. В c4 различены безубыточность и строго положительная маржа; в c13 одинаковый бюджет на одних фактах. |

# Решение по главе 3

**Выбор — B с уточнением единицы.** По условию поле «факт» содержит сумму внесённых значений. Пустой набор записей даёт в этом поле 0. Достоверность полного квартального итога зависит от того, за сколько месяцев внесён факт. Пояснение можно дать в подписи к сводке, сохранив два столбца «план» и «факт».

Для независимой проверки я взял месячные значения в рублях, отбросил пропуски, посчитал оставшиеся записи и сложил их. Для каждого магазина предполагается одна запись на месяц.

| Факт по месяцам, ₽ | Месяцев с фактом | Поле «факт», ₽ | Что известно о полном квартале |
|---|---:|---:|---|
| пусто, пусто, пусто | 0 из 3 | 0 | Сумма неизвестна |
| 0, 0, 0 | 3 из 3 | 0 | Подтверждено 0 ₽ |
| 0, пусто, 17 | 2 из 3 | 17 | Сумма неизвестна |

Решающая проверка — первая строка. Вариант A заменяет предписанную числовую сумму словами «нет данных». Эти слова точны как пояснение о полном квартале. Вариант B сохраняет числовое значение и объясняет, почему оно совпадает у двух магазинов. В частичной строке оба текста дают верное толкование. Из A стоит взять правило считать месяцы с заполненным фактом, включая явные нули. Наличие плана ничего не говорит о заполнении факта.

В подписи B появляются тысячи рублей. Ноль одинаков в обеих шкалах, поэтому ошибку масштаба выявляет частичная строка. При входных 17 ₽ поле в рублях показывает 17 ₽, а поле в тысячах рублей — 0,017 тыс. ₽. Если исходные данные уже выражены в тысячах рублей, значение 17 означает 17 тыс. ₽. Подпись должна следовать единице таблицы.

Выбор изменится в пользу A, если по договорённости сумма пустого набора должна отображаться как пропуск. При текущем определении поля полный квартальный факт можно сообщить, когда подтверждены значения всех трёх месяцев.

# Выбор объяснения для главы 3

Ученик — SQL-аналитик, который осваивает pandas. В управленческой таблице pf полагаются два столбца: «план» и «факт», каждый отражает сумму внесённых денежных значений. Для одного магазина все три месяца квартала пусты, для второго три раза явно указан 0 ₽. Нужно краткое пояснение, как передать эти строки пользователю сводки. Определи, корректен ли текст при частичном заполнении и когда можно сообщить фактическую сумму за весь квартал. Не требуй дополнительных колонок в ответе этой карточки.

## A

Строка «сумма внесённых за квартал денежных сумм» отвечает на вопрос, сколько рублей внесено по доступным записям. Покажите рядом, за сколько месяцев записан факт. Если все три месяца пусты, охват равен 0 из 3, а сумму укажите как «нет данных». Если каждый месяц записан ноль, охват равен 3 из 3, а сумма — 0 ₽. При охвате 1 или 2 из 3 можно показать сумму по заполненным месяцам; полный итог квартала остаётся неизвестным. Подсчитывайте месяцы по заполненному факту, включая записанные нули. Значение плана не подтверждает наличие факта.

## B

В строке «сумма внесённых значений за квартал» обе точки получат 0 тыс. ₽. Для первой точки оставьте рядом «внесено 0 из 3 месяцев, итог за квартал неизвестен» и запросите замеры. Для второй запишите «внесено 3 из 3, во всех трёх месяцах указан 0»: квартальный ноль подтверждён. Если заполнена лишь часть месяцев, укажите их число и сумму внесённых значений. По ней нельзя подтвердить полный квартал.

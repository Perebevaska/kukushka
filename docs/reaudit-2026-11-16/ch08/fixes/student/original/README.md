## Автоматы

Вопрос: где обследовать 300 уникальных адресов и поставить 40 автоматов по 140 тыс.₽/год при риске убытка<=2.5%? Решение — Екатеринбург, средняя годовая маржа 1479 тыс.₽, интервал сценариев 803–2207 тыс.₽. Оценка доли убытков 0/1000, это не гарантия нулевого риска. Казань 523 тыс., риск 0.8%; Пермь 1149 тыс., риск 0/1000 — все проходят ограничение. Данные известного конечного реестра, сценарии без возвращения; неопределённость новых адресов и годовой эксплуатации в них не включена.

Файлы: sites-project.ipynb, sites-artifacts/risk.csv, chosen-sites.csv (конкретные 40ID), quality.csv, profile.csv, risk.png, summary.json. Лес — заранее предусмотренная проверка чувствительности, не независимый новый тест выбора модели.

## Абонемент «Зерно+»

Историческое решение на 2026-07-01: порог 0.22, 347 адресатов из 1987 кандидатов; мощность до 441 контакта, стоимость 52050₽. Ожидается 146.2 покупки, 36.7 изних органические; прогноз дополнительной маржи 123087₽ за 3 месяца. Всем кандидатам — около 6296₽, отказ 0₽. Это прогноз по калибровке и переносу контрольной доли, не уже заработанные деньги.

На независимой от выбора политики проверке: AUC0.8683, 70 контактов,40 отобранныхконтролей, оценка дополнительной маржи 29100₽. Условный bootstrap95% интервал маржи на контакт 193–633₽; он не включает подбор политики и будущий сдвиг. Треть контроля отложена до поиска порога; обучение/порог использовали оставшийся контроль и OOFtrain. Ограничение мощности 300/1350 и минимум 20 контролей определены до вычислений.

Среди адресатов 59.4%зарегистрировались через приложение, медианная давность 7.65 дня, частота 0.459 заказа/неделю;165 из 347 были в последние 7 дней. «Все недавно были» или «покупают по дороге на работу» из этого не следует. Возраст не в модели, аудит использует явно выбранные мной границы<30/30–49/50+; пропуски и 1900 вне групп.

## Входы и запуск

Исходные sites.csv и final1.db взять из учебной главы 8, поместить в каталог DATA. База не включена в этот учебный Git-репозиторий. В общей папке аудита данные хранятся один раз в ../technical/data-baseline относительно student. Для автономной передачи укажите COURSE_DATA — без переменной действует этот относительный путь.

```sh
python -m venv .venv
.venv/bin/pip install -r requirements.txt
COURSE_DATA=../technical/data-baseline OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 .venv/bin/python execute_notebooks.py
```

Запускать из папки student; COURSE_DATA может указывать на другой каталог. Все выходы относительны student. Вычисления последовательны, n_jobs=1. Внешней публикации и git push нет; локальный учебный репозиторий сохраняет блокноты и результаты. Нерешённые продолжения — ISSUES.md.

# Глава 14. Критерий делового решения до разбора чужих результатов

Срез `6adf0eb`, роль 6, Astra high. Источники критерия — введение, публичная постановка проекта и назначение роли. Ответы эксперта, ученика, исходы технических прогонов и прежние замечания на момент записи не открывались. Координатор сообщил о предварительном показе сводки вечерней точности предыдущим уроком. Эта часть порядка предъявления уже известна критику.

1. **Решение на следующую смену.** Управляющая выбирает, когда просить пекаря проверить конкретную ячейку. Единица наблюдения — пара `(time, slot)`, 12 ячеек, класс 0 означает пустоту. Для каждой ячейки отдельно выстроить сетку через 15 минут. Учитывать один сигнал на k-м наблюдаемом подряд пустом по модели кадре. Пропуск для одной ячейки прерывает подтверждение именно в ней, даже если остальные ячейки сфотографированы. По пропуску нельзя определить физическое состояние места или непрерывность реальной пустоты.
2. **Цена решения заранее.** По первому дню для каждого k из 1, 2, 3 сложить 120 ₽ за сигнал при занятой ячейке, 300 ₽ за каждый наблюдаемый истинный эпизод без сигнала, 30 ₽ за каждый сигнал после первого внутри того же истинного эпизода и 1 ₽ за каждую минуту до первого сигнала в обнаруженном эпизоде. Истинные эпизоды — последовательности соседних наблюдаемых пустых кадров одной ячейки. Начало ожидания — первый истинно пустой кадр. Для стоимости нужна сумма задержек, для интерпретации — средняя только по обнаруженным эпизодам. Если обнаруженных эпизодов нет, средняя не определена. Длинная серия прогнозов, начавшаяся ложным сигналом, может одновременно оставить следующий истинный эпизод без сигнала. Сопоставить все три стоимости, при равенстве выбрать меньший k. Это заданные цены исходов без объявленного лимита числа вызовов и без наблюдаемой выручки.
3. **Проверка переноса.** До ознакомления с результатами на другом дне сохранить нормировку, обучающий набор, параметры леса и k. Затем на всех ячейках применить один зафиксированный конвейер без подбора, сверить каждый сигнал, пропуски, ложные и повторные вызовы, суммарную и среднюю задержку. Для результата аудита различать воспроизведение арифметики известного дня и применение процедуры к впервые предъявленным кадрам. Указать, что известно о дне до фиксации. Одиночный синтетический день позволяет судить об этом прогоне. Для запуска на других сменах нужны наблюдения в рабочих условиях.
4. **Расписание.** По камере считать пустые пары время–ячейка, по 0,25 ячейко-часа за интервал; для утреннего среза использовать [11:00, 13:00). По ленте запаса и спроса сравнить три расписания при одних начальных остатках, спросе и правиле пополнения. Различать перенос имеющейся партии и добавление ещё одной. Для каждого указать утро, вторую часть смены [13:00, 17:00) и весь день [07:00, 22:00). Пограничный кадр в 22:00 не представляет интервал открытой смены. Изменённые ячейко-часы показывают эффект расписания в симуляции. Экономическая выгода требует цен, маржи, затрат, списаний, спроса и сопоставимых смен; содержимое одной ячейки также не определяет доступность товара в остальных.
5. **Другая область.** Для парковки ключ — время и конкретное место. Если отметки «свободно» наблюдались в 10:00 и 10:30 с отсутствующим 10:15, при k=2 уведомления в 10:30 нет. Ещё одно наблюдение в 10:45 может подтвердить начало новой серии. Различать пропуск наблюдения, пропущенный эпизод и задержку водителю в минутах. Новые цена ложного сообщения, цена пропуска, допустимое ожидание и шаг съёмки определяются задачей парковки. Число кадров, цены пекарни и решение о допекании не переносятся автоматически.

Будущий пересчёт работы ученика проводить по его сохранённым решениям и письму после фиксации. При проверке границы выбора менять ровно одну цену, остальные исходы сохранять.

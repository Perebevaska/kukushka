## Финальная проверка v2

Браузер получил опубликованные страницы с действующего статического HTTP-сервера 55585. Каждая разрешённая загрузка страницы, JS и CSS побайтно сверена с текущим сайтом. Сетевые обращения за Pyodide, API прогресса и к внешним адресам блокировались. Использованы пять временных профилей, включая отдельный профиль проверки прежних ответов. Во встроенных вопросах 05/c1 и 06/c2 прежняя неревизованная сдача не отвечала на отредактированный вопрос. После нового нажатия в хранилище остались старая и новая записи. Неизменённый встроенный 06/c1 восстановился.

PR15-02 и PR15-03 перепроверены на финальных страницах. Ученик нажал обе ссылки развилки 01. В 06 до единой попытки по карточкам через меню открывались бриф, комплект сдачи, критерии, ручной чек-лист, пример README, формат письма и вопрос про выездной сервис. Прямые ссылки в разделе сдачи открывают существующие шаблон, зависимости и checker. PR15-04, PR15-05 и PR15-06 сохраняют решения первой редакции. Перенос предъявляется в меню 06 как отдельный раздел. Его разбор открывается по желанию. Выбор места оставляет ученику свободу выполнить его после всей основной работы.

Остаток вне технической приёмки — проверить на человеческом потоке SQL-аналитиков фактическое время проекта и насколько легко ученики сами находят перенос после рабочего проекта. Для внешнего наблюдения пригодны время до выбора нужной ветки, первая самостоятельная записка по выездам и способность получателя повторить расчёт по README. Эти эмпирические оценки не измерялись браузерными нажатиями.

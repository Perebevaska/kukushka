## Как изменились итоговые тесты

В начале каждого теста ученик видит один открытый вопрос на перенос. После собственного ответа он раскрывает варианты. После выбора сайт показывает объяснения. Открытый ответ предназначен для самопроверки и не входит в балл. При возвращении на страницу восстанавливаются выбор и пояснения. В главе 2 результат основного пути по-прежнему считается по 18 вопросам, пять углублений учитываются отдельно. [Проверка в Chrome по главам](quiz-browser.jsonl)

Из 223 вопросов единственный самый длинный вариант был верным в **192**, теперь в **55**. На одном этом признаке раньше можно было гарантировать проходной балл 80% в 12 главах, теперь в **0 из 15**. Единственный самый короткий вариант верен в 28 из 223 вопросов, раньше — в четырёх. Сравнивали видимый текст вариантов без пояснений. Ничья по длине гарантированного выбора не даёт. [Исходный подсчёт](../review-results.txt) · [Сверка по финальному HTML](review/ch01.md)

Агент-студент получил **223/223** на перемешанных вариантах. По отдельным листам он перечитал 117 вопросов после второй редакции; вопрос 12 первой главы повторил ещё раз после последней правки. Для всех 15 глав есть собственный открытый ответ. В главе 1 первая запись на диск не удалась, и студент сохранил этот ответ после просмотра вариантов. В браузере воспроизведены все 223 выбора, восстановление ответов после перезагрузки и запуск чистой второй попытки в главе 2. Это прохождение одного агента. Предыдущая методическая оценка **4,36/5** относится к версии до правок. Новой оценки по пяти критериям в этом цикле не выставляли.

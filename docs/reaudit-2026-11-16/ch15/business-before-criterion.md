# Независимый критерий делового решения

Сформулирован по брифу, собственному расчёту и текущим учебным материалам до открытия исторических замечаний, ответов коллег и журнала ученика. Глава 15, 740b115. Для каждого результата уточняю, что знает принимающий решение человек в этот момент и что может сделать.

1. Руководитель B2B получает дату среза, квартал звонков, очередь с ID и порядком, фактическое число офисов при предоставленной ёмкости. Признаки, прогноз и параметры доступны до назначения. Июньские исходы допустимы после фиксации списка. На сентябрьском рабочем срезе исход четвёртого квартала неизвестен.
2. На одном и том же наборе офисов отделены рубли ожидаемой пользы от условной подстановки наблюдаемого ухода и от фактически пришедших денег. Обе основные политики ограничены одинаковым количеством слотов, показаны расходы, объём, бездействие и необязательный вариант вне бюджета. Для сравнения качества порядка берём одинаковое фактическое число первых офисов.
3. Удержание среди уходящих, маржа, годовой горизонт, постоянство месячной выручки и скидка всем контактам отражены явно. На том же списке меняем только s. При переотборе возвращаемся ко всем действующим офисам. Любое совпадение списков допустимо.
4. Из наблюдений об офисах, ответах API и задержках делаем только выводы в единицах измерения журнала. Проверка причин требует сравнения назначенных вмешательств. Владелец пилота и дата измерения названы. Суммы на три объекта можно независимо пересчитать по ID.

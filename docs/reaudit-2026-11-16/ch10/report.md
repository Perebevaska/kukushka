## Собственный проект, native и передача

Исходный проект ученика и первая передача сохранены без переписывания. Первая операция получателя — документированный reload сохранённой модели без fit. Для 1104 уникальных ключей «дата × кофейня» за июль–декабрь расхождение с plan равно нулю, SHA модели до/после совпал. Отдельно проверены другой период (552 строки), одна строка, обратный порядок, будущая мутация при reload, чистое ядро с refit и refit при будущей мутации — семь успешных проверок. Все 16 замороженных файлов сверены по SHA. [Первая квитанция](fixes/recipient-evidence/first-inputs-manifest.json) · [Порядок семи проверок](fixes/recipient-evidence/verification.json)

Стандартной библиотекой координатор независимо соединил исходный plan с публичными фактами по ключам: RMSE **8,672295629326**, MAE **6,335017907405**, bias «факт − прогноз» **−0,537929554353 тыс. ₽ на кофейню-день**. Первый комплект проверял иной период запроса при прежней июльской модели; произвольная новая дата обучения тогда CLI не предоставлялась. Этот предел первоначального доказательства сохранён.

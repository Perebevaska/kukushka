# Передача квартального/полугодового плана коллеге

Задача: выпуск утром 1 июля 2025 сразу на июль–декабрь, 6 кофеен. Единица выручки и прогноза — тыс. ₽ за день на кофейню. Моя конфигурация исключает погоду: архива прогноза на дату выпуска нет. Праздники и акции трактуются как утверждённый на выпуск план из учебного CSV; в реальной эксплуатации нужен его архив.

До финальной оценки зафиксированы 3 семейства: frozen_week, linear_interactions, trend_hgb. Выбор по неокруглённому RMSE апреля–июня после обучения до апреля. HGB: 200 итераций, глубина3, learning_rate .05, random_state11, ранняя остановка выключена, 1поток. Число итераций здесь фиксированное решение ученика, не подбор по тесту. Финальные процедуры обучаются до июля; победитель не переопределяется по второму полугодию.

Файлы: `data/daily_sales.csv` — вход обучения; `selection.json` — выбранное до финального теста решение; `metrics.csv` — качество и реальные длительности; `model.joblib` — обученная выбранная модель; `request.csv` — даты и доступные на выпуск признаки без целевой выручки/погоды; `plan.csv` — пакетный план; `versions.json` — среда; `project.ipynb` — выполненный из чистого ядра блокнот.

Из папки проекта: `python run.py` пересоздаёт отчёт и артефакты. `python run.py --predict request.csv --output recomputed.csv` пересчитывает план из сохранённой модели. Пути к данным определены относительно run.py; новый каталог Git не создаётся. Зависимости: numpy, pandas, scikit-learn, joblib; версии записаны в versions.json. Для блокнота также nbformat/nbclient/ipykernel.

Ориентир заморожен: для каждой кофейни и дня недели последняя известная касса июня, без обновления фактами июля. Линейная модель содержит фиксированные взаимодействия формата с выходным/праздником; trend_hgb прогнозирует экспоненциальный тренд и остаточную нормированную выручку. После reload проверяются совпадение пакета и одиночной строки. plan.csv предназначен для учебной передачи: неопределённость прогноза не оценивалась, два года одной сети не доказывают переносимость на другой бизнес.

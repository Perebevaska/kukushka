# Native extra и8упражнений

`native-extra.ipynb` — публичный учебный extra с моими выполненными outputs и8заранее выбранными упражнениями. `public-repeat.csv` и `exercises.csv` — результаты последнего контролируемого запуска. `native-extra-first-design.ipynb`/`exercises-first-design.csv` — сохранённый первый дизайн с другимиseed/patience/cap; не смешивать с итоговым сравнением. Failed-kernel/import и execution*.log сохраняют ошибки окружения. Отсутствие пакета не записано нулевой длительностью.

Блокнот ищет вход в `../project/data/daily_sales.csv`. Установлены Python3.12, numpy/pandas,scikit-learn1.8.0,CatBoost1.2.10,LightGBM4.7.0,nbformat,nbclient,ipykernel. Для переносимого запуска выберите ядро именно этого окружения; имя ядра на нашей машине былоku-student, путь интерпретатора временный и не часть данных. Restart Kernel and Run All выполняет всё сверху вниз. OMP_NUM_THREADS=1,OPENBLAS_NUM_THREADS=1,MKL_NUM_THREADS=1 выставляются перед запуском ядра; модели CatBoost/LightGBM также ограничены1потоком.

Упражнения: дваlr×две библиотеки(4),CatBoostсфлагами(1),снятиетренда×двебиблиотеки(2),LightGBM15листов/min_child_samples5(1). Контрольseed0/patience100/cap3000общий с публичным запуском. После экспериментов не выбирается другая модель собственного проекта по тесту. Время реальное на одном компьютере; строки содержат отдельный финальныйfit и подбор+финальныйfit. В публичной таблице predict — лучшее из5пакетных повторов, в моих упражнениях — один пакетный вызов; сравнивать абсолютные predict между этими двумя таблицами как одинаковую процедуру нельзя.

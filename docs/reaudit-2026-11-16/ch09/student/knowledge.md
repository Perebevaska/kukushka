# Моя карточка главы 9

## 01-vectors
Векторная строка обязана совпадать порядком с весами. Евклидова норма — корень суммы квадратов; L1 — сумма модулей. Косинус сравнивает направление, масштаб влияет на соседей.

## 02-matrices
Внутренние размеры совпадают, внешние дают форму результата. Клетка — строка на столбец; X.T@X собирает суммы, центрированная версия даёт ковариацию. Единицы превращают intercept в общий вес.

## 02b-vectorize
np.where заменяет условия по строкам; ветви вычисляются целиком. Сначала сверяю ответы, затем измеряю реальные повторные вызовы perf_counter. Нулевой таймер означает None, отношение не определено. Короткий цикл допустим вокруг векторизованного длинного.

## 03-normal-equation
Нормальное уравнение собирает все строки в систему по числу весов. Ранг проверяю до solve; флаги+единицы зависимы. Остатки МНК ортогональны столбцам. При зависимости lstsq даёт один минимум нормы, коэффициенты неоднозначны.

## 03b-own-model
fit сохраняет self.intercept_/coef_ и возвращает self; predict читает состояние конкретного объекта. RegressorMixin первым,BaseEstimator последним дают score/get_params и копирование. Правила бизнеса проверяются теми же фолдами.

## 04-transform
XP — новые столбцы-смеси. Обратимый P сохраняет достижимые МНК-прогнозы на обучении; явный перенос P^-1w сохраняет любой прогноз. Независимые fit на новых строках требуют единственности расширенной системы. Ridge штраф и геометрия kNN/деревьев чувствительны. Известные пары вскрывают P.

## 05-project
Один split и один ключ для train/test/новой анкеты. Сравнение R² до округления. Полный ранг и cond контролируют обратимость и численную точность; member_id исключён. Четыре независимые пары раскрывают4×4ключ, цель тоже персональная.

## Итог прохождения
Приняты 94 из 94 ID. Три отказа: реальный best_time в vectorize принят только после прямой записи таймера (одна подсказка про np.where); group-mean — после возврата y к Series вместо созданного мной ndarray (помощь 0). Точный внутренний контракт неизвестен, скрытый checker не читал.

Самостоятельный MyOLS через lstsq с intercept: train 3750 / test 1250, R² 0.371314 на исходных и скрытых данных, MAE 4.938463 тыс. ₽ против 6.184992 у среднего. P имеет ранг 4, cond 26.88453; расширенная X имеет ранг 5. Максимальная разница прогнозов 7.71e-13 тыс. ₽. Плохой ключ имеет ранг 3 и R² 0.333637. Атака из четырёх независимых пар раскрыла 100% профилей. Новая анкета дала 21.27 тыс. ₽, другой ключ — −2144.35.

Цель передаётся открыто. Смесь не криптография, отсутствие member_id не гарантирует обезличивание. Contractor-demo остаётся локальным; internal содержит ID, ключ, истинные метки и открытую новую анкету, этот каталог не предназначен подрядчику.

Два независимых fit сохраняют новые прогнозы при полном ранге [1,X], явный перенос весов сохраняет любой прогноз без этого условия. При аффинной смене единиц нужно согласованно перенести коэффициенты и intercept. Две температурные шкалы с константой линейно зависимы: согласованные физические строки сохраняют прогнозы, произвольные противоречивые строки находятся вне гарантии.

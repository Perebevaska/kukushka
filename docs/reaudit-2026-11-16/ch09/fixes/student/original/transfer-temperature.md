# Перенос: температура в двух шкалах

Если датчик отдаёт Цельсий и Фаренгейт, F = 1.8C + 32. Для обычной линейной регрессии со свободным членом прогноз b + wC можно выразить через F как (b − 32w/1.8) + (w/1.8)F. Поэтому для любого физически того же измерения предсказание сохранится: изменяются числа признака, коэффициент и базовый уровень, а итоговая величина — нет. Важно перевести новые строки той же формулой.

Если держать обе шкалы одновременно со столбцом единиц, появится точная линейная зависимость F − 1.8C − 32 = 0. Второй температурный столбец не добавляет информации. Разные наборы коэффициентов могут дать один и тот же минимум ошибки и одинаковые прогнозы на всех согласованных температурах. Но если искусственно подать C=0 и F=100, это не одна физическая температура: выбранные при двух fit решения могут предсказать разное. Обычный МНК не даёт содержательной гарантии для такой невозможной строки.

Для модели без свободного члена сдвиг32 уже нельзя всегда компенсировать. Для Ridge даже обратимая смена масштаба меняет штраф на веса, так что обещание одинакового результата после нового fit требует другой настройки штрафа. Сам перенос уже выбранных весов по формуле сохраняет предсказание, но не означает, что другое обучение выберет именно их.

# Открытый ответ до повторного чтения вариантов

Задача знакома по первому проходу; это проверка сохранённых знаний, а не новое независимое измерение обучения. Сантиметры — метры, умноженные на100. При метрах m и сантиметрах100m вклад двух колонок b+w1*m+w2*100m сворачивается в b+(w1+100w2)*m. Вторая колонка не добавляет независимого условия или новых линейных прогнозов на согласованных физических строках; минимальная ошибка обычного МНК та же. Пары весов неоднозначны, расширенная матрица с обеими записями теряет полный ранг. При переобучении решения минимальной нормы могут различаться на невозможной строке с несогласованными метрами/сантиметрами. Для Ridge изменение представления меняет штраф, поэтому гарантию обычного МНК автоматически не переношу.

CW до вариантов: Q1 — хочу объяснить, почему новый числовой столбец не даёт новых сведений о длине. Q2 — вопрос test-open и уже освоенная формула линейного вклада. Q3 — ожидаю сохранение наилучшей ошибки на согласованных строках и неоднозначность двух отдельных коэффициентов.

## Решение и независимость

Все 15 вопросов имеют один защитимый выбор среди данных вариантов. Мои выборы до ключа совпали с ключом: 15/15. Блокеров сдачи и двух одновременно правильных вариантов не обнаружено. Обнаружены две локальные неточности объяснений; они не меняют ключ и результат. Это оценка одного агента, а не наблюдение за человеком.

Порядок сохранён: сначала прочитан только файл с условиями без вариантов; ответы на вводный кейс и 15 вопросов записаны в [quiz-blind.md](quiz-blind.md). Затем открыт перемешанный ученический лист и сохранены выборы в [quiz-choices.md](quiz-choices.md). Только после этого открыты `content/ch01/test.md`, все пояснения и `site/ch01/test.html`, затем прежняя приёмка. Это не новая браузерная сдача: решение по обезличенному текстовому листу, сверка публикации по HTML и поведения результата по JS.

Вводный кейс решён до вариантов: 3 выдачи (`len`) и 5 книг (`sum`). Различены число строк и сумма значения. У Q9 в открытом ответе честно отделены связывание аргументов от неизвестного тела функции; у Q10 до вариантов перечислены правила, поскольку открытое условие не содержит сравниваемых строк.

## Локальная редактура

**Q02-P3.** Две трактовки слов «дробное число»: (а) школьная — число с ненулевой дробной частью; тогда 5.0 не является дробным по значению; (б) разговорная в курсе — число типа `float`; тогда авторская мысль верна. Исправление пояснения: «Обычное деление целых чисел `/` возвращает `float`, поэтому здесь Python печатает `5.0`, даже при делении нацело». Приёмка на другом примере: ученик предсказывает и вывод `print(12 / 3)`, и его тип, не утверждая наличие ненулевой дробной части.

**Q06-P3.** Две трактовки пояснения: (а) выражение обязано непосредственно вернуть `bool`; это неверно — `if 1:` выполняет ветвь; (б) Python проверяет истинность результата; это верно, но сейчас не так написано. Исправление: «После `if` требуется выражение: Python проверит истинность его значения. Обычное присваивание через `=` здесь недопустимо; для равенства используют `==`». Приёмка: ученик объясняет, почему `if revenue:` допустимо, а `if revenue = plan:` нет. Тема `:=` для этой правки не нужна.

Оба замечания касаются пояснений, не однозначности вариантов. Требования переделывать тест целиком нет. У Q12 можно дополнительно уточнить «затем повышает их на 10 % и округляет», но это редакционная точность, а не найденный блокер.

## Внешние признаки по опубликованному HTML

Использован видимый текст каждого варианта: HTML-сущности декодированы, код сохранён, пояснения `blockquote` и метки `[x]`/`[ ]` исключены, пробелы нормализованы. Длина — число Unicode-символов. Равные максимумы/минимумы не дают гарантированного выбора. Воспроизведение: `python3 docs/reaudit-2026-11-16/ch01/quiz-lengths.py`; подробный текст, длины и SHA256 HTML сохранены в [quiz-lengths.json](quiz-lengths.json).

| Признак | Сейчас | Baseline приёмки 15 ноября | До прежней редакции |
|---|---:|---:|---:|
| Верный — единственный самый длинный | 4/15 = 26,7 % (Q1, Q6, Q8, Q15) | 4/15 = 26,7 % | 7/15 = 46,7 % |
| Верный — единственный самый короткий | 1/15 = 6,7 % (Q4) | 1/15 = 6,7 % | 1/15 = 6,7 % |

Baseline — [независимая приёмка главы 1](../../course-improvements/reaudit/fixes/review/ch01.md); исторические цифры взяты оттуда, а текущие пересчитаны независимо. В JavaScript итог считается через `Math.round(100 * ok / qs.length)`, положительный уровень — от 80 %. Для 15 вопросов это 12 правильных ответов. Самый длинный вариант гарантирует только 4, самый короткий — 1: ни одна эвристика не достигает порога. Это подсчёт гарантированных попаданий по единственному экстремуму; он не означает, что дополнительные случайные догадки невозможны.

Порядок вариантов перемешивается `seededShuffle` в `site/assets/lesson.js`; позиции исходного HTML нельзя переносить в пользовательский экран. Исходная разметка содержит ключи и объяснения, которые JS превращает в интерактивные кнопки и скрывает до ответа; их не считали видимой подсказкой. В HTML варианты находятся в закрытом `details` после открытого вопроса. Отдельный вклад вводного кейса в балл отсутствует. Фактическая интерактивная скрытость в браузере в рамках этой роли заново не проверялась.

# Редактура и повторная проверка теста главы 1

16 ноября 2026. Разрешённая глава — 1. Основание: [рецензия](../review.md), E03, Q02 и Q06. Роль — редактор и критик теста (Sol medium). Изменены только `content/ch01/09b-style.md` и `content/ch01/test.md`; сайт и Jupyter не генерировались.

## Изменения

- **E03:** в таблице и объяснении указан предел PEP 8 — 79 символов. Отдельно названы 88 символов по умолчанию у Black и приоритет настроек проекта; для задания явно оставлены 79 и пример строки из 84 символов. Условие, чекер, подсказки и разобранный пример сохраняют тот же предел и способ переноса в скобках.
- **Q02:** пояснения верного ответа и дистрактора о запрете деления целых теперь называют тип `float`, а не обязательную ненулевую дробную часть. Значение 5.0 явно названо равным пяти.
- **Q06:** пояснения верного ответа и дистрактора об именах теперь описывают проверку истинности. `if revenue:` допустимо; для 0 ветка пропускается, для 1 выполняется. Для проверки равенства нужен `==`.

Различие лимитов сверено 16 ноября с [PEP 8](https://peps.python.org/pep-0008/#maximum-line-length) и [Black 26.10.1](https://black.readthedocs.io/en/stable/the_black_code_style/current_style.html#line-length). Других упоминаний диапазона 79–88 в редактируемом уроке не осталось.

По PEP 8 — не длиннее 79 символов.` Проверяется реальная граница длины, остальные требования сохранены.

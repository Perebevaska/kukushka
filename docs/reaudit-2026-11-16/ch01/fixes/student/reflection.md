## Объясняю своими словами

У Казани сейчас больше выручка: 538 × 198 = 106524, а у Перми 412 × 205 = 84460. Сравнивать нужно произведение, а не цену и не одни чашки. Если Пермь продаст 520 чашек по 205, получится 106600 — она обгонит Казань на 76 рублей.

При равном числе заказов обычное сравнение Python ставит Ёжевичный чай перед Американо. Это не привычный русский алфавит. Ключ (-частота, название) сначала поднимает частые напитки, а при равенстве сравнивает названия. До запуска записал тройку для четырёх равных: Ёжевичный чай, Американо, Бабл-ти.

Отчёт считает только принятые записи: сначала int от суммы как есть, потом первое читаемое вхождение ID. Средний чек — их суммарные деньги / их количество. Город и день выбираются по сумме денег, напитки — по количеству. Топ ограничен тремя, остальные заказы отдельно. Учтённую сумму нельзя назвать полной месячной выручкой, если есть нечитаемые суммы или конфликтующие записи. Журнал объясняет расхождение исходных строк и принятых заказов.

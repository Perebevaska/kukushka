::: quiz 01-vectors
Что такое скалярное произведение вектора количеств (чашек) на вектор цен?

- [x] Выручка: сумма произведений количества на цену по всем позициям
  > Скалярное произведение — «взвешенная сумма», та же операция, что прогноз линейной модели.
- [ ] Средняя цена
  > Среднюю цену получим, если ещё разделить на число чашек.
- [ ] Новый вектор
  > Результат — одно число.
- [ ] Расстояние между векторами
  > Расстояние считается иначе — через разности.
:::

::: quiz 01-vectors
Почему перед расчётом расстояний между гостями признаки масштабируют?

- [x] Иначе признак в больших единицах (рубли) задавит признак в маленьких (визиты)
  > Расстояние складывает разности; разница в 500 ₽ «весит» больше разницы в 5 визитов.
- [ ] Чтобы расстояние стало целым
  > Целым оно от этого не станет.
- [ ] Масштаб на расстояние не влияет
  > Влияет напрямую.
- [ ] Только для косинуса
  > Косинус как раз меньше страдает от масштаба целого вектора.
:::

::: quiz 01-vectors
Две кофейни продают капучино, латте и раф в пропорции 3 : 2 : 1, но одна продаёт в десять раз больше другой. Какая мера скажет, что «вкусы гостей» у них одинаковые?

- [x] Косинусное сходство: оно равно 1
  > Косинус сравнивает направление векторов, а не длину: умножение вектора на 10 направление не меняет.
- [ ] Евклидово расстояние: оно равно 0
  > Расстояние большое — один вектор в десять раз длиннее другого.
- [ ] Манхэттенское расстояние: оно равно 0
  > Манхэттенское расстояние тоже зависит от размера продаж, а не от пропорций.
- [ ] Скалярное произведение: оно равно 1
  > Скалярное произведение растёт вместе с объёмами продаж, к единице оно не привязано.
:::

::: quiz 01-vectors
Курьер едет по городу с прямоугольной сеткой улиц: 3 км на восток и 4 км на север. Какое расстояние честнее для оценки пути?

- [x] Манхэттенское: 3 + 4 = 7 км
  > По кварталам напрямую не проехать, путь — сумма модулей разностей по осям.
- [ ] Евклидово: 5 км
  > Это расстояние «по прямой», через дворы и дома.
- [ ] Косинусное сходство
  > Косинус сравнивает направления, а не длину пути.
- [ ] 12 км — произведение 3 · 4
  > Произведение разностей расстоянием не является.
:::

::: quiz 02-matrices
`X` — (100, 3), `W` — (3, 2). Какой формы будет `X @ W`?

- [x] (100, 2)
  > Внутренние размеры (3 и 3) совпадают и «съедаются», остаются внешние.
- [ ] (3, 3)
  > Это форма `W @ W.T`.
- [ ] (100, 3)
  > Число столбцов результата берётся от `W`.
- [ ] Ошибка
  > Формы стыкуются: 3 и 3.
:::

::: quiz 02-matrices
Что делает транспонирование `X.T`?

- [x] Меняет строки и столбцы местами
  > Форма (n, k) становится (k, n).
- [ ] Обращает матрицу
  > Обратная — `np.linalg.inv`.
- [ ] Сортирует строки
  > Порядок значений не меняется, меняется ориентация.
- [ ] Умножает на единичную матрицу
  > Умножение на единичную ничего не меняет.
:::

::: quiz 03b-own-model
Вы пишете свой класс `MyLinearRegression` с методами `fit` и `predict`. Что должен сделать `fit`, чтобы `predict` потом смог прогнозировать?

- [x] Сохранить выученное в атрибуты объекта (`self.coef_`, `self.intercept_`) и вернуть `self`
  > Атрибуты живут в объекте между вызовами методов, и `predict` их читает. `return self` позволяет писать `.fit(X, y).predict(X_new)`.
- [ ] Вернуть веса через `return w`, а `predict` найдёт их сам
  > `predict` не видит, что вернул `fit`. Он знает только сам объект (`self`) и его атрибуты.
- [ ] Записать веса в обычную переменную `coef_` внутри `fit`
  > Обычная переменная исчезает, как только `fit` заканчивает работу. `predict` упадёт с `AttributeError`.
- [ ] Ничего: `predict` сам решит нормальное уравнение
  > У `predict` нет ответов `y`, учиться ему не на чем. Его дело — применить выученное.
:::

::: quiz 02b-vectorize
Нужно посчитать сумму к оплате для 2 миллионов чеков. Какой вариант — скрытый цикл по строкам?

- [x] `df.apply(lambda r: r["amount"] * r["rate"], axis=1)`
  > `apply` с `axis=1` вызывает функцию Python для каждой строки отдельно — короче цикла, но так же медленно.
- [ ] `df["amount"] * df["rate"]`
  > Это векторная операция над столбцами: её считает numpy одним циклом на C.
- [ ] `np.where(df["amount"] > 500, df["amount"] * 0.9, df["amount"])`
  > `np.where` проверяет условие сразу для всего столбца — это векторизация, а не цикл.
- [ ] `X @ w`
  > Матричное умножение — одна операция numpy.
:::

::: quiz 02b-vectorize
Вы замерили цикл и векторный вариант по одному разу и получили ускорение «в 15 раз», а у коллеги — «в 70». Что сделать?

- [x] Повторить замер несколько раз и взять наименьшее время (или `%timeit`); заодно сверить ответы через `np.allclose`
  > Один замер шумит: первый вызов медленнее следующих, мешают другие программы. Наименьшее из повторов ближе к чистой скорости.
- [ ] Поверить первому замеру: он самый честный
  > Первый вызов как раз часто самый медленный — в нём есть подготовка.
- [ ] Взять среднее из двух чисел — 42.5 раза
  > Замеры на разных компьютерах и в разных условиях не усредняют; повторяют замер у себя.
- [ ] Значит, векторизация не работает
  > Работает: и 15, и 70 раз — порядок «десятки раз».
:::

::: quiz 02b-vectorize
Чем заменить в векторном коде `if km > 8: p += 100`?

- [x] `p = np.where(km > 8, p + 100, p)`
  > Условие проверяется для всего массива, и для каждой строки выбирается одно из двух значений.
- [ ] `if (km > 8).any(): p += 100`
  > Надбавку получат все доставки, если хоть одна дальняя.
- [ ] `p = p + 100 * km`
  > Это не условие, а надбавка за каждый километр.
- [ ] `if km > 8: p = p + 100` — numpy сам разберётся
  > `if` с массивом падает с ошибкой `The truth value of an array ... is ambiguous`.
:::

::: quiz 03b-own-model
Свою модель-правило «всем одно среднее» прогнали через `cross_val_score` рядом с линейной регрессией. Зачем это делают?

- [x] Чтобы честно сравнить модель с тем, как решают без неё, на тех же фолдах
  > Если модель не обыгрывает простое правило, она не нужна. На доставках: правило ошибается на 8.24 минуты, регрессия — на 5.91.
- [ ] Чтобы ускорить обучение регрессии
  > Правило на обучение регрессии не влияет.
- [ ] Потому что `cross_val_score` не работает без двух моделей
  > Работает и с одной.
- [ ] Чтобы заполнить пропуски средним
  > Это другая задача — `SimpleImputer`.
:::

::: quiz 03-normal-equation
Что значит «ошибки перпендикулярны признакам» для обученной линейной регрессии?

- [x] Остатки уже нельзя уменьшить, изменив веса: в них не осталось ничего, что линейно объясняется признаками
  > Это условие оптимума: Xᵀ · (y − Xw) = 0.
- [ ] Все ошибки равны нулю
  > Ошибки есть, но они «не похожи» на признаки.
- [ ] Признаки независимы
  > Это про остатки, а не про признаки.
- [ ] Модель переобучилась
  > Это свойство любого решения МНК.
:::

::: quiz 03-normal-equation
В таблицу попали и цена в рублях, и та же цена в тысячах рублей. Что случится с нормальным уравнением?

- [x] XᵀX станет вырожденной: столбцы линейно зависимы, единственных весов нет
  > Признаки, повторяющие друг друга, — мультиколлинеарность в крайней форме.
- [ ] Модель станет точнее
  > Новой информации нет.
- [ ] Ничего
  > Обратной матрицы не существует — решение не единственное.
- [ ] Веса станут нулевыми
  > Веса можно «перекладывать» между столбцами бесконечно многими способами.
:::

Признаки умножили на обратимую матрицу P. Что станет с качеством линейной регрессии и дерева?

  > Модель как раз не пострадает.

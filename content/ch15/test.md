::: quiz 01-artifact
Что такое «отпечаток данных» (хеш файла) в паспорте модели?

- [x] Короткая строка, по которой можно проверить, что модель обучена именно на этом файле
  > Если файл изменится хоть на байт, отпечаток будет другим.
- [ ] Копия данных внутри модели
  > Данные в модель не копируются.
- [ ] Пароль к данным
  > Это не защита, а проверка совпадения.
- [ ] Размер файла
  > Размер может совпасть и у разных файлов.
:::

::: quiz 01-artifact
Что должно быть в паспорте модели?

- [x] Версия, на каких данных обучена, метрики, порог, входные признаки и ограничения применения
  > Паспорт отвечает на вопрос «что это за модель и где ей можно верить».
- [ ] Только файл модели
  > Файл без описания ничего не говорит о модели.
- [ ] Только метрика качества
  > Без данных и признаков метрику не проверить.
- [ ] Пароль от сервера
  > Секреты в паспорт не кладут.
:::

::: quiz 02-service
Какой код ответа вернуть, если запрос пришёл не в формате JSON?

- [x] 400
  > 400 — запрос не разобрать; 422 — разобрали, но данные не прошли проверку.
- [ ] 422
  > 422 — для корректного JSON с неверными значениями.
- [ ] 500
  > 500 — ошибка самого сервиса.
- [ ] 200 с пустым ответом
  > Это скроет ошибку от клиента.
:::

::: quiz 02-service
Зачем в сервисе проверять `isinstance(x, bool)` отдельно от проверки числа?

- [x] В Python `True` — тоже целое число (1), и без отдельной проверки `"visits": true` прошёл бы как 1
  > Проверка типов должна ловить такие подмены.
- [ ] bool работает медленнее
  > Скорость тут ни при чём.
- [ ] JSON не поддерживает bool
  > Поддерживает: `true` и `false`.
- [ ] Так требует FastAPI
  > Проблема в самом Python, а не во фреймворке.
:::

::: quiz 02-service
Зачем пакетному обработчику запросов не падать на одной плохой записи?

- [x] Одна некорректная строка не должна лишать ответа остальные; ошибки возвращают построчно
  > Клиент видит, какие записи исправить.
- [ ] Чтобы скрыть ошибки
  > Ошибки возвращаются, просто не роняют всё.
- [ ] Так быстрее
  > Дело в надёжности.
- [ ] Пакеты всегда корректны
  > Не всегда — поэтому и защищаются.
:::

::: quiz 03-experiments
Что записывать в журнал эксперимента, чтобы его можно было повторить?

- [x] Версию данных, параметры модели, зерно случайности, версии библиотек и полученные метрики
  > Без любого из этих пунктов повторить результат может не получиться.
- [ ] Только итоговую метрику
  > По одной метрике запуск не повторить.
- [ ] Только код
  > Код без параметров и данных не даёт того же результата.
- [ ] Время запуска
  > Полезно, но недостаточно.
:::

::: quiz 03-experiments
Почему после 50 запусков с разными настройками лучшая валидационная метрика завышена?

- [x] Среди многих попыток какая-то выиграла частично за счёт удачи — это ловушка множественных попыток
  > Честная оценка — на отложенных данных, которые в выборе не участвовали.
- [ ] Метрика не может быть завышена
  > Может — из-за отбора лучшего.
- [ ] Из-за MLflow
  > Журнал ни при чём.
- [ ] Потому что запусков мало
  > Наоборот, проблема растёт с числом запусков.
:::

::: quiz 04-deploy
Зачем фиксировать точные версии библиотек (`scikit-learn==1.8.0`)?

- [x] Чтобы модель и код работали одинаково у вас, на сервере и через год
  > Новая версия может изменить поведение функций или формат файла модели.
- [ ] Чтобы установка была быстрее
  > Скорость тут ни при чём.
- [ ] Новые версии всегда хуже
  > Не хуже, но могут работать иначе.
- [ ] Без этого Python не запустится
  > Запустится, но результат может измениться.
:::

::: quiz 04-deploy
Что означает строка расписания cron `0 3 * * *`?

- [x] Каждый день в 03:00
  > Поля: минута, час, день месяца, месяц, день недели.
- [ ] Каждые 3 минуты
  > Это было бы `*/3 * * * *`.
- [ ] 3-го числа каждого месяца
  > Это `0 0 3 * *`.
- [ ] Каждые 3 часа
  > Это `0 */3 * * *`.
:::

::: quiz 05-project
Допустим, после обновления мобильного приложения в журнале сервиса резко выросла доля ответов 422 от него. С чего начать разбор?

- [x] Посмотреть тексты ошибок 422 в журнале: какие поля клиент присылает не так после изменений
  > 422 — данные не прошли проверку; ответ на вопрос «что именно» есть в журнале.
- [ ] Сразу откатить модель
  > Модель до этих запросов даже не доходит.
- [ ] Перезагрузить сервер
  > При 422 сервер работает правильно.
- [ ] Увеличить число серверов
  > Нагрузка тут ни при чём.
:::

::: quiz 01-inspect
С чего начинать работу с новой выгрузкой?

- [x] С осмотра: размер и типы, пропуски, варианты значений в текстовых столбцах, дубли
  > Сначала понять, что не так, — потом чистить и считать.
- [ ] Сразу строить графики
  > Графики на грязных данных покажут артефакты, а не закономерности.
- [ ] Удалить все строки с пропусками
  > Так можно потерять большую часть данных без причины.
- [ ] Переименовать столбцы по-русски
  > Это оформление, к качеству данных оно не относится.
:::

::: quiz 02-missing
Когда пропуск лучше оставить и добавить столбец-флаг, а не заполнять?

- [x] Когда сам факт пропуска что-то значит — например, гость не указал телефон
  > Флаг сохраняет информацию «не указано», а выдуманное значение её стирает.
- [ ] Никогда: пропуски всегда нужно заполнить
  > Заполнение выдумывает данные и может исказить расчёты.
- [ ] Когда пропусков меньше 1 %
  > Доля пропусков важна, но решает смысл пропуска.
- [ ] Когда столбец текстовый
  > Тип столбца не определяет стратегию.
:::

::: quiz 02-missing
В столбце `source` встречается текст «не указано». Как его считать?

- [x] Это замаскированный пропуск: его стоит превратить в `NaN` (например, через `na_values` при чтении)
  > Иначе `isna()` его не увидит, а «не указано» станет отдельным «источником» в отчёте.
- [ ] Как обычный источник привлечения
  > Это не источник, а отсутствие ответа.
- [ ] Удалить анкету целиком
  > Остальные поля анкеты могут быть в порядке.
- [ ] Заменить на самый частый источник
  > Это выдумывание данных.
:::

::: quiz 03-types
Почему кассовый CSV читают с `sep=";"` и `decimal=","`?

- [x] Касса пишет по-русски: значения разделены точкой с запятой, а дробная часть — запятой
  > Без этих параметров pandas прочитает всё одним столбцом или примет «125,5» за текст.
- [ ] Так быстрее
  > Дело в формате файла, а не в скорости.
- [ ] Так требует pandas для любых CSV
  > По умолчанию pandas ждёт запятую-разделитель и точку в дробях.
- [ ] Чтобы убрать дубли
  > Параметры чтения не убирают дубли.
:::

::: quiz 04-duplicates
Анкеты «C1023» и «c1023 » — один гость или два?

- [x] Один: после `strip()` и `upper()` номера совпадут — это неявный дубль
  > Неявные дубли находят только после нормализации ключа.
- [ ] Два: строки же разные
  > Разница только в регистре и пробеле — это одна карта.
- [ ] Нельзя сказать без телефона
  > Номер карты — ключ: после нормализации его достаточно.
- [ ] Один, но удалять нельзя
  > Его нужно свести к одной анкете, иначе гость посчитается дважды.
:::

::: quiz 05-strings
Как свести «г. Пермь», « пермь» и «Пермь» к одному виду?

- [x] Цепочкой: `strip` → `lower` → убрать «г.» → `strip` → `capitalize`
  > Каждый шаг снимает одну причину различий; порядок важен.
- [ ] `replace({"г. Пермь": "Пермь"})`
  > Так исправится одно написание, а остальные останутся.
- [ ] `upper()`
  > Регистр выровняется, но «г.» и пробелы останутся.
- [ ] Удалить редкие написания
  > Это потеря данных: те же гости из Перми.
:::

::: quiz 06-categories
Что делает `pd.cut(age, bins=[14, 25, 35], right=False)` со значением 25?

- [x] Относит его к интервалу [25, 35)
  > `right=False` — левая граница включена, правая нет.
- [ ] Относит к [14, 25)
  > Правая граница 25 при `right=False` не включена.
- [ ] Делает NaN
  > 25 попадает во второй интервал.
- [ ] Ошибка: граница не может совпадать со значением
  > Совпадение границы со значением — обычная ситуация.
:::

::: quiz 07-anomalies
Возраст гостя по анкете — 126 лет. Что это скорее всего?

- [x] Заглушка: дата рождения 1900-01-01, когда поле не заполнили
  > Невозможные значения часто — следы систем, а не настоящие данные.
- [ ] Самый старший гость сети
  > Правдоподобие — первый фильтр.
- [ ] Ошибка расчёта возраста
  > Расчёт верный, неверна исходная дата.
- [ ] Выброс, который надо оставить
  > Это не выброс, а невозможное значение — его превращают в пропуск.
:::

::: quiz 08-pipeline
Зачем оформлять очистку функцией `clean_clients(raw)`, а не держать в двадцати ячейках?

- [x] Её можно запустить на следующей выгрузке одной строкой и получить тот же результат
  > Функция — это повторяемость и одно место для исправлений.
- [ ] Функции работают быстрее ячеек
  > Скорость та же.
- [ ] Иначе pandas не позволит сохранить результат
  > Сохранить можно и без функции.
- [ ] Чтобы спрятать код от коллег
  > Наоборот: функцию проще прочитать и проверить.
:::

::: quiz 08-pipeline
Что записывают в журнал потерь при очистке?

- [x] Сколько строк осталось после каждого шага
  > Так сразу видно, если шаг неожиданно выкинул слишком много.
- [ ] Все удалённые строки целиком
  > Можно и так, но журнал — это прежде всего короткие цифры по шагам.
- [ ] Время выполнения каждого шага
  > Это про производительность, а не про данные.
- [ ] Названия всех столбцов
  > Названия не меняются от очистки строк.
:::

::: quiz 01-plots
Вы рисуете выручку по напиткам горизонтальными столбцами `ax.barh(s.index, s.values)` и хотите, чтобы самый продаваемый напиток был наверху. Как отсортировать `s`?

- [x] По возрастанию — `s.sort_values()`: у `barh` первый элемент рисуется внизу, последний — наверху
  > Ось Y идёт снизу вверх, поэтому для «лидер наверху» самый большой должен быть последним.
- [ ] По убыванию — `s.sort_values(ascending=False)`, как для вертикальных столбцов
  > Тогда лидер окажется внизу: у `barh` порядок снизу вверх.
- [ ] Никак: `barh` сам ставит самый длинный столбец наверх
  > `barh` рисует в том порядке, в каком переданы данные.
- [ ] По алфавиту, чтобы напиток было легко найти
  > Алфавит прячет главное — кто лидер; у напитков нет своего естественного порядка.
:::

::: quiz 02-histograms
Что значит «90-й процентиль времени доставки — 48 минут»?

- [x] 90 % доставок укладываются в 48 минут, 10 % — дольше
  > Квантиль — язык для бизнеса: «в девяти случаях из десяти».
- [ ] Среднее время — 48 минут
  > Среднее и квантиль — разные числа.
- [ ] 90 % доставок длятся ровно 48 минут
  > Квантиль — граница, а не значение для большинства.
- [ ] 10 % доставок опаздывают
  > Опоздание считают относительно обещания, а не квантиля.
:::

::: quiz 02b-shape
Условная кофейня в среднем делает 2 доставки в день, и в 13–14 % дней осени доставок не было вовсе. Управляющий считает, что это сбой выгрузки. Что ответить?

- [x] Это ожидаемо: для счётчика независимых событий со средним 2 формула Пуассона даёт $e^{-2} ≈ 13.5$ % пустых дней
  > Пустые дни — нормальная часть распределения Пуассона. Сбоем было бы, если бы пустых дней было, например, вдвое больше, чем ждёт формула.
- [ ] Да, это сбой: при среднем 2 пустых дней быть не может
  > Среднее 2 складывается и из дней с 4–5 доставками, и из пустых.
- [ ] Пустые дни надо выбросить, чтобы среднее было честным
  > Наоборот: без пустых дней среднее завысится. Их достраивают через `reindex(days, fill_value=0)`.
- [ ] Это значит, что распределение — колокол
  > Колокол получается у сумм многих вкладов, а не у счётчиков с маленьким средним.
:::

::: quiz 03-boxplots
Что показывает ящик на boxplot?

- [x] Середину данных: от первого до третьего квартиля, половину всех значений
  > Линия внутри — медиана, усы — до дальних значений без выбросов.
- [ ] Среднее плюс-минус стандартное отклонение
  > Ящик строится по квартилям, а не по среднему.
- [ ] Все значения без выбросов
  > Без выбросов — это ящик вместе с усами.
- [ ] Доверительный интервал
  > Ящик описывает данные, а не неопределённость оценки.
:::

::: quiz 03b-sigma
Коллега посчитал разброс времени по пяти доставкам курьера: в pandas `s.std()` вышло 4.39, в numpy `np.std(s)` — 3.93. Кто прав?

- [x] Оба: pandas по умолчанию делит на n − 1 (`ddof=1`), numpy — на n (`ddof=0`); на пяти значениях разница около 12 %
  > На маленьких группах `ddof` заметно меняет ответ, поэтому его пишут явно. На тысячах строк разница исчезает.
- [ ] pandas: numpy считает σ неправильно
  > Оба считают верно — по разным формулам.
- [ ] numpy: pandas выбрасывает выбросы
  > pandas ничего не выбрасывает; разница только в знаменателе.
- [ ] Никто: на пяти значениях σ посчитать нельзя
  > Посчитать можно, просто оценка будет неточной — и тем важнее указать `ddof`.
:::

::: quiz 04-slices
Почему при сравнении долей по группам рядом всегда показывают размер группы?

- [x] Доля в маленькой группе очень шумная: 3 опоздания из 5 — это 60 %, но цифра ненадёжна
  > Размер группы подсказывает, насколько верить проценту.
- [ ] Чтобы таблица выглядела солиднее
  > Это не оформление, а защита от ложных выводов.
- [ ] Размер нужен, чтобы посчитать долю
  > Долю можно посчитать и без вывода размера — но тогда не видно надёжности.
- [ ] Так требует groupby
  > groupby ничего такого не требует.
:::

::: quiz 05-time
Зачем скользящее среднее за 7 дней на дневном графике выручки?

- [x] Оно гасит недельный ритм и шум отдельных дней, и становится виден тренд
  > Окно в неделю содержит все дни недели ровно один раз.
- [ ] Оно делает прогноз на неделю вперёд
  > Скользящее среднее описывает прошлое, а не будущее.
- [ ] Чтобы убрать выходные
  > Выходные остаются в данных; их влияние усредняется.
- [ ] Окно может быть любым, 7 — случайный выбор
  > Для дневных данных с недельным ритмом 7 — осознанный выбор.
:::

::: quiz 05b-cohorts
Матрицу удержания построили 30 июня. У июньской когорты есть только месяц 0, ячейки месяцев 1–5 пустые. Менеджер пишет в отчёте: «Июньская когорта — худшая: удержание после первого месяца 0 %». Что не так?

- [x] Ячейки пустые, потому что эти месяцы для июньской когорты ещё не наступили: это «нет данных», а не ноль
  > Когорты сравнивают только по месяцам жизни, которые у всех уже прошли. Июньскую можно будет сравнить с остальными по месяцу 1 в конце июля.
- [ ] Всё верно: раз в июле заказов нет, удержание нулевое
  > Июля в выгрузке нет вообще. Отсутствие данных о будущем — не уход гостей.
- [ ] Нужно было делить не на размер когорты, а на число заказов
  > Знаменатель здесь ни при чём: проблема в том, что месяц ещё не наступил.
- [ ] Пустые ячейки надо заполнить средним удержанием других когорт
  > Так в отчёт попадёт выдуманная цифра. Пустые ячейки оставляют пустыми и подписывают.
:::

::: quiz 05c-dau-mau
В июне средний DAU предзаказов — 127 гостей, в месяце 30 дней. Аналитик пишет: «MAU июня — 127 × 30 = 3 810 гостей». Что не так?

- [x] Сумма DAU считает постоянного гостя по разу за каждый его день; MAU — разные гости за месяц, его считают по исходным заказам через `nunique`
  > Настоящий MAU июня — 874: гость, заказавший в 20 дней, в сумме DAU посчитан 20 раз.
- [ ] Нужно было умножать на число рабочих дней
  > Дело не в числе дней: сумма дневных счётчиков в принципе не равна числу разных гостей.
- [ ] Всё верно, так MAU и считают
  > Тогда sticky = DAU / MAU всегда был бы 1/30 и ничего бы не говорил.
- [ ] Надо брать максимальный DAU, а не средний
  > Максимум DAU — тоже гости одного дня, а не месяца.
:::

::: quiz 06-correlation
Корреляция Пирсона между расстоянием и временем доставки — 0.10, Спирмена — 0.41. Почему так?

- [x] Несколько аномально долгих доставок ломают Пирсона, а ранги к ним устойчивы
  > Пирсон чувствителен к выбросам; Спирмен смотрит только на порядок значений.
- [ ] Один из расчётов ошибочен
  > Оба верны: они по-разному реагируют на выбросы.
- [ ] Связи нет
  > Спирмен показывает заметную монотонную связь.
- [ ] Спирмен всегда больше Пирсона
  > Не всегда: это зависит от данных.
:::

::: quiz 06-correlation
Условный пример: по неделям корреляция между долей опозданий и средней оценкой гостей — −0.8. Можно ли написать в отчёте «опоздания снижают оценку»?

- [ ] Да: корреляция сильная, значит, это причина
  > Сильная корреляция не говорит, что из чего следует: оба ряда могут тянуть общие причины (погода, загрузка).
- [x] Пока нет: корреляция показывает только согласованность; нужно проверить на уровне доставок и исключить общие причины — например, сравнить оценки внутри одной погоды
  > Причину подтверждают срезом, где мешающий признак зафиксирован, а лучше — экспериментом.
- [ ] Нет: при −0.8 связи нет, потому что корреляция отрицательная
  > Знак показывает направление: чем больше опозданий, тем ниже оценка. Связь сильная.
- [ ] Да, если недель больше десяти
  > Число точек влияет на надёжность r, но не превращает связь в причину.
:::

::: quiz 07c-metrics
Аналитик говорит «средний чек — 370.9 ₽», маркетолог — «392.7 ₽». Данные одни и те же. Как это возможно?

- [x] Аналитик усреднил по заказам (частые гости весят больше), маркетолог — по гостям (каждый гость — один голос)
  > Оба верны, это разные средние. В отчёте пишут, чьё оно: «средний чек заказа» или «средний чек гостя».
- [ ] Один из них ошибся в коде
  > Обе цифры получаются из верного кода — вопрос в весах.
- [ ] Маркетолог посчитал выручку на гостя
  > Выручка на гостя за полгода — около 2 953 ₽, совсем другое число.
- [ ] У них разные периоды
  > Период один; различаются только веса.
:::

::: quiz 04-slices
В снег опаздывает 34 % доставок, в ясную погоду — 24 %. Но в снег чаще едут машины: 45 % снежных доставок против 27 % в ясную погоду. Что это значит для оценки влияния снега?

- [x] Разница в 10 пунктов занижает влияние снега: при составе курьеров как в ясную погоду в снег опаздывало бы около 40 %
  > Общая доля смешивает два эффекта: снег замедляет, а в снег чаще едут машины, которым он почти не мешает. Сравнивать нужно при одинаковом составе групп.
- [ ] Снег добавляет ровно 10 пунктов опозданий
  > Группы «снег» и «ясно» различаются составом курьеров, поэтому 10 пунктов — не чистый эффект снега.
- [ ] Влияние снега завышено: в снег опаздывают из-за машин
  > Наоборот: машины в снег опаздывают реже всех (около 7 %) и тянут общую долю вниз.
- [ ] Состав курьеров не важен, раз считаем долю, а не число опозданий
  > Доля по погоде — смесь долей разных курьеров, и в снег веса у этой смеси другие.
:::

::: quiz 08-eda
Как правильно записать вывод исследования?

- [x] Утверждение, цифра с размером группы и что из этого следует для бизнеса
  > «В снег опаздываем в 1.4 раза чаще, чем в ясную погоду (34 % против 24 %, 166 снежных доставок) — нужен запас во времени обещания» — понятно и проверяемо.
- [ ] Перечислить все построенные графики
  > Графики — материал, вывод — то, что из них следует.
- [ ] Только цифры, без интерпретации
  > Без «что это значит» руководитель не поймёт, что делать.
- [ ] Как можно осторожнее, без цифр
  > Без цифр вывод не проверить.

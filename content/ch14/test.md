**До выбора вариантов.** Модель проверяли на дневных фото, а новая камера снимает более тёмные кадры. Как собрать проверку устойчивости, сохранив независимость тестовых фотографий от обучения?

::: quiz 01-pixels
Цветная картинка 64 × 64 хранится как массив какой формы?

- [x] (64, 64, 3)
  > Каждый пиксель — три числа: красный, зелёный, синий.
- [ ] (64, 64)
  > Это чёрно-белая картинка.
- [ ] (3, 64)
  > Не хватает одного измерения.
- [ ] (4096,)
  > Так выглядит развёрнутая в строку серая картинка.
:::

::: quiz 01-pixels
Почему к пикселям в формате uint8 нельзя просто прибавить 50, чтобы сделать ярче?

- [x] Переполнение uint8 превратит светлые пиксели в тёмные
  > Сначала переводят uint8 в более широкий числовой тип, затем прибавляют 50 и ограничивают результат через np.clip. После переполнения в uint8 ограничивать уже поздно.
- [ ] Операция сложения запрещена для любого массива uint8
  > Можно, но с переполнением.
- [ ] Изменять яркость допустимо исключительно умножением
  > Прибавление тоже меняет яркость — с учётом переполнения.
- [ ] Сложение автоматически преобразует изображение в серое
  > Каналы останутся.
:::

::: quiz 01b-files
10 000 цветных кадров 1920 × 1080 на диске в JPEG занимают несколько гигабайт. Сколько памяти они займут после загрузки в numpy в `uint8`?

- [x] Около 62 ГБ
  > Поэтому кадры читают пакетами и сразу уменьшают, а не загружают все разом.
- [ ] Несколько ГБ, как JPEG на диске
  > numpy хранит каждое число отдельно; сжатие JPEG при чтении снимается.
- [ ] Около 6 ГБ
  > `uint8` — 1 байт на число без всякого сжатия; 6.2 МБ — это один кадр, а не 10 000.
- [ ] Около 250 ГБ
  > Столько займут кадры в `float32` (4 байта на число). В `uint8` — вчетверо меньше.
:::

::: quiz 01b-files
В каком формате хранить маски сегментации (0 — фон, 255 — выпечка)?

- [x] PNG: значения 0 и 255 сохраняются без потерь
  > JPEG на границах маски даёт промежуточные значения вроде 3 и 252, а для масок с номерами классов это порча разметки.
- [ ] JPEG: quality=95 сохраняет маски достаточно точно
  > Глазу незаметны, а числам — заметны: на границах появятся значения, которых в маске не было.
- [ ] Любой: перевод в float восстановит значения маски
  > Перевод в `float` не вернёт исходные 0 и 255 там, где JPEG их уже исказил.
- [ ] BMP: он всегда создаёт самые компактные маски
  > BMP хранит пиксели без сжатия — он, наоборот, самый большой.
:::

::: quiz 02-filters
Картинка 32 × 32, фильтр 5 × 5 без дополнения краёв. Какого размера выход свёртки?

- [x] 28 × 28
  > 32 − 5 + 1 = 28 по каждой стороне.
- [ ] 32 × 32
  > Так будет с дополнением краёв (padding).
- [ ] 27 × 27
  > Ошибка на единицу: 32 − 5 + 1 = 28.
- [ ] 5 × 5
  > Это размер фильтра.
:::

::: quiz 02-filters
Что делает фильтр размытия (все веса одинаковые)?

- [x] Усредняет соседние пиксели
  > Края при этом тоже становятся мягче.
- [ ] Выделяет границы объектов
  > Края выделяют фильтры с весами разных знаков.
- [ ] Увеличивает размер изображения
  > Свёртка без дополнения картинку уменьшает.
- [ ] Меняет цветовое пространство
  > Усредняющий фильтр сглаживает значения соседних пикселей, а не переводит изображение в другое цветовое пространство.
:::

::: quiz 03-classic
Модель на сырых пикселях хорошо работает на центрированных кадрах, но ошибается на сдвинутых. Что поможет?

- [x] Аугментация сдвигами и пулинг для устойчивости признаков
  > Показывая модели сдвинутые копии, мы учим её не обращать на них внимания.
- [ ] Увеличение числа деревьев без изменения данных
  > Они не научат модель новым положениям.
- [ ] Удаление всех сдвинутых кадров из проверки
  > В работе кадры всё равно будут сдвигаться.
- [ ] Сжатие каждого изображения до одного пикселя
  > Пропадёт вся информация.
:::

::: quiz 03-classic
Камера на конвейере распознаёт этикетки. При сдвиге вправо левый край кадра заполняется серым фоном. Какой тест лучше проверяет это условие?

- [x] Сдвинуть отложенные кадры, заполняя край серым
  > Это воспроизводит изменение камеры: ушедшая за правый край часть исчезает, а новый край имеет нужный фон.
- [ ] Циклически сдвинуть отложенные кадры через `np.roll`
  > Он вернёт ушедшие пиксели слева и создаст другое изображение.
- [ ] Проверить только исходные кадры без сдвигов
  > Такие кадры не проверяют заявленный сдвиг.
- [ ] Обучиться на сдвинутом тесте и оценить его же
  > Это перестанет быть независимой проверкой устойчивости.
:::

::: quiz 04-cnn
Почему у свёрточной сети меньше параметров, чем у полносвязной на той же картинке?

- [x] Веса одного локального фильтра общие для разных мест
  > Число весов фильтра не зависит от размера картинки.
- [ ] У свёрточных фильтров отсутствуют обучаемые веса
  > Учит — веса фильтров.
- [ ] В свёрточных слоях всегда отсутствуют смещения
  > Смещения есть.
- [ ] Вход ограничен только одноканальными изображениями
  > Работает и с цветными.
:::

::: quiz 04b-transfer
Что такое перенос обучения (transfer learning)?

- [x] Взять предобученную сеть и дообучить на своей задаче
  > Так хорошие признаки получают без миллионов своих примеров.
- [ ] Скопировать готовую модель на другой компьютер
  > Это развёртывание, а не перенос обучения.
- [ ] Дважды обучить одну архитектуру с нулевых весов
  > Смысл как раз в том, чтобы не учить с нуля.
- [ ] Скопировать исходный набор изображений из другой задачи
  > Переносят знания модели, а не данные.
:::

::: quiz 04b-transfer
Точность модели на 16 фиксированных случайных фильтрах: 50 фото на класс — 0.908, 100 — 0.922, 200 — 0.940. Фотограф предлагает доснять ещё по 1000 фото на класс. Что разумно ответить?

- [x] Проверить небольшую новую партию и стоимость прироста
  > Кривая описывает измеренный диапазон. Эффект следующей тысячи и окупаемость съёмки ещё не измерены; пилот позволяет пересмотреть решение.
- [ ] Заказать всю съёмку: прирост точности будет пропорционален
  > Прирост от новых данных убывает: на полке каждая следующая сотня фото даёт всё меньше.
- [ ] Сократить набор до 50: вся разница несущественна
  > 3 пункта — заметная разница, а уже собранные фото ничего не стоят.
- [ ] Сначала обучить ResNet с нуля: иначе оценить пользу нельзя
  > С нуля сеть учат как раз тогда, когда данных очень много, — это противоположная ситуация.
:::

::: quiz 04-cnn
Что такое рецептивное поле нейрона глубокого слоя?

- [x] Область исходного изображения, которая влияет на нейрон
  > Поэтому глубокие слои «видят» крупные формы, а первые — края.
- [ ] Размер фильтра только первого свёрточного слоя
  > Это только начало: поле растёт с глубиной.
- [ ] Количество всех нейронов текущего скрытого слоя
  > Это ширина слоя.
- [ ] Полный размер картинки независимо от архитектуры
  > Только у самых глубоких слоёв поле может охватить всю картинку.
:::

::: quiz 04c-detection
Настоящая рамка (0, 0, 10, 10), рамка модели (5, 0, 15, 10) — сдвинута на половину ширины. Засчитают ли её при обычном пороге IoU ≥ 0.5?

- [x] Нет: IoU = 50 / 150 = 1/3
  > Объединение растёт за счёт обеих «лишних» половин, поэтому IoU падает быстрее, чем кажется на глаз.
- [ ] Да: IoU = 50 / 100 = 0.5
  > Половина площади общая, но делят не на площадь одной рамки, а на объединение — 150.
- [ ] Да: IoU = 100 / 100 = 1
  > IoU смотрит на положение, а не только на размер.
- [ ] Нельзя решить без уверенности детектора
  > Уверенность влияет на порядок сопоставления, а IoU считается только по координатам.
:::

::: quiz 04c-detection
Детектор нарисовал на одном круассане две рамки, обе с IoU > 0.5 с настоящей рамкой. Как их засчитают?

- [x] Одна верная детекция и одна лишняя ложная тревога
  > Иначе детектор, рисующий по три рамки на объект, выглядел бы лучше честного. Такие дубли убирает NMS.
- [ ] Два попадания, так как обе рамки достаточно точны
  > Тогда полнота могла бы стать больше 1, а дубли поощрялись бы.
- [ ] Два ложных срабатывания из-за неверного числа рамок
  > Более уверенная рамка нашла круассан — это попадание.
- [ ] Ни одного, пока координаты рамок не усреднены
  > Рамки не усредняют: их сопоставляют по убыванию уверенности.
:::

::: quiz 05-project
Модель, обученная на дневных кадрах, вечером путает пустые ячейки с полными. Что разумно сделать?

- [x] Нормировка яркости и обучение на вечерних условиях
  > Модель должна видеть условия, в которых будет работать.
- [ ] Отключение оповещений на всех вечерних кадрах
  > Проблема останется — просто её не будет видно.
- [ ] Повышение порога уверенности до значения 0.99
  > Модель будет молчать, но ошибаться не перестанет.
- [ ] Установка второй камеры без изменения модели
  > Это дорого и не устраняет причину.
:::

## Логика суда

Проверка гипотез устроена как суд с презумпцией невиновности:

- **H₀, нулевая гипотеза** — «подсудимый невиновен»: эффекта нет, разница между группами — случайность;
- **H₁, альтернатива** — «виновен»: эффект есть;
- **доказательства** — данные. Если они очень плохо совместимы с невиновностью — выносим «виновен», то есть **отвергаем H₀**. Если доказательств недостаточно — оправдываем, но это не значит, что подсудимый точно невиновен.

Для TMN-1 и PRM-1:

- H₀: настоящая доля опозданий у кофеен одинаковая, разница в данных — случайность;
- H₁: доли различаются.

## Перестановочный тест

Если H₀ верна и кофейня ни на что не влияет, то метка «TMN-1» или «PRM-1» у доставки — просто ярлык. Перемешаем ярлыки случайно и посчитаем разницу долей. Повторим тысячи раз — получим, какие разницы рождает **чистая случайность**. Останется сравнить с ними настоящую разницу.

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

d = pd.read_csv("deliveries.csv")
ok = d[d["actual_min"].between(1, 299)]
x = ok[ok["shop_id"].isin(["TMN-1", "PRM-1"])]
late = (x["actual_min"] > x["promised_min"]).to_numpy()
is_tmn = (x["shop_id"] == "TMN-1").to_numpy()

observed = late[is_tmn].mean() - late[~is_tmn].mean()

rng = np.random.default_rng(0)
diffs = []
for _ in range(5000):
    shuffled = rng.permutation(is_tmn)          # перемешали ярлыки
    diffs.append(late[shuffled].mean() - late[~shuffled].mean())
diffs = np.array(diffs)

p_value = (np.abs(diffs) >= abs(observed)).mean()
print(f"наблюдаемая разница {observed * 100:.1f} п.п., p-value = {p_value:.3f}")

fig, ax = plt.subplots(figsize=(8, 3.5))
ax.hist(diffs * 100, bins=40, color="lightgray")
ax.axvline(observed * 100, color="tab:red")
ax.axvline(-observed * 100, color="tab:red", linestyle="--")
ax.set_xlabel("разница долей при перемешанных ярлыках, п.п.")
ax.set_title("Что даёт случайность")
```

- `rng.permutation(is_tmn)` — тот же массив в случайном порядке: число «TMN» сохраняется, но достаются они случайным доставкам;
- гистограмма — разницы, которые случаются, когда кофейня ни при чём;
- красная линия — наша разница. Пунктир — такая же по модулю в другую сторону.

### Разберём вместе: перестановочный тест на шести доставках

Три доставки кофейни A: опоздали две (1, 1, 0). Три доставки кофейни B: ни одного опоздания (0, 0, 0). Разница долей — 2/3 − 0 = **0.67**. Неужели A так плоха?

Если кофейня ни на что не влияет, ярлыки «A» и «B» можно раздать шести доставкам как угодно. Способов выбрать, какие три доставки назовутся «A», — 20. Переберём их по тому, сколько опозданий попало в «A»:

- оба опоздания в «A» — 4 способа (третья доставка — любая из четырёх вовремя): разница **+0.67**;
- одно опоздание в «A», одно в «B» — 12 способов: разница **0**;
- оба опоздания в «B» — 4 способа: разница **−0.67**.

Разница по модулю не меньше наблюдаемой (0.67) получается в 4 + 4 = 8 случаях из 20. p-value = 8 / 20 = **0.4**.

::: figure perm-toy
Слева — то, что наблюдали: две опоздавшие доставки из трёх у A и ни одной у B. Справа — разница долей при всех 20 раскладах ярлыков. Красные расклады не менее крайние, чем наш: их 8 из 20, p-value = 0.4.
:::

Что получилось: «две из трёх против ноля из трёх» звучит как большая разница, но при полной одинаковости кофеен такое случается в 40 % раскладов. Перемешивание в коде делает то же самое, только для сотен доставок, где все расклады не перебрать, — и поэтому берёт тысячи случайных.

```python
import numpy as np
from itertools import combinations
late = np.array([1, 1, 0, 0, 0, 0])
observed = 2 / 3
diffs = []
for a_idx in combinations(range(6), 3):
    is_a = np.isin(np.arange(6), a_idx)
    diffs.append(late[is_a].mean() - late[~is_a].mean())
diffs = np.array(diffs)
print(len(diffs), (np.abs(diffs) >= observed - 1e-9).mean())
```

- `combinations(range(6), 3)` — все 20 способов выбрать три номера из шести: это и есть 20 раскладов ярлыка «A».
- `np.isin(np.arange(6), a_idx)` — маска «попал ли номер в выбранные»: `True` у доставок, названных «A».
- `- 1e-9` — запас на округление: 2/3, посчитанная двумя способами, может отличаться в последнем знаке.

## Что такое p-value

**p-value** — доля перемешиваний, в которых случайная разница оказалась **не меньше** наблюдаемой по модулю. Точнее: вероятность увидеть такую или ещё большую разницу, **если H₀ верна**.

Здесь p ≈ 0.18: случайность сама даёт такую разницу почти в каждом пятом перемешивании. Данные **вполне совместимы** с тем, что кофейни работают одинаково. Отвергнуть H₀ мы не можем.

Сравните с KZN-2 и KZN-1 — разница около 11 п.п.:

```python
import numpy as np
import pandas as pd

d = pd.read_csv("deliveries.csv")
ok = d[d["actual_min"].between(1, 299)]
x = ok[ok["shop_id"].isin(["KZN-2", "KZN-1"])]
late = (x["actual_min"] > x["promised_min"]).to_numpy()
grp = (x["shop_id"] == "KZN-2").to_numpy()
observed = late[grp].mean() - late[~grp].mean()

rng = np.random.default_rng(0)
diffs = np.array([late[p].mean() - late[~p].mean() for p in (rng.permutation(grp) for _ in range(5000))])
print(f"разница {observed * 100:.1f} п.п., p-value = {(np.abs(diffs) >= abs(observed)).mean():.4f}")
```

p ≈ 0.002: случайность почти никогда не даёт такой разницы. (Если ни одно из 5 000 перемешиваний не дало разницы не меньше наблюдаемой, симуляция выдаст p = 0. Это не «невозможно», а «меньше 1/5000» — так и пишут в отчёте: p < 0.0002.) Значит, H₀ плохо объясняет данные — отвергаем её: KZN-2 действительно опаздывает чаще.

::: warn
p-value — **не** вероятность того, что H₀ верна, и не вероятность «случайности». Это вероятность данных (таких или ещё более крайних) при условии H₀. Почему нельзя сказать «с вероятностью 99.8 % эффект есть»: чтобы говорить о вероятности самой гипотезы, нужно знать, насколько она была правдоподобна **до** данных — а этого тест не знает и не учитывает. Он отвечает только на вопрос «насколько удивительны данные, если эффекта нет». Отсюда правильная формулировка: «если бы эффекта не было, такая разница встречалась бы в 0.2 % случаев».
:::

::: figure p-value
Схема: колокол — разницы между группами, которые получаются при случайном перемешивании меток. Красные хвосты — доля таких же или более крайних разниц, это и есть p-value.
:::

::: quiz
Тест дал p-value = 0.03. Что это значит?

- [x] Если бы эффекта не было, разница не меньше наблюдаемой получалась бы случайно примерно в 3 % случаев
  > p-value считают в мире, где верна нулевая гипотеза. Это мера того, насколько данные удивительны для этого мира.
- [ ] С вероятностью 97 % эффект существует
  > p-value — не вероятность гипотезы. Он отвечает на вопрос о данных при условии H₀, а не наоборот.
- [ ] Эффект равен 3 %
  > Размер эффекта считают отдельно. Маленький p бывает и у крошечного эффекта на больших данных.
- [ ] С вероятностью 3 % мы ошиблись в расчётах
  > p-value не про ошибки в коде: он описывает случайность данных.
:::

## Порог значимости α

Где граница между «маленьким» и «большим» p? Её выбирают **заранее** и называют уровнем значимости α. Общепринятое значение — 0.05:

- p < 0.05 — «статистически значимо»: отвергаем H₀;
- p ≥ 0.05 — «не значимо»: не отвергаем H₀.

::: predict
```python static
def decision(p, alpha=0.05):
    return "отвергаем H0" if p < alpha else "не отвергаем H0"

print(decision(0.03), "|", decision(0.18))
```

- `не отвергаем H0 | отвергаем H0`
- [x] `отвергаем H0 | не отвергаем H0`
- `отвергаем H0 | отвергаем H0`

Почему: 0.03 меньше порога 0.05 — данные плохо совместимы с H₀. 0.18 больше порога — оснований отвергнуть H₀ нет.
:::

Порог 0.05 — договорённость, а не закон природы. В медицине берут строже (0.01 и меньше), в быстрых продуктовых экспериментах иногда мягче (0.1). Главное — выбрать порог **до** того, как посмотрели на p.

## «Не отвергли» ≠ «доказали отсутствие»

Для TMN-1 и PRM-1 мы не отвергли H₀. Значит ли это, что кофейни работают одинаково? Нет. Это значит, что **данных недостаточно**, чтобы увидеть разницу. Возможно, она есть, но маленькая, а доставок мало.

В суде так же: оправдательный приговор за недостатком улик не доказывает невиновность.

## Быстрая формула: z-тест для двух долей

Перемешивание — честный и понятный способ, но на тысячах гостей и тысячах повторов он медленный. Для долей есть готовая формула, которая отвечает на тот же вопрос, — **z-тест для двух долей**. Она понадобится в задачах этого урока, в A/B-тестах и в проекте, поэтому разберём её руками.

Две кофейни: в A опоздали 72 доставки из 300 (24 %), в B — 90 из 300 (30 %). Разница 6 п.п. — это эффект или случайность?

1. **Общая доля при H₀.** Если кофейни одинаковые, обе группы — один поток с общей долей: (72 + 90) / 600 = **0.27**. Её обозначают `p_pool` (*pooled* — объединённая).
2. **Стандартная ошибка разницы при H₀.** Как в уроке «Доверительные интервалы»: SE разницы долей — корень из суммы двух дисперсий. Только при H₀ доля у обеих групп одна — 0.27: √(0.27 × 0.73 × (1/300 + 1/300)) ≈ **0.036**, то есть 3.6 п.п. При равных группах `1/n + 1/n` превращается в `2 / n`.
3. **z — разница в единицах этой ошибки:** 0.06 / 0.036 ≈ **1.66**. Разница чуть больше полутора стандартных ошибок.
4. **p-value.** По ЦПТ при H₀ разница ложится колоколом, а z — на стандартный колокол (среднее 0, σ = 1). `stats.norm.sf(1.66)` — доля колокола правее 1.66, около 0.049. Нас интересует разница **в любую сторону**, поэтому хвостов два: p = 2 × 0.049 ≈ **0.098**.

```python
import numpy as np
from scipy import stats
xa, na, xb, nb = 72, 300, 90, 300
p_pool = (xa + xb) / (na + nb)
se = np.sqrt(p_pool * (1 - p_pool) * (1 / na + 1 / nb))
z = (xb / nb - xa / na) / se
print(round(p_pool, 2), round(se, 4), round(z, 2), round(2 * stats.norm.sf(abs(z)), 3))
```

Что получилось: 6 п.п. на 300 доставках — p ≈ 0.1, H₀ не отвергаем. Логика та же, что у перемешивания: «как часто случайность даёт такую разницу». Разница только в том, откуда берётся распределение разниц при H₀: перемешивание его симулирует, а формула берёт готовый колокол. На больших выборках ответы почти совпадают.

## Две ошибки

| | H₀ на самом деле верна | H₀ на самом деле неверна |
|---|---|---|
| **Отвергли H₀** | Ошибка I рода (ложная тревога) | Верно — нашли эффект |
| **Не отвергли H₀** | Верно | Ошибка II рода (пропустили эффект) |

- Вероятность **ошибки I рода** равна α: при α = 0.05 в 5 % случаев, когда эффекта нет, мы всё равно его «найдём».
- Вероятность ошибки II рода обозначают β. Вероятность найти эффект, когда он есть, — **мощность** теста: мощность = 1 − β. Она растёт с размером выборки и с размером эффекта.

::: figure alpha-beta
Условная схема: серый колокол — разницы, которые даёт случайность при верной H₀, синий — при настоящем эффекте. Правее порога отвергаем H₀: красное — ложная тревога (α), жёлтое — пропуск эффекта (β), зелёное — мощность.
:::

Проверим первое утверждение симуляцией: много раз сравним две группы, у которых **одинаковая** доля опозданий 0.24, и посмотрим, как часто тест «находит» разницу:

```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(1)
n = 300
false_alarms = 0
for _ in range(2000):
    a = rng.random(n) < 0.24
    b = rng.random(n) < 0.24
    p_pool = (a.sum() + b.sum()) / (2 * n)
    se = np.sqrt(p_pool * (1 - p_pool) * 2 / n)
    z = (a.mean() - b.mean()) / se
    p = 2 * stats.norm.sf(abs(z))
    false_alarms += p < 0.05
print("доля ложных тревог:", false_alarms / 2000)
```

Здесь вместо перемешивания — z-тест для долей из раздела выше: 2 000 перемешиваний на каждый из 2 000 экспериментов считались бы слишком долго. Ложных тревог — около 5 %, как и обещает α.

::: warn Типичные ошибки
- **p-value = вероятность, что H₀ верна.** Нет: это вероятность получить такую же или большую разницу, **если** H₀ верна.
- **«Не отвергли» = «эффекта нет».** Может быть, данных просто мало (мощность).
- **Односторонний тест после того, как увидели знак.** Это подгонка; направление выбирают до данных.
- **Перебор сегментов.** 20 сравнений «без эффекта» дадут хотя бы одно p < 0.05 в 64 % случаев.
- **Перемешивать ответы и группы по отдельности.** Перемешиваются только ярлыки групп; ответы остаются при своих строках.
:::

::: quiz
Сравнили две кофейни по 60 доставок, тест дал p = 0.4, и H₀ не отвергли. Какую ошибку мы могли совершить?

- [x] Ошибку II рода: разница может быть, но на 60 доставках у теста не хватило мощности её заметить
  > «Не отвергли» — это возможный пропуск эффекта. Его вероятность тем выше, чем меньше данных и чем меньше сам эффект.
- [ ] Ошибку I рода: мы нашли эффект, которого нет
  > Ошибка I рода — ложная тревога, то есть отвергнутая H₀. Здесь мы H₀ не отвергали.
- [ ] Никакую: p = 0.4 доказывает, что кофейни работают одинаково
  > Большое p говорит лишь, что данные совместимы с H₀, а не что H₀ доказана.
- [ ] Ошибку I рода с вероятностью 0.4
  > p-value — не вероятность ошибки. Вероятность ошибки I рода задаёт порог α, и она возможна, только когда H₀ отвергают.
:::

## Двусторонний и односторонний

Мы считали «разница не меньше по модулю» — это **двусторонний** тест: H₁ «доли различаются в любую сторону». Если до сбора данных есть основание интересоваться только одним направлением («новое обещание **уменьшит** опоздания»), используют **односторонний**: считают только перемешивания с разницей не меньше наблюдаемой в нужную сторону. Его p примерно вдвое меньше.

::: warn
Выбирать односторонний тест **после** того, как увидели данные, — нечестно: так легко превратить p = 0.08 в «значимое» 0.04. Направление выбирается заранее, по смыслу задачи. Если сомневаетесь — двусторонний.
:::

### hint
В каждом эксперименте две группы из одного и того же распределения: `a = rng.random(n) < 0.24`, `b = rng.random(n) < 0.24`.

### hint
Шаги — как в разделе про z-тест: общая доля `p_pool`, `se = np.sqrt(p_pool * (1 - p_pool) * 2 / n)` (при равных группах `1/n + 1/n = 2/n`), `z`, `p = 2 * stats.norm.sf(abs(z))`.

```python
import numpy as np
from scipy import stats

n = 250
alarms = 0
for _ in range(2000):
    a = rng.random(n) < 0.24
    b = rng.random(n) < 0.24
    p_pool = (a.sum() + b.sum()) / (2 * n)
    se = np.sqrt(p_pool * (1 - p_pool) * 2 / n)
    z = (a.mean() - b.mean()) / se
    alarms += 2 * stats.norm.sf(abs(z)) < 0.05
false_rate = alarms / 2000
```

### hint
Оформите функцию `power(n, pa=0.24, pb=0.30, sims=2000)` и вызовите её дважды. Генератор создайте один раз до обоих вызовов.

### solution
```python
import numpy as np
from scipy import stats
rng = np.random.default_rng(4)

def power(n, pa=0.24, pb=0.30, sims=2000):
    hits = 0
    for _ in range(sims):
        a = rng.random(n) < pa
        b = rng.random(n) < pb
        p_pool = (a.sum() + b.sum()) / (2 * n)
        se = np.sqrt(p_pool * (1 - p_pool) * 2 / n)
        z = (b.mean() - a.mean()) / se
        hits += 2 * stats.norm.sf(abs(z)) < 0.05
    return hits / sims

power_200 = power(200)
power_800 = power(800)
```

### explain

Вот почему эксперимент планируют заранее: сколько данных нужно, чтобы увидеть эффект нужного размера. Это урок «A/B-тест: от дизайна до решения».

### solution
```python
import numpy as np
import pandas as pd

def perm_test(a, b, n_perm=2000, seed=0):
    rng = np.random.default_rng(seed)
    observed = a.mean() - b.mean()
    pooled = np.concatenate([a, b])
    k = len(a)
    count = 0
    for _ in range(n_perm):
        perm = rng.permutation(pooled)
        if abs(perm[:k].mean() - perm[k:].mean()) >= abs(observed):
            count += 1
    return observed, count / n_perm

d = pd.read_csv("deliveries.csv")
ok = d[d["actual_min"].between(1, 299)]
auto = ok.loc[ok["courier"] == "авто", "actual_min"].to_numpy()
velo = ok.loc[ok["courier"] == "вело", "actual_min"].to_numpy()
res = perm_test(auto, velo)
res
```

### explain
Авто-доставки в среднем на 0.4 минуты быстрее вело, p ≈ 0.47 — разница неотличима от случайной. ## task: many | Двадцать сегментов | star

### hint
Не обязательно моделировать каждую доставку: число опозданий из 300 — биномиальная случайная величина (урок «Распределения: мат. ожидание, биномиальное, Пуассона»), и `rng.binomial` симулирует её одной строкой. `rng.binomial(300, 0.24, size=(2000, 20)) / 300` — сразу доли для 2000 исследований × 20 сегментов. ### hint

### solution
```python
import numpy as np
from scipy import stats
rng = np.random.default_rng(5)
n = 300
a = rng.binomial(n, 0.24, size=(2000, 20)) / n
b = rng.binomial(n, 0.24, size=(2000, 20)) / n
p_pool = (a + b) / 2
se = np.sqrt(p_pool * (1 - p_pool) * 2 / n)
p = 2 * stats.norm.sf(np.abs(a - b) / se)
p_any = (p < 0.05).any(axis=1).mean()
p_formula = round(1 - 0.95 ** 20, 3)
```

### explain
Почти в двух исследованиях из трёх «нашёлся» значимый сегмент, хотя эффекта нет вообще. Это проблема **множественных сравнений**: чем больше проверок, тем больше ложных находок. Как с ней бороться — в уроке «Ловушки статистики».

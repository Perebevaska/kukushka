::: quiz 01-probability
Вероятность хотя бы одного опоздания в двух независимых доставках, если каждая опаздывает с вероятностью 0.25?

- [x] 1 − 0.75² ≈ 0.44
  > «Хотя бы один» удобно считать через противоположное событие: обе вовремя — 0.75 · 0.75.
- [ ] 0.5 = 0.25 + 0.25
  > Сложение не учитывает случай, когда опоздали обе, — он посчитан дважды.
- [ ] 0.0625 = 0.25²
  > Это вероятность, что опоздают **обе**.
- [ ] 0.25
  > Шансов больше, раз доставок две.
:::

::: quiz 02-distributions
Число опозданий из 20 доставок при вероятности 0.25 — в среднем сколько?

- [x] 5 = 20 · 0.25
  > Среднее биномиального распределения — n · p.
- [ ] 0.25
  > Это вероятность для одной доставки.
- [ ] 10
  > Половина была бы при p = 0.5.
- [ ] 20
  > Столько было бы, если бы опаздывали все.
:::

::: quiz 02b-normal
Пилот новой кофейни: 20 доставок, обычная доля опозданий 0.1. Можно ли считать вероятность «5 и больше опозданий» через нормальное приближение?

- [x] Нет: n · p = 2 — меньше 10, распределение сильно скошено, и колокол заметно ошибётся в хвосте
  > Правило «n · p ≥ 10 и n · (1 − p) ≥ 10» здесь не выполняется. Считайте точно: `stats.binom.sf(4, 20, 0.1)`.
- [ ] Да: доставок больше 10
  > Важно не n само по себе, а n · p — ожидаемое число опозданий. Их здесь всего 2.
- [ ] Да: нормальное приближение работает при любых n и p
  > При маленьком n · p биномиальное распределение скошено, а колокол симметричен — ошибка в хвостах большая.
- [ ] Нет: нормальное распределение вообще не подходит для долей
  > Подходит, когда данных достаточно: на этом построены z-тест для долей и интервал для доли.
:::

::: quiz 03-sampling
Зачем нужна стандартная ошибка среднего?

- [x] Она показывает, насколько выборочное среднее «гуляет» от выборки к выборке, — меру его точности
  > SE = σ / √n: чем больше выборка, тем точнее среднее.
- [ ] Это разброс отдельных значений
  > Разброс значений — стандартное отклонение σ.
- [ ] Это ошибка в расчётах
  > Это свойство случайной выборки, а не ошибка.
- [ ] Она равна стандартному отклонению
  > Она меньше в √n раз.
:::

::: quiz 04-confidence
Как изменится 95-процентный интервал, если взять уровень 99 %?

- [x] Станет шире
  > Чтобы чаще накрывать настоящее значение, интервал должен захватывать больше.
- [ ] Станет уже
  > Выше уверенность — шире интервал.
- [ ] Не изменится
  > Уровень доверия прямо задаёт ширину.
- [ ] Сместится вправо
  > Центр — та же оценка, меняется ширина.
:::

::: quiz 04-confidence
Зачем бутстрэп, если есть формулы интервалов?

- [x] Он даёт интервал для любой статистики — медианы, выручки на гостя, — где формулы нет или она сложная
  > Пересэмплируем данные с возвращением и смотрим разброс статистики.
- [ ] Он всегда точнее формул
  > Когда формула применима, результаты обычно близки.
- [ ] Он не требует данных
  > Требует — он и есть работа с данными.
- [ ] Только для маленьких выборок
  > Работает на любых, а на очень маленьких как раз бывает ненадёжен.
:::

::: quiz 05-hypotheses
Тест не отверг нулевую гипотезу (p = 0.4). Что можно сказать?

- [x] Данных недостаточно, чтобы заметить эффект; это не доказательство, что эффекта нет
  > «Не отвергли» — не «доказали отсутствие»: эффект может быть маленьким, а выборка — малой.
- [ ] Эффекта точно нет
  > Отсутствие доказательств — не доказательство отсутствия.
- [ ] Эффект есть с вероятностью 60 %
  > p-value не вероятность гипотез.
- [ ] Тест ошибся
  > Тест отработал как положено.
:::

::: quiz 06-tests
Как сравнить долю опозданий в группе доставок с изменением и в группе без него (доставки в группах разные)?

- [x] z-тестом для долей (или хи-квадратом)
  > Метрика — доля, группы независимые.
- [ ] Парным t-тестом
  > Парный тест — для одних и тех же объектов до и после.
- [ ] Тестом Манна — Уитни
  > Он для сравнения распределений чисел, а не долей «да/нет».
- [ ] Корреляцией
  > Корреляция не сравнивает группы.
:::

::: quiz 07-ab
Почему гостей делят на группы случайно, а не, скажем, по городам?

- [x] Случайность выравнивает все остальные различия между группами, и разница в метрике объясняется только изменением
  > При делении по городам эффект смешается с различиями городов.
- [ ] Так быстрее
  > Скорость не главное — главное честность сравнения.
- [ ] Так требует статистический тест
  > Тест можно посчитать на любых группах, но вывод будет неверным.
- [ ] Чтобы группы были одного размера
  > Размеры можно уравнять и без случайности; дело в сопоставимости.
:::

::: quiz 07-ab
Что такое MDE в дизайне эксперимента?

- [x] Минимальный эффект, который тест с выбранным размером выборки сможет надёжно заметить
  > Если ожидаемый эффект меньше MDE, тест почти наверняка его пропустит.
- [ ] Максимальный эффект, который возможен
  > Это не предел эффекта, а предел чувствительности теста.
- [ ] Средний эффект прошлых тестов
  > MDE считают до запуска из размера выборки и разброса метрики.
- [ ] Уровень значимости
  > Значимость — α, отдельный параметр.
:::

::: quiz 08-pitfalls
После теста аналитик нашёл эффект только у гостей Уфы старше 40 лет. Как к этому относиться?

- [x] Как к гипотезе для следующего теста: при многих срезах «эффект» в каком-то из них найдётся случайно
  > Сегменты, выбранные после теста, — ловушка множественных сравнений.
- [ ] Как к доказанному результату
  > Без поправки и повторной проверки это может быть случайность.
- [ ] Внедрить изменение только для этой группы
  > Сначала проверить отдельным экспериментом.
- [ ] Проигнорировать навсегда
  > Это полезная идея, но её надо проверить.
:::

::: quiz 08-pitfalls
Аналитик каждый день смотрит p-value A/A-теста (эффекта точно нет) и останавливает тест, как только p < 0.05. Как часто он объявит ложную победу за две недели?

- [x] Заметно чаще 5 %: каждый взгляд — новый шанс поймать случайный провал p под порог
  > В симуляции урока «Ловушки статистики» при 14 ежедневных проверках ложных побед было около 23 %.
- [ ] Ровно в 5 % тестов — порог же 0.05
  > Порог 0.05 обещает 5 % ложных тревог только для одной проверки в конце.
- [ ] Реже 5 %: чем больше данных, тем меньше ошибок
  > Данных к концу больше, но остановка происходит при первом же «значимом» дне.
- [ ] В 70 % тестов: 14 проверок по 5 %
  > Проверки зависимы — данные накапливаются, — поэтому ошибки не складываются так просто.
:::

::: quiz 08-pitfalls
Пять кофеен с худшей долей опозданий за октябрь отправили на тренинг. В ноябре у них опозданий стало меньше. Что можно сказать о тренинге?

- [x] Пока ничего: худшие по случайности кофейни и без тренинга в среднем улучшаются (регрессия к среднему); нужна группа сравнения
  > Попадание в «худшие» отчасти объясняется невезением, а невезение в следующем месяце не повторяется.
- [ ] Тренинг сработал: опоздания снизились
  > Такое же «улучшение» показали бы худшие кофейни и без всякого тренинга.
- [ ] Тренинг навредил остальным кофейням
  > Данных об этом нет; вопрос о самих пяти кофейнях.
- [ ] Нужно отправить на тренинг лучших — у них эффект будет больше
  > У лучших по случайности кофеен наоборот: в следующем месяце они в среднем станут хуже.
:::

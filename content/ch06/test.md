::: quiz 01-what-is-ml
Что в задаче «опоздает ли доставка» является ответом (целевым признаком)?

- [x] Факт опоздания: опоздала доставка или нет
  > Модель учится предсказывать именно его по остальным признакам.
- [ ] Расстояние до гостя
  > Это признак — то, по чему предсказываем.
- [ ] Модель
  > Модель — результат обучения, а не столбец данных.
- [ ] Время заказа
  > Тоже признак.
:::

::: quiz 02-split
Дерево без ограничений даёт 95 % на обучении и 73 % на тесте. Как это назвать?

- [x] Переобучение: модель запомнила обучающие строки, но плохо обобщает
  > Признак — большой разрыв между обучением и тестом.
- [ ] Недообучение
  > При недообучении плохо и на обучении.
- [ ] Утечка
  > Утечка дала бы высокое качество и на тесте.
- [ ] Нормальная ситуация для дерева
  > Такой разрыв — повод ограничить глубину.
:::

::: quiz 03-tree
Как ограничить переобучение дерева?

- [x] Ограничить глубину или задать минимальное число объектов в листе
  > Мелкие листья запоминают шум; ограничения заставляют искать общие закономерности.
- [ ] Добавить больше признаков
  > Это обычно усиливает переобучение.
- [ ] Учить на тесте
  > Тест не для обучения.
- [ ] Убрать базовую модель
  > Базовая модель — точка отсчёта, на переобучение она не влияет.
:::

::: quiz 04-categorical
Почему погоду не кодируют числами «ясно = 0, облачно = 1, дождь = 2, снег = 3»?

- [x] Модель решит, что снег «больше» дождя и между ними есть порядок и расстояния, которых нет
  > Для категорий без порядка делают флаги (one-hot).
- [ ] Числа занимают больше памяти
  > Наоборот, флаги занимают больше.
- [ ] sklearn не принимает целые числа
  > Принимает, но смысл кодировки неверный.
- [ ] Так нельзя посчитать среднее
  > Дело не в среднем, а в ложном порядке.
:::

::: quiz 04-categorical
Модель обучили на флагах погоды, а в новых данных появилась «гроза». Что сделать?

- [x] Строить флаги для новых данных по тем же столбцам, что при обучении; неизвестная категория даёт нули
  > Модель знает только столбцы обучения — новые данные приводят к той же форме.
- [ ] Добавить столбец «гроза» к новым данным
  > Модель такого столбца не знает — будет ошибка.
- [ ] Переобучить модель на одной новой строке
  > Одна строка ничему не научит.
- [ ] Удалить заказы с грозой
  > Прогноз для них всё равно нужен.
:::

::: quiz 05-forest
Что делает `n_estimators` у случайного леса?

- [x] Задаёт число деревьев, которые голосуют
  > Больше деревьев — стабильнее результат, но дольше обучение; после некоторого числа выигрыш почти исчезает.
- [ ] Глубину каждого дерева
  > Глубина — `max_depth`.
- [ ] Число признаков в модели
  > Признаки модели те же; `max_features` лишь задаёт, сколько из них дерево рассматривает при каждом разбиении.
- [ ] Долю тестовой выборки
  > Разбиение делается отдельно.
:::

::: quiz 06-logistic
Чем `predict_proba` полезнее `predict` для акции удержания?

- [x] Даёт вероятность ухода — гостей можно ранжировать и выбрать порог или топ под бюджет
  > `predict` уже применил порог 0.5 и спрятал степень уверенности.
- [ ] Он точнее
  > Модель та же, меняется только вид ответа.
- [ ] Он работает без обучения
  > Требует обученной модели, как и `predict`.
- [ ] Возвращает список уходящих
  > Возвращает вероятности для всех.
:::

::: quiz 07-regression
Модель прогнозирует минуты доставки с MAE = 6. Что это значит?

- [x] В среднем прогноз ошибается на 6 минут в ту или другую сторону
  > MAE — средний модуль ошибки в единицах ответа.
- [ ] Модель ошибается в 6 % случаев
  > MAE — не доля ошибок.
- [ ] Все прогнозы отличаются ровно на 6 минут
  > Это среднее; отдельные ошибки разные.
- [ ] Модель на 6 минут лучше базовой
  > Сравнение с базовой — отдельная цифра.
:::

::: quiz 08-validation
Зачем нужна валидационная выборка, если есть тест?

- [x] По ней выбирают модель и настройки, а тест остаётся нетронутым для итоговой честной оценки
  > Если выбирать по тесту, его цифра станет завышенной.
- [ ] Чтобы обучать модель дважды
  > Валидация — не для обучения.
- [ ] Тест и валидация — одно и то же
  > Роли разные: выбор и итоговая проверка.
- [ ] Она нужна только для нейросетей
  > Для любой модели, где что-то выбирают.
:::

::: quiz 08-validation
Чем кросс-валидация лучше одного разбиения на train и validation?

- [x] Оценка усредняется по нескольким разбиениям и меньше зависит от удачи одного
  > Видно и среднее качество, и его разброс.
- [ ] Она быстрее
  > Обучение идёт k раз — медленнее.
- [ ] Она не требует данных для проверки
  > Каждый фолд по очереди служит проверкой.
- [ ] Она заменяет тест
  > Тест всё равно нужен для итоговой оценки.
:::

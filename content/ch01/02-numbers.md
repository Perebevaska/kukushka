## Переменная — это имя для значения

Посчитаем выручку кофейни за день: продано 120 чашек по 180 рублей.

```python
print(120 * 180)
```

Работает, но через неделю будет непонятно, что такое 120 и 180. Дадим числам имена:

```python
cups = 120
price = 180
revenue = cups * price
print(revenue)
```

`cups = 120` читается так: «положи 120 в переменную `cups`». Дальше вместо числа можно писать имя — Python подставит значение.

Удобно представлять переменную как **ячейку в Excel, у которой есть имя**: в ячейку `revenue` записана формула, которая берёт значения из ячеек `cups` и `price`. Разница одна: в Python формула считается **один раз**, в момент выполнения строки, и сама не пересчитывается.

```python
cups = 120
price = 180
revenue = cups * price
cups = 200          # поменяли количество чашек
print(revenue)      # выручка осталась старой — её посчитали раньше
```

::: figure var-assign
Слева: Python сначала считает правую часть (120 × 180), потом кладёт результат в `revenue`. Справа: `cups` перевесили на 200, а в `revenue` по-прежнему лежит число 21 600 — формулы переменная не помнит.
:::

::: warn
Знак `=` в Python — это **присваивание**, а не сравнение. `revenue = cups * price` значит «посчитай справа и положи результат в переменную слева». Сравнение на равенство записывается двумя знаками: `==` — до него дойдём в уроке про условия.
:::

### Как называть переменные

- латинскими буквами, цифрами и `_`, но не с цифры: `revenue_2026` — можно, `2026_revenue` — нельзя;
- без пробелов: слова соединяют подчёркиванием — `avg_check`, `orders_count`. Этот стиль называется *snake_case*;
- регистр важен: `Revenue` и `revenue` — две разные переменные;
- называйте по смыслу: `price` лучше, чем `p` или `x1`.

::: sql
Это как алиасы в запросе: `SELECT cups * price AS revenue`. Только в Python «алиас» живёт дальше по коду, и его можно использовать в следующих вычислениях.
:::

### Переменную можно обновить

Новое значение можно посчитать из старого. Например, на складе 40 кг зерна, за день ушло 6,5 кг:

```python
stock = 40
stock = stock - 6.5
print(stock)
```

Сначала считается правая часть (`40 - 6.5`), потом результат кладётся обратно в `stock`. Для такого действия есть короткая запись:

```python
stock = 40
stock -= 6.5     # то же, что stock = stock - 6.5
stock -= 7.25
print(stock)
```

Аналогично работают `+=`, `*=`, `/=`.

## Целые и дробные числа

В Python два основных вида чисел:

| Тип | Что это | Примеры |
|---|---|---|
| `int` | целое число (*integer*) | `120`, `-5`, `0` |
| `float` | дробное число (*floating point*) | `180.5`, `0.25`, `3.0` |

Дробная часть отделяется **точкой**, а не запятой: `6.5`, а не `6,5`. Узнать тип значения можно функцией `type`:

```python
print(type(120))
print(type(6.5))
print(type(3.0))
```

`<class 'int'>` читается просто как «тип int»; слово `class` пока не обращайте внимания.

Большие числа удобно писать с подчёркиваниями — Python их игнорирует, а читать легче:

```python
monthly_revenue = 1_314_000
print(monthly_revenue)
```

## Арифметика

| Действие | Запись | Результат |
|---|---|---|
| сложение, вычитание | `7 + 2`, `7 - 2` | `9`, `5` |
| умножение | `7 * 2` | `14` |
| деление | `7 / 2` | `3.5` — всегда `float` |
| целая часть от деления | `7 // 2` | `3` |
| остаток от деления | `7 % 2` | `1` |
| степень | `7 ** 2` | `49` |

Порядок действий — как в математике: сначала `**`, потом `*` `/` `//` `%`, потом `+` и `-`. Действия одной группы выполняются слева направо: `seconds % 3600 // 60` — сначала `%`, потом `//`. Скобки меняют порядок:

```python
print(2 + 3 * 4)
print((2 + 3) * 4)
```

::: sql
В SQL Server и PostgreSQL деление целых чисел отбрасывает дробную часть: `SELECT 7 / 2` вернёт `3`. В Python `7 / 2` — это `3.5`. Если нужно поведение «как в SQL», используйте `//`. Это частый источник расхождений, когда цифры из базы сверяют с цифрами из Python.
:::

`//` и `%` удобны, когда нужно разложить что-то на целые части. Например, 157 стаканов раскладываем по упаковкам по 50 штук:

```python
cups = 157
packs = cups // 50     # сколько полных упаковок
left = cups % 50       # сколько осталось
print(packs, left)
```

`%` читается «остаток от деления»: 157 = 3 · 50 + 7, поэтому `157 // 50` — это 3 (полные упаковки), а `157 % 50` — 7 (то, что не влезло). Проверка простая: `packs * 50 + left` снова даёт 157.

То же самое умеет одна встроенная функция: `divmod(157, 50)` возвращает оба числа сразу — `(3, 7)`. Пару в скобках можно разложить по двум переменным: `packs, left = divmod(cups, 50)`. Такие пары подробно разберём в уроке «Кортежи и множества», а пока `//` и `%` по отдельности понятнее.

::: figure floor-mod
157 стаканов: `//` даёт число полных упаковок по 50 (3), `%` — то, что не влезло (7). Обычное деление дало бы дробь 3.14.
:::

::: predict
```python static
print(7 // 2, 7 % 2)
```

- `3.5 1`
- [x] `3 1`
- `3 0.5`

Почему: `//` — целая часть от деления (3), `%` — остаток (1).
:::

### Округление

Средний чек почти никогда не получается ровным. Функция `round(число, знаков)` округляет:

```python
revenue = 84_530
orders = 260
avg_check = revenue / orders
print(avg_check)
print(round(avg_check, 2))
print(round(avg_check))       # без второго аргумента — до целого
```

::: deep
Попробуйте `print(0.1 + 0.2)`. Получится `0.30000000000000004`. Это не ошибка Python: дробные числа хранятся в двоичном виде, и некоторые десятичные дроби в нём нельзя записать точно (как 1/3 в десятичном). Так ведут себя Excel, SQL с типом `float` и любой другой язык. Для денег в отчётах результат округляют, а в базах используют тип `decimal` (в Python есть одноимённый модуль, но в курсе он не понадобится).
:::

### Разберём вместе: таблица значений

Проследим программу строка за строкой и будем записывать, что лежит в каждой переменной после строки:

```python
cups = 140
price = 190
revenue = cups * price
price = 210
cups += 10
print(cups, price, revenue)
```

| после строки | `cups` | `price` | `revenue` |
|---|---|---|---|
| 1 | 140 | — | — |
| 2 | 140 | 190 | — |
| 3 | 140 | 190 | 26 600 |
| 4 | 140 | **210** | 26 600 |
| 5 | **150** | 210 | 26 600 |

Выведется `150 210 26600`.

1. В строке 3 Python **один раз** считает 140 × 190 и кладёт число 26 600 в `revenue`. Формулы, как в Excel, переменная не запоминает.
2. Строки 4 и 5 меняют `price` и `cups`, но `revenue` об этом не знает — в ней старое число.
3. Чтобы выручка пересчиталась, строку `revenue = cups * price` нужно выполнить ещё раз — после изменений.

Что получилось: переменная — это ярлык на значение, а не ячейка с формулой. Таблица «после строки N» — лучший способ разобраться в любом непонятном коде: так же отлаживают программы и опытные разработчики.

::: quiz
157 стаканов раскладывают по упаковкам по 50 штук. Какое выражение даст число **полных** упаковок?

- [ ] `157 / 50`
  > Обычное деление всегда даёт дробь: 3.14. Это «сколько упаковок примерно», а не сколько полных.
- [x] `157 // 50`
  > Целая часть от деления — 3 полные упаковки. Остаток `157 % 50` — 7 стаканов, которые не влезли.
- [ ] `round(157 / 50)`
  > Здесь случайно выйдет 3, но округление — не то же самое: для 175 стаканов `round(3.5)` даст 4, а полных упаковок 3.
- [ ] `157 % 50`
  > Это остаток: 7 стаканов, которым не хватило упаковки.
:::

## Текст и число — не одно и то же

Из файлов и форм числа часто приходят как текст. Выглядит так же, а ведёт себя иначе:

```python
price_text = "185"
print(price_text * 3)
```

Строка, умноженная на 3, — это та же строка, повторённая три раза. Чтобы считать, текст надо превратить в число: `int(...)` — в целое, `float(...)` — в дробное.

```python
price_text = "185"
price = int(price_text)
print(price * 3)
print(float("3.5") + 1)
```

А сложить строку и число Python не даст вовсе — получится `TypeError`:

```python error
price_text = "185"
print(price_text + 15)
```

::: predict
```python static
print("12" * 2)
```

- `24`
- [x] `1212`
- `Ошибка TypeError`

Почему: `"12"` — строка, а строка, умноженная на число, повторяется. Чтобы получить 24, нужно `int("12") * 2`.
:::

::: warn Типичные ошибки
- **Ожидание «формулы».** `revenue = cups * price` не пересчитается при изменении `price` — нужно выполнить строку снова.
- **Деление `/` всегда даёт дробь.** `10 / 2` — это `5.0`; целая часть — `//`.
- **Скобки в процентах.** `new - old / old * 100` сначала делит; разность — в скобки.
- **Запятая в дроби.** `6,5` — это два числа; дробь пишется через точку: `6.5`.
:::

```python
assert printed_line('2 ч 3 мин 4 с'), 'Ожидалась строка «2 ч 3 мин 4 с».'
assert not has_literal(2) and not has_literal(4), 'Числа нужно посчитать, а не вписать.'
```

### hint
В часе 3600 секунд. `seconds // 3600` — целые часы, `seconds % 3600` — секунды, которые остались после них.

### hint
Остаток снова делим: на 60 — минуты, остаток от 60 — секунды. Вывод: `print(h, "ч", m, "мин", s, "с")`.

### solution
```python
seconds = 7384
h = seconds // 3600
m = seconds % 3600 // 60
s = seconds % 60
print(h, "ч", m, "мин", s, "с")
```

### explain
7384 секунды: 7384 // 3600 = 2 часа, остаток 184 секунды; 184 // 60 = 3 минуты, остаток 4 секунды. Каждый шаг — «сколько целых единиц и что осталось», та же пара `//` и `%`.

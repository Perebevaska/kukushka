## Строка таблицы — это список

Вот продажи по кофейням за день: город, число чашек, средняя цена чашки. Одну строку такой таблицы можно хранить списком:

```python
row = ["Пермь", 412, 205]
print(row[0], row[1], row[2])
```

А всю таблицу — **списком строк**, то есть списком списков:

```python
sales = [
    ["Пермь", 412, 205],
    ["Казань", 538, 198],
    ["Тюмень", 297, 214],
    ["Уфа", 365, 189],
]
print(len(sales))     # сколько строк
print(sales[1])       # вторая строка целиком
print(sales[1][0])    # строка 1, столбец 0
```

Два индекса подряд читаются слева направо: `sales[1]` — это список `["Казань", 538, 198]`, а `[0]` берёт из него первый элемент.

::: figure nested-index
Первый индекс выбирает строку-список, второй — элемент внутри неё: `sales[1][1]` — чашки Казани.
:::

::: sql
Это результат запроса `SELECT city, cups, avg_price FROM sales_day` — только без названий столбцов. Какой столбец что значит, держим в голове: 0 — город, 1 — чашки, 2 — цена. В pandas у столбцов появятся имена, и станет удобнее. Но устройство «строки × столбцы» то же.
:::

::: predict
```python static
t = [["a", 1], ["b", 2]]
print(t[1][0])
```

- `1`
- [x] `b`
- `a`

Почему: `t[1]` — вторая строка `["b", 2]`, а `[0]` берёт её первый элемент.
:::

## Проход по строкам

Цикл `for` по таблице выдаёт строки по одной:

```python
sales = [
    ["Пермь", 412, 205],
    ["Казань", 538, 198],
    ["Тюмень", 297, 214],
]
for row in sales:
    print(row[0], "—", row[1], "чашек")
```

### Распаковка строки

`row[0]`, `row[1]` читать неудобно. Строку можно **распаковать** сразу в именованные переменные — столько переменных, сколько значений в строке:

```python
sales = [
    ["Пермь", 412, 205],
    ["Казань", 538, 198],
    ["Тюмень", 297, 214],
]
for city, cups, price in sales:
    print(f"{city}: {cups} чашек по {price} ₽")
```

Если число переменных не совпадёт с длиной строки, будет `ValueError: too many values to unpack` или `not enough values to unpack`.

## Столбец, итог, фильтр

Вытащить один столбец в отдельный список:

```python
sales = [
    ["Пермь", 412, 205],
    ["Казань", 538, 198],
    ["Тюмень", 297, 214],
]
cups = []
for row in sales:
    cups.append(row[1])
print(cups)
print("Всего чашек:", sum(cups))
```

Отобрать строки по условию — тот же фильтр из прошлого урока, только в новый список кладём строку целиком:

```python
sales = [
    ["Пермь", 412, 205],
    ["Казань", 538, 198],
    ["Тюмень", 297, 214],
]
big = []
for row in sales:
    if row[1] > 400:
        big.append(row)
print(big)
```

::: sql
Первое — `SELECT cups FROM sales` и `SELECT SUM(cups) FROM sales`. Второе — `SELECT * FROM sales WHERE cups > 400`.
:::

::: quiz
В Перми продали 412 чашек по 205 ₽, в Казани — 538 по 198 ₽, в Тюмени — 297 по 214 ₽. Какая «средняя цена чашки по сети» честная?

- [ ] Среднее трёх цен: (205 + 198 + 214) / 3
  > Так у Тюмени с 297 чашками тот же вес, что у Казани с 538. Средняя цена должна учитывать, где чашек продано больше.
- [x] Вся выручка, делённая на все чашки
  > Это средневзвешенная цена: каждая кофейня входит с весом своих продаж. Именно её получит бухгалтер, разделив деньги на чашки.
- [ ] Цена кофейни, где продали больше всего чашек
  > Это цена одной кофейни, остальные две в расчёт не попали.
- [ ] Медиана цен
  > Медиана тоже не учитывает, сколько чашек продано по каждой цене.
:::

::: figure weighted-avg
Сверху у каждой кофейни одинаковый вес, снизу — вес по числу чашек. Казань продала больше всех по самой низкой цене, поэтому честная средняя ниже.
:::

## Вычисляемый столбец

Добавим к каждой строке выручку = чашки × цена. Строка — список, значит, к ней можно добавить элемент через `append`:

```python
sales = [
    ["Пермь", 412, 205],
    ["Казань", 538, 198],
    ["Тюмень", 297, 214],
]
for row in sales:
    row.append(row[1] * row[2])
print(sales)
```

Теперь у каждой строки четыре значения, и выручка лежит в столбце с индексом 3.

::: figure row-alias
`row` в цикле — второе имя строки таблицы, а не копия: `append` дописывает выручку прямо в `sales`.
:::

::: warn
`row.append(...)` меняет **исходную** таблицу: `row` — не копия, а та же самая строка из `sales`. Обычно это и нужно. Но если запустить этот код ещё раз (например, после правки), столбец добавится повторно.
:::

::: tip Аналогия
Ярлык на рабочем столе: открыли папку через ярлык и положили в неё файл — файл появился в самой папке, а не в копии. `row` — такой ярлык на строку из `sales`.
:::

::: predict
```python static
row = ["Пермь", 2, 100]
row.append(row[1] * row[2])
print(len(row))
```

- `3`
- [x] `4`
- `200`

Почему: `append` добавил в строку четвёртый элемент — выручку 200. Длина строки стала 4.
:::

### Разберём вместе: два индекса — строка и столбец

Таблица продаж — список списков:

```python
sales = [
    ["Пермь", 412, 205],
    ["Казань", 538, 198],
    ["Тюмень", 297, 214],
]
```

| | `[0]` город | `[1]` чашки | `[2]` цена |
|---|---|---|---|
| `sales[0]` | Пермь | 412 | 205 |
| `sales[1]` | Казань | **538** | 198 |
| `sales[2]` | Тюмень | 297 | 214 |

1. `sales[1]` — вся вторая строка: `["Казань", 538, 198]`.
2. `sales[1][1]` — второй элемент этой строки: **538**. Первый индекс — строка, второй — столбец, как адрес ячейки «строка, столбец».
3. `sales[1][1] * sales[1][2]` — выручка Казани: 538 × 198 = 106 524.
4. `for city, cups, price in sales:` раскладывает каждую строку по трём именам — и вместо `row[1]` можно писать `cups`.

```python
sales = [["Пермь", 412, 205], ["Казань", 538, 198], ["Тюмень", 297, 214]]
print(sales[1], sales[1][1], sales[1][1] * sales[1][2])
for city, cups, price in sales:
    print(city, cups * price)
```

Что получилось: список списков — это таблица Excel без заголовков. Работать с ней можно, но номера столбцов приходится помнить. В главе 2 pandas даст столбцам имена — и `row[1]` превратится в `df["cups"]`.

## Красивый вывод таблицы

Чтобы столбцы стояли ровно, в f-строке задают ширину поля: `{x:<10}` — выровнять по левому краю в 10 символов, `{x:>8}` — по правому в 8. Числа принято выравнивать вправо, текст — влево:

```python
sales = [
    ["Пермь", 412, 205],
    ["Казань", 538, 198],
    ["Тюмень", 297, 214],
]
print(f"{'Город':<8}{'Чашки':>7}{'Цена':>7}")
for city, cups, price in sales:
    print(f"{city:<8}{cups:>7}{price:>7}")
```

Слово `'Город'` внутри f-строки записано в одинарных кавычках: сама f-строка уже в двойных, и двойная кавычка внутри закончила бы её раньше времени.

Ширину можно совмещать с форматом числа: `{revenue:>10,.0f}`.

::: warn Типичные ошибки
- **Перепутаны индексы.** `sales[1][2]` — цена Казани, а не чашки; держите перед глазами порядок столбцов.
- **Распаковка не на то число имён.** `for city, cups in sales:` при трёх столбцах — `ValueError: too many values to unpack`.
- **Среднее из средних.** Средняя цена по сети — вся выручка / все чашки, а не среднее цен кофеен.
- **Числа из текста остались строками.** После `split` все значения — текст; `int(...)` обязателен.
:::

## task: weighted | Средняя цена чашки по сети | plus

Средняя цена чашки по сети — **не** среднее из цен кофеен: в Казани чашек больше, и её цена должна весить больше. Правильно: вся выручка, делённая на все чашки. Посчитайте `avg_price`, округлив до двух знаков.

### starter
```python
sales = [
    ["Пермь", 412, 205],
    ["Казань", 538, 198],
    ["Тюмень", 297, 214],
    ["Уфа", 365, 189],
]

```

### check
```python
v = need('avg_price')
assert close(v, 200.7, 1e-9), f'avg_price = {v}. Простое среднее цен даёт 201.5 — нужно взвешенное: сумма (чашки × цена) / сумма чашек.'
```

### hint
Два накопителя в одном цикле: `total_revenue` и `total_cups`. После цикла — деление и `round(…, 2)`.

### hint
В цикле: `total_revenue += cups * price`, `total_cups += cups`.

### solution
```python
sales = [
    ["Пермь", 412, 205],
    ["Казань", 538, 198],
    ["Тюмень", 297, 214],
    ["Уфа", 365, 189],
]
total_revenue = 0
total_cups = 0
for city, cups, price in sales:
    total_revenue += cups * price
    total_cups += cups
avg_price = round(total_revenue / total_cups, 2)
```

### explain
Это одна из самых частых ошибок в отчётах: среднее средних. В SQL правильный вариант — `SUM(cups * price) / SUM(cups)`, а не `AVG(avg_price)`.

```python
want = ['Город    Чашки', 'Пермь      412', 'Казань     538', 'Тюмень     297']
got = [l.rstrip() for l in _out.splitlines() if l.strip()]
bad = next((i for i, (g, w) in enumerate(zip(got, want)) if g != w), None)
if bad is not None:
    raise AssertionError(f'Строка {bad + 1} расходится.\nНужно:   {want[bad]!r} (длина {len(want[bad])})\nСейчас: {got[bad]!r} (длина {len(got[bad])})\nКаждая строка — 14 символов: поле 8 + поле 6.')
assert got == want, f'Сейчас строки такие: {got}'
assert uses_fstring(), 'Используйте f-строки с шириной поля.'
```

### hint
`:<8` — выровнять влево в поле из 8 символов, `:>6` — вправо в поле из 6.

### hint
Заголовок: `f"{'Город':<8}{'Чашки':>6}"`. Внутри f-строки в двойных кавычках текст пишется в одинарных.

### solution
```python
sales = [
    ["Пермь", 412, 205],
    ["Казань", 538, 198],
    ["Тюмень", 297, 214],
]
print(f"{'Город':<8}{'Чашки':>6}")
for city, cups, price in sales:
    print(f"{city:<8}{cups:>6}")
```

### explain
Ширина поля в f-строке — это число символов, которое займёт значение, даже если само оно короче: `f"{'Тюмень':<8}"` даёт «Тюмень» и два пробела. Числа принято выравнивать по правому краю: тогда разряды стоят друг под другом и столбец читается как в Excel. Заголовок выравнивается теми же ширинами, что и строки, иначе «Чашки» съедет относительно чисел. Третий элемент строки (`price`) распаковывается в переменную, но в таблицу не идёт — так можно взять из строки только нужное.

## task: from-text | Таблица из текста | star

Таблица пришла текстом — как из CSV-файла: строки разделены переводом строки (в тексте это символ `\n`), значения — точкой с запятой. Превратите её в список списков `table`, где чашки и цена — числа.

### starter
```python
text = "Пермь;412;205\nКазань;538;198\nТюмень;297;214"

```

### check
```python
t = need('table', list)
assert t == [['Пермь', 412, 205], ['Казань', 538, 198], ['Тюмень', 297, 214]], f'table = {t!r}. Проверьте, что числа — int, а не строки.'
```

### hint
Сначала разрежьте текст на строки: `text.split("\n")`. Каждую строку — по `;`.

### hint
После `city, cups, price = line.split(";")` все три значения — строки. Числа нужно превратить через `int`.

### solution
```python
text = "Пермь;412;205\nКазань;538;198\nТюмень;297;214"
table = []
for line in text.split("\n"):
    city, cups, price = line.split(";")
    table.append([city, int(cups), int(price)])
```

### explain
Примерно так и работает чтение CSV — в уроке «Файлы, CSV и модули» будет модуль `csv`, а потом pandas, которые делают это за вас. Зато теперь понятно, что внутри.

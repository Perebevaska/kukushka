::: quiz 02-numbers
Что выведет `print(10 / 2)`?

- [ ] `5`
  > Так выведет `10 // 2` — целочисленное деление.
- [x] `5.0`
  > Обычное деление `/` в Python всегда даёт дробное число, даже если делится нацело.
- [ ] `5,0`
  > Python пишет дробную часть через точку.
- [ ] Ошибку: делить целые нельзя
  > Делить можно — результат просто будет дробным.
:::

::: quiz 03-strings
`city = "Пермь"`. Что такое `city[-1]`?

- [x] `"ь"` — последний символ
  > Отрицательные индексы считают с конца: `-1` — последний, `-2` — предпоследний.
- [ ] `"П"` — первый символ
  > Первый — `city[0]`.
- [ ] Ошибка: индексов меньше нуля не бывает
  > В Python бывают, и это удобно.
- [ ] `"Перм"` — всё, кроме последнего
  > Это срез `city[:-1]`.
:::

::: quiz 04-lists
`cities = ["Пермь", "Казань"]`, затем `cities = cities.append("Уфа")`. Что теперь в `cities`?

- [ ] `["Пермь", "Казань", "Уфа"]`
  > Так было бы без присваивания: просто `cities.append("Уфа")`.
- [x] `None`
  > `append` меняет список на месте и ничего не возвращает. Присвоив результат, мы затёрли список значением `None`.
- [ ] `"Уфа"`
  > `append` не возвращает добавленный элемент.
- [ ] Ошибку
  > Ошибки не будет, и этим ловушка опасна: она проявится позже.
:::

::: quiz 05-for
Какие числа даст `range(1, 5)`?

- [ ] 1, 2, 3, 4, 5
  > Правая граница в `range` не включается.
- [x] 1, 2, 3, 4
  > От левой границы включительно до правой — не включая, как у срезов.
- [ ] 0, 1, 2, 3, 4
  > С нуля начинается `range(5)`.
- [ ] 1 и 5
  > `range` даёт все числа между границами, а не только сами границы.
:::

::: quiz 06-if
Почему `if revenue = plan:` вызывает синтаксическую ошибку?

- [x] `=` — присваивание, а для сравнения нужно `==`
  > В условии должно стоять выражение, которое даёт True или False. Присваивание таким выражением не является.
- [ ] После `if` нельзя использовать переменные
  > Можно, если сравнивать их через `==`, `>` и другие операторы.
- [ ] Нужно писать `if (revenue = plan):`
  > Скобки не помогут: ошибка в знаке.
- [ ] `plan` — зарезервированное слово
  > Это обычное имя переменной.
:::

::: quiz 08-dicts
Для подсчёта напитков пишут `counts[d] = counts.get(d, 0) + 1`. Зачем здесь `get`, а не `counts[d] + 1`?

- [x] При первой встрече напитка ключа ещё нет, и `counts[d]` упал бы с `KeyError`; `get` вернёт 0
  > Это главный приём подсчёта по группам: запасное значение 0 для новых ключей.
- [ ] `get` работает быстрее
  > Скорость тут ни при чём.
- [ ] Без `get` счёт пойдёт с единицы, а не с нуля
  > Без `get` счёт вообще не начнётся — будет ошибка.
- [ ] `get` сортирует ключи
  > Сортировки в этой строке нет.
:::

::: quiz 09-functions
Функция объявлена как `def rub(amount, decimals=0):`. Что будет при вызове `rub(1500)`?

- [x] `decimals` возьмёт значение по умолчанию — 0
  > Параметры со значением по умолчанию можно не передавать.
- [ ] Ошибка: передан только один аргумент
  > Ошибка была бы, если бы у `decimals` не было значения по умолчанию.
- [ ] `amount` станет 0, а `decimals` — 1500
  > Аргументы без имени заполняют параметры по порядку: первый — `amount`.
- [ ] `decimals` будет `None`
  > `None` было бы, только если бы так написали в объявлении.
:::

::: quiz 11-comprehensions
Что делает `if` в выражении `[round(p * 1.1) for p in prices if p > 200]`?

- [x] Отбирает только цены больше 200, остальные в новый список не попадают
  > `if` в конце генератора — фильтр. Новый список может оказаться короче исходного.
- [ ] Поднимает на 10 % только дорогие цены, а дешёвые оставляет как есть
  > Дешёвые не остаются, а пропадают. Чтобы оставить, нужно условие перед `for`: `x if … else y`.
- [ ] Вызывает ошибку: в генераторе нельзя писать `if`
  > Можно: это обычный приём.
- [ ] Сортирует цены
  > Порядок элементов сохраняется.
:::

::: quiz 12-errors
`int("12.5")` падает с `ValueError`. Как превратить такую строку в число?

- [x] `float("12.5")` — строка с дробной частью превращается в дробное число
  > `int` понимает только запись целого числа. Если нужно целое — `int(float("12.5"))` даст 12.
- [ ] `int("12.5", 10)`
  > Второй аргумент — основание системы счисления. Точку он не поможет разобрать.
- [ ] Обернуть в `try`, и `int` сработает
  > `try` не меняет результат — он только ловит ошибку.
- [ ] `"12.5" + 0`
  > Строку нельзя сложить с числом.
:::

::: quiz 13-files
Что случится, если открыть существующий файл отчёта командой `open("report.md", "w")`?

- [x] Старое содержимое сотрётся, файл начнётся заново
  > Режим `"w"` пишет файл с нуля. Дописать в конец можно в режиме `"a"`.
- [ ] Новый текст допишется в конец
  > Это поведение режима `"a"`.
- [ ] Ошибка: файл уже существует
  > Так ведёт себя режим `"x"`, а `"w"` молча перезаписывает.
- [ ] Файл откроется только для чтения
  > Для чтения — режим `"r"`, по умолчанию.
:::

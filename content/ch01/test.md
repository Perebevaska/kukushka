**До выбора вариантов.** В списке выдач `[2, 1, 2]` каждое число — количество книг в одной выдаче. Как отдельно получить число выдач и общее число книг? Сначала сформулируйте ответ своими словами.

::: quiz 01-start
Программа из трёх строк: `print("Начало")`, `print(revenue)`, `print("Конец")`. Переменная `revenue` нигде не создана. Что появится на экране?

- [x] «Начало», затем `NameError`; выполнение остановится
  > Python выполняет строки сверху вниз и останавливается на первой ошибке. Первая строка успела сработать, третья до очереди не дошла.
- [ ] `NameError`, без вывода «Начало»
  > Первая строка выполнилась до ошибки, её вывод останется на экране.
- [ ] «Начало» и «Конец», без ошибки
  > Python не перескакивает через ошибку: после неё программа останавливается.
- [ ] «Начало», пустая строка, «Конец»
  > Неизвестное имя — это ошибка, а не пустое значение.
:::

::: quiz 02-numbers
Что выведет `print(10 / 2)`?

- [ ] `5`
  > Так выведет `10 // 2` — целочисленное деление.
- [x] `5.0`
  > Результат `/` имеет тип `float`, даже при делении нацело. Значение здесь — ровно пять, вывод — `5.0`.
- [ ] `5,0`
  > Python пишет дробную часть через точку.
- [ ] Ошибку: делить целые нельзя
  > Делить целые можно — результат будет иметь тип `float`.
:::

::: quiz 03-strings
`city = "Пермь"`. Что такое `city[-1]`?

- [x] `"ь"` — последний символ
  > Отрицательные индексы считают с конца: `-1` — последний, `-2` — предпоследний.
- [ ] `"П"` — первый символ
  > Первый — `city[0]`.
- [ ] Ошибка индекса `IndexError`
  > Индекс −1 в Python допустим и указывает на последний символ. В строке «Пермь» он существует.
- [ ] `"Перм"` — всё, кроме последнего
  > Это срез `city[:-1]`.
:::

::: quiz 04-lists
`cities = ["Пермь", "Казань"]`, затем `cities = cities.append("Уфа")`. Что теперь в `cities`?

- [ ] `["Пермь", "Казань", "Уфа"]`
  > Так было бы без присваивания: просто `cities.append("Уфа")`.
- [x] `None`
  > `append` меняет список на месте и ничего не возвращает. Присвоив результат, мы затёрли список значением `None`.
- [ ] `"Уфа"`
  > `append` не возвращает добавленный элемент.
- [ ] Ошибку
  > Ошибки не будет, и этим ловушка опасна: она проявится позже.
:::

::: quiz 05-for
Какие числа даст `range(1, 5)`?

- [ ] 1, 2, 3, 4, 5
  > Правая граница в `range` не включается.
- [x] 1, 2, 3, 4
  > От левой границы включительно до правой — не включая, как у срезов.
- [ ] 0, 1, 2, 3, 4
  > С нуля начинается `range(5)`.
- [ ] 1 и 5
  > `range` даёт все числа между границами, а не только сами границы.
:::

::: quiz 06-if
Почему `if revenue = plan:` вызывает синтаксическую ошибку?

- [x] `=` присваивает значение, а для сравнения нужен `==`
  > `if` проверяет истинность значения выражения. Знак `=` присваивает, а здесь нужно сравнение `revenue == plan`.
- [ ] `if` не принимает имена переменных
  > Можно: `if revenue:` проверит само значение. Для числа 0 условие ложно, для 1 — истинно; сравнение необязательно.
- [ ] У сравнения пропущены круглые скобки
  > Скобки не помогут: ошибка в знаке.
- [ ] `plan` нельзя использовать как имя
  > Это обычное имя переменной.
:::

::: quiz 07-tables
`sales = [["Пермь", 412, 205], ["Казань", 538, 198], ["Тюмень", 297, 214]]`. Что вернёт `sales[1][0]`?

- [x] `"Казань"`
  > Первый индекс — строка таблицы (с нуля: 1 — вторая строка), второй — столбец в ней (0 — город).
- [ ] `412`
  > Это `sales[0][1]`: первая строка, второй столбец. Порядок индексов — сначала строка, потом столбец.
- [ ] `"Пермь"`
  > Пермь — строка с индексом 0, а `sales[1]` — вторая строка.
- [ ] Ошибку: двойной индекс не работает
  > Работает: `sales[1]` — список, и к нему снова применяется `[0]`.
:::

::: quiz 08-dicts
Для подсчёта напитков пишут `counts[d] = counts.get(d, 0) + 1`. Зачем здесь `get`, а не `counts[d] + 1`?

- [x] `get` даёт 0, если ключ напитка ещё не создан
  > Это главный приём подсчёта по группам: запасное значение 0 для новых ключей.
- [ ] `get` ускоряет обновление счётчика
  > Скорость тут ни при чём.
- [ ] `get` начинает счёт с нуля вместо единицы
  > Без `get` счёт вообще не начнётся — будет ошибка.
- [ ] `get` упорядочивает ключи по алфавиту
  > Сортировки в этой строке нет.
:::

::: quiz 09-functions
Функция объявлена как `def rub(amount, decimals=0):`. Что будет при вызове `rub(1500)`?

- [x] `amount=1500`, `decimals=0`
  > Параметры со значением по умолчанию можно не передавать.
- [ ] Ошибка: не хватает аргумента `decimals`
  > Ошибка была бы, если бы у `decimals` не было значения по умолчанию.
- [ ] `amount=0`, `decimals=1500`
  > Аргументы без имени заполняют параметры по порядку: первый — `amount`.
- [ ] `amount=1500`, `decimals=None`
  > `None` было бы, только если бы так написали в объявлении.
:::

::: quiz 09b-style
Какая строка оформлена по PEP 8?

- [x] `avg_check = round(revenue / orders, ndigits=2)`
  > Имя в snake_case, пробелы вокруг `=` присваивания и `/`, у именованного аргумента `ndigits=2` пробелов нет.
- [ ] `avgCheck = round(revenue / orders, ndigits=2)`
  > Имя не в snake_case: нужно `avg_check`.
- [ ] `avg_check = round(revenue / orders, ndigits = 2)`
  > У именованного аргумента пробелы вокруг `=` не ставят: `ndigits=2`.
- [ ] `avg_check=round(revenue/orders, ndigits=2)`
  > Вокруг `=` присваивания и вокруг `/` нужны пробелы.
:::

::: quiz 10-tuples-sets
`cities = ["Пермь", "Казань", "Пермь", "Уфа", "Казань", "Пермь"]`. Что даст `len(set(cities))`?

- [x] `3` — число разных городов
  > `set` оставляет каждое значение один раз, как `COUNT(DISTINCT city)` в SQL.
- [ ] `6` — число всех городов
  > Это `len(cities)` — все строки вместе с повторами.
- [ ] `{"Пермь", "Казань", "Уфа"}`
  > Это `set(cities)`, а `len` от него — число элементов.
- [ ] Ошибка: у множества нет длины
  > У множества есть длина, как у списка.
:::

::: quiz 11-comprehensions
Что делает `if` в выражении `[round(p * 1.1) for p in prices if p > 200]`?

- [x] Отбирает цены больше 200, затем повышает их на 10 %
  > `if` в конце генератора — фильтр. Новый список может оказаться короче исходного.
- [ ] Повышает цены выше 200, остальные оставляет в списке
  > Дешёвые не остаются, а пропадают. Чтобы оставить, нужно условие перед `for`: `x if … else y`.
- [ ] Запрещён внутри генератора
  > Можно: это обычный приём.
- [ ] Сортирует цены по возрастанию
  > Порядок элементов сохраняется.
:::

::: quiz 12-errors
`int("12.5")` падает с `ValueError`. Как превратить такую строку в число?

- [x] `float("12.5")`
  > `int` понимает только запись целого числа. Если нужно целое — `int(float("12.5"))` даст 12.
- [ ] `int("12.5", 10)`
  > Второй аргумент — основание системы счисления. Точку он не поможет разобрать.
- [ ] Обернуть `int("12.5")` в `try`
  > `try` позволяет обработать исключение, но не меняет правила преобразования строки в число.
- [ ] `"12.5" + 0`
  > Строку нельзя сложить с числом.
:::

::: quiz 13-files
Что случится, если открыть существующий файл отчёта командой `open("report.md", "w")`?

- [x] Старое содержимое сотрётся
  > Режим `"w"` пишет файл с нуля. Дописать в конец можно в режиме `"a"`.
- [ ] Текст допишется в конец файла
  > Это поведение режима `"a"`.
- [ ] Ошибка: такой файл уже существует
  > Так ведёт себя режим `"x"`, а `"w"` молча перезаписывает.
- [ ] Файл откроется для чтения
  > Для чтения — режим `"r"`, по умолчанию.
:::

::: quiz 14-project
В дневном реестре библиотеки 12 записей о выдаче. У двух стёрто число выданных книг. По десяти читаемым записям выдано 18 книг. Как подписать итог?

- [x] 18 книг по 10 записям с известным количеством
  > Эти 18 книг можно пересчитать. В двух оставшихся записях количество неизвестно, поэтому точный итог дня пока открыт.
- [ ] За весь день выдано ровно 18 книг
  > Такой итог получился бы, если бы в двух нечитаемых записях стояли нули. В реестре этих значений нет.
- [ ] По всем 12 выдачам среднее — 1,5 книги
  > В числитель попали книги из десяти записей, а в знаменатель — все двенадцать. Для читаемых записей можно посчитать среднее: 18 / 10 = 1,8.
- [ ] Книги получили 10 разных читателей
  > Один читатель мог прийти несколько раз. Для такого подсчёта нужны идентификаторы читателей.
:::

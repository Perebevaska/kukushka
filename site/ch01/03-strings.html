Строки и f-строки

Чистим названия городов, вырезаем куски из кодов заказов и собираем аккуратные подписи для отчёта.

0 из 10

Строка — это последовательность символов

Строки мы уже писали: всё, что в кавычках, — строка (тип str). Их можно складывать и узнавать длину:

city = "Казань"
greeting = "Привет, " + city + "!"
print(greeting)
print(len(city))

len (от length) возвращает количество символов. Пробелы и знаки препинания тоже считаются.

Индексы: каждый символ по номеру

У каждого символа есть номер — индекс. Нумерация начинается с нуля:

 К   а   з   а   н   ь
 0   1   2   3   4   5
-6  -5  -4  -3  -2  -1

Отрицательные индексы считают с конца: -1 — последний символ, -2 — предпоследний.

city = "Казань"
print(city[0])
print(city[1])
print(city[-1])
Частая ошибка

Индекс за пределами строки — это ошибка IndexError. В «Казани» 6 символов, значит последний индекс — 5, а не 6:

city = "Казань"
print(city[6])

Срезы: кусок строки

Чтобы взять несколько символов подряд, используют срез s[начало:конец]. Начало включается, конец — нет:

order_id = "ZRN-2026-000153"
print(order_id[0:3])     # символы 0, 1, 2
print(order_id[4:8])     # символы 4, 5, 6, 7

Если начало или конец не указать, срез идёт от начала строки или до конца:

order_id = "ZRN-2026-000153"
print(order_id[:3])      # первые три
print(order_id[9:])      # с 9-го до конца
print(order_id[-3:])     # последние три
Как в SQL

В SQL SUBSTRING('ZRN-2026', 1, 3) начинает счёт с единицы и берёт три символа. В Python то же самое — s[0:3]: счёт с нуля, второе число — где остановиться, а не сколько взять. Удобное правило: длина среза s[a:b] равна b − a.

s = "Зерно"
print(s[1:3])

  • [x] ер

Почему: индекс 1 — это «е» (счёт с нуля), а правая граница 3 не включается: берутся символы 1 и 2.

Разберём вместе: срезы на коде кофейни

Код кофейни PRM-12. Выпишем индексы над каждым символом:

символ P R M - 1 2
индекс 0 1 2 3 4 5
с конца −6 −5 −4 −3 −2 −1
  1. code[0:3] — с 0 до 3, не включая 3: "PRM". Короче — code[:3].
  2. code[4:] — с 4 до конца: "12".
  3. code[-2:] — последние два символа: тоже "12". Удобно, когда длина кода бывает разной.
  4. code[3] — один символ: "-".
  5. len(code) — 6, а последний индекс — 5: индексы начинаются с нуля.
code = "PRM-12"
print(code[:3], code[4:], code[-2:], code[3], len(code))

Что получилось: правая граница среза не входит в срез. Зато длина среза считается вычитанием: [0:3] — три символа, [4:8] — четыре. Если ошиблись на один символ, почти всегда виновата именно правая граница.

Методы строк

Метод — это функция, которая «принадлежит» значению и вызывается через точку: строка.метод(). Вот самые нужные для чистки данных:

Метод Что делает Пример → результат
.strip() убирает пробелы по краям " Пермь " → "Пермь"
.lower() / .upper() все буквы маленькие / большие "Пермь" → "пермь"
.title() каждое слово с большой буквы "нижний тагил" → "Нижний Тагил"
.capitalize() только первая буква строки большая "нижний тагил" → "Нижний тагил"
.replace(a, b) заменяет a на b "1 250".replace(" ", "") → "1250"
.startswith(a) начинается ли строка с a "ZRN-1".startswith("ZRN") → True
.endswith(a) заканчивается ли на a "report.csv".endswith(".csv") → True

Типичная задача аналитика — привести к одному виду названия, которые люди вводили руками:

raw = "   нижний ТАГИЛ  "
clean = raw.strip().title()
print("[" + clean + "]")

Методы можно вызывать цепочкой: raw.strip() возвращает строку, у неё вызывается .title().

Частая ошибка

Методы не меняют исходную строку — они возвращают новую. Результат надо сохранить в переменную:

city = "  Пермь "
city.strip()          # результат посчитан и выброшен
print("[" + city + "]")
city = city.strip()   # а так — сохранён
print("[" + city + "]")
Как в SQL

Соответствия: TRIM → .strip(), UPPER/LOWER → .upper()/.lower(), REPLACE → .replace(), LIKE 'ZRN%' → .startswith("ZRN"), LIKE '%латте%' → "латте" in s.

city.strip()

Почему: strip() вернул новую строку, но её никуда не сохранили. В city по-прежнему 5 букв и 2 пробела.

Есть ли подстрока: оператор in

"а" in "строка" — это вопрос «есть ли внутри?». Ответ — True (да) или False (нет). Это отдельный тип данных, bool; подробно разберём его в уроке про условия.

product = "Капучино на овсяном"
print("овсян" in product)
print("миндал" in product)
print("капучино" in product.lower())   # оба конца в нижнем регистре: True
print("Капучино" in product.lower())   # False: слева большая «К», справа всё маленькое

Регистр важен: in сравнивает символы точно. Чтобы поиск не зависел от регистра, приводите к одному регистру обе стороны — и строку, и то, что ищете.

f-строки: собираем текст из значений

Склеивать строки через + неудобно: числа приходится превращать в текст через str(...) (str(210) → "210", обратное действие к int()), а пробелы легко потерять. Для подписей и отчётов есть f-строки: перед кавычкой ставится буква f, а значения подставляются в фигурных скобках.

name = "Латте"
price = 210
print(f"{name}: {price} ₽")
print(f"Три чашки {name.lower()} стоят {price * 3} ₽")

Внутри {} можно писать любое выражение — Python посчитает его и вставит результат.

Формат чисел

После выражения через двоеточие можно указать формат:

Запись Что получится Пример для x = 1314000.456
{x:.2f} 2 знака после точки 1314000.46
{x:,.2f} + разделитель тысяч 1,314,000.46
{x:.0f} без дробной части 1314000
{share:.1%} процент с 1 знаком для 0.0947 → 9.5% 
revenue = 1314000.456
share = 0.0947
print(f"Выручка: {revenue:,.2f} ₽")
print(f"Доля онлайн-заказов: {share:.1%}")

Разделитель тысяч в Python — запятая, как в англоязычных отчётах. Чтобы получить русский вариант с пробелом, замените запятые после форматирования:

revenue = 1314000.456
text = f"{revenue:,.2f}".replace(",", " ")
print(f"Выручка: {text} ₽")
Совет

{x:.1%} сам умножает на 100 и добавляет знак %. Поэтому в него передают долю (0.0947), а не уже посчитанный процент (9.47).

Старший брат f-строки: метод .format()

В чужом коде встретите запись .format(): пустые {} в строке заполняются значениями из скобок метода по порядку. Формат после двоеточия пишется так же, как в f-строке:

print("{}: {:,.2f} ₽".format("Выручка", 1314000.456))

template = "{shop}: {revenue:,.0f} ₽"     # обычная строка, без f
print(template.format(shop="PRM-1", revenue=412300))

Зачем он, если есть f-строки: шаблон без буквы f можно хранить отдельно и заполнять много раз — например, строку отчёта для каждой кофейни. Для своих строк пишите f-строки.

Типичные ошибки
  • Индекс с единицы. Первый символ — s[0], а s[1] — второй.
  • Метод без сохранения. name.strip() не меняет name, а возвращает новую строку; нужно name = name.strip().
  • Скобки у методов. name.upper без () — сам метод, а не результат.
  • Склейка текста с числом через +. "Цена: " + 210 — ошибка; используйте f-строку.

Год — число, а срезы работают со строками. Как быть?

Что запомнить

  • len(s) — длина строки. Индексы начинаются с 0, s[-1] — последний символ.
  • Срез s[a:b] берёт символы с a по b не включая b. s[:3] — первые три, s[-2:] — последние два.
  • Методы .strip(), .lower(), .upper(), .title(), .replace(a, b) возвращают новую строку — исходная не меняется.
  • подстрока in s даёт True или False; .startswith() и .endswith() — проверка начала и конца.
  • f-строка: f"Выручка: {revenue:,.2f} ₽". Внутри {} — любое выражение, после : — формат.

Списки

Храним много значений в одной переменной — выручку за две недели, меню, города — и считаем по ним сумму, среднее, максимум и топ.

Много значений в одной переменной

Выручка кофейни за неделю — это семь чисел. Заводить семь переменных mon, tue, wed… неудобно. Для набора значений в Python есть список (тип list): значения в квадратных скобках через запятую.

revenue = [41200, 38900, 45100, 39800, 52300, 61700, 58400]
cities = ["Пермь", "Казань", "Тюмень"]
print(revenue)
print(cities)
print(len(cities))

len работает и со списками: возвращает число элементов.

Как в SQL

Список похож на один столбец результата запроса: SELECT revenue FROM daily WHERE week = 41. Порядок значений в списке важен и сохраняется — как в результате с ORDER BY.

Индексы и срезы — как у строк

Всё, что вы знаете про индексы и срезы строк, работает и со списками. Нумерация с нуля, -1 — последний элемент:

revenue = [41200, 38900, 45100, 39800, 52300, 61700, 58400]
print(revenue[0])      # понедельник
print(revenue[-1])     # воскресенье
print(revenue[5:])     # выходные — с 5-го до конца
print(revenue[:5])     # будни — первые пять

Список можно менять

В отличие от строки, список можно изменять «на месте».

Заменить элемент по индексу:

prices = [210, 190, 250]
prices[1] = 195          # поправили цену второго напитка
print(prices)

Добавить в конец — append, удалить по значению — remove:

cities = ["Пермь", "Казань"]
cities.append("Тюмень")
print(cities)
cities.remove("Казань")
print(cities)

Проверить, есть ли значение в списке, — оператор in, как у строк. Узнать индекс значения — метод index:

menu = ["Латте", "Капучино", "Раф", "Американо"]
print("Раф" in menu)
print("Мокко" in menu)
print(menu.index("Раф"))
Частая ошибка

index и remove падают с ошибкой ValueError, если такого значения в списке нет. Если не уверены — сначала проверьте через in.

Очередь у бара: insert, pop, extend

Бариста держит в голове очередь заказов. Новые встают в конец — это append. Но бывает и по-другому: срочный заказ из приложения, оплаченный к точному времени, ставят вперёд; готовый напиток уходит из начала очереди, и нужно знать, какой именно; из приложения прилетает сразу пачка заказов. Для этого у списка есть ещё три метода.

То же кодом:

queue = ["Латте", "Раф", "Чай"]
queue.insert(0, "Американо")   # срочный — вперёд
print(queue)
done = queue.pop(0)            # готов первый — забираем и запоминаем
print("Готов:", done, "| в очереди:", queue)
queue.extend(["Мокко", "Какао"])   # пачка заказов из приложения
print(queue)
last = queue.pop()             # гость отменил последний заказ
print("Отменён:", last, "| позиция Рафа:", queue.index("Раф"))

Здесь важны две вещи. У insert первый аргумент — позиция, второй — значение. А pop в отличие от insert и extend возвращает удалённый элемент, поэтому его результат сохраняют в переменную: done, last. pop() без аргумента берёт последний элемент — удобно для «отменить последнее действие». index список не меняет, а только ищет: после всех сдвигов Раф снова на позиции 1.

Как читать результат: pop — это «удалить и отдать», а remove — «удалить и забыть». Если удалённое значение нужно дальше (что отдать гостю, что записать в журнал), берите pop.

метод что делает что возвращает
lst.append(x) добавляет x в конец None
lst.extend(other) добавляет в конец каждый элемент other None
lst.insert(i, x) вставляет x на позицию i, хвост сдвигается None
lst.pop() / lst.pop(i) удаляет последний / i-й элемент удалённый элемент
lst.remove(x) удаляет первое вхождение x None
lst.index(x) ищет x позицию первого вхождения

None в правом столбце — специальное значение «ничего нет». Его возвращают методы, которые меняют сам список, а не создают новый. Поэтому x = queue.append("Чай") положит в x не список, а None.

Предскажите вывод

Что выведет этот код? Сначала ответьте, потом запустите.

a = [1, 2]
a.append([3, 4])
print(len(a))
  • 4
  • [x] 3
  • 2

Почему: append добавляет один элемент — здесь это целый список [3, 4]. Получилось [1, 2, [3, 4]], три элемента. С extend([3, 4]) было бы четыре.

Типичные ошибки
  • append вместо extend. queue.append(["Мокко", "Чай"]) положит в очередь один элемент-список, и len вырастет на 1, а не на 2.
  • x = lst.extend(...) или x = lst.insert(...). Эти методы возвращают None, как и sort(). Результат — в самом списке.
  • pop() из пустого списка. Сообщение IndexError: pop from empty list. Перед pop проверяйте, что список не пуст: len(queue) > 0.
  • Перепутанные аргументы insert. Сначала позиция, потом значение: insert(0, "Раф"), а не insert("Раф", 0) — второе упадёт с TypeError.

Агрегаты: сумма, минимум, максимум

Для числовых списков есть встроенные функции:

revenue = [41200, 38900, 45100, 39800, 52300, 61700, 58400]
total = sum(revenue)
print("За неделю:", total)
print("Лучший день:", max(revenue))
print("Худший день:", min(revenue))
print("В среднем:", round(total / len(revenue), 2))

Функции для среднего среди встроенных нет: среднее — это сумма, делённая на количество. В pandas (глава 2) для этого будет готовый .mean().

Как в SQL

sum(revenue) — это SUM(revenue), len(revenue) — COUNT(*), max и min — MAX и MIN. Только в SQL функции работают со столбцом таблицы, а здесь — со списком.

Сортировка

sorted(список) возвращает новый список, отсортированный по возрастанию. С параметром reverse=True — по убыванию:

revenue = [41200, 38900, 45100, 39800, 52300, 61700, 58400]
print(sorted(revenue))
print(sorted(revenue, reverse=True))
top3 = sorted(revenue, reverse=True)[:3]
print("Три лучших дня:", top3)
print("Исходный список не изменился:", revenue)

Строки сортируются по алфавиту:

print(sorted(["Тюмень", "Казань", "Пермь"]))
Как в SQL

sorted(revenue, reverse=True)[:3] — это ORDER BY revenue DESC LIMIT 3.

Сортировка на месте

У списка есть и метод .sort(): он сортирует сам список и ничего не возвращает (точнее, возвращает None). Частая ошибка — сохранить его результат:

revenue = [41200, 38900, 45100]
result = revenue.sort()
print(result)     # None
print(revenue)    # а сам список отсортирован

Если нужен отсортированный список в новой переменной — используйте sorted.

  • [3, 1, 2]

Почему: .sort() сортирует сам список и ничего не возвращает — в res попадает None.

Разберём вместе: sort против sorted

Неделя выручки: revenue = [41200, 38900, 45100]. Две похожие строки ведут себя по-разному:

код что вернул что стало с revenue
top = sorted(revenue, reverse=True) новый список [45100, 41200, 38900] не изменился
revenue.sort(reverse=True) None переставлен на месте
top = revenue.sort() None → в top пусто переставлен
  1. sorted(...) — функция: делает копию, сортирует её и возвращает. Исходный порядок дней недели сохранится.
  2. .sort() — метод списка: переставляет элементы внутри самого списка и ничего не возвращает.
  3. Поэтому top = revenue.sort() — частая ловушка: в top оказывается None, а исходный список уже перемешан.
revenue = [41200, 38900, 45100]
top = sorted(revenue, reverse=True)
print(top, revenue)
result = revenue.sort()
print(result, revenue)

Что получилось: если порядок списка что-то значит (дни недели, позиции в меню), берите sorted — оригинал не пострадает. sort() — когда старый порядок точно не нужен.

Проверьте себя

Нужны три лучших дня, но список revenue дальше понадобится в прежнем порядке — по дням. Что использовать?

  • [x] sorted(revenue, reverse=True)[:3]

    sorted возвращает новый отсортированный список, а revenue не трогает.

  • [ ] revenue.sort(reverse=True), затем revenue[:3]

    sort переставляет сам revenue: порядок дней будет потерян.

  • [ ] top = revenue.sort(reverse=True)

    sort ничего не возвращает: в top окажется None, а revenue всё равно переставится.

  • [ ] revenue[-3:]

    Это три последних дня по календарю, а не три лучших.

Из строки в список и обратно

Данные часто приходят строкой с разделителями. Метод split режет строку по разделителю и возвращает список:

line = "Латте;Капучино;Раф;Американо"
menu = line.split(";")
print(menu)
print(len(menu))

Обратная операция — join: склеить список строк, вставив между ними разделитель. Обратите внимание, что метод вызывается у разделителя:

menu = ["Латте", "Капучино", "Раф"]
print(", ".join(menu))
print(" | ".join(menu))
Совет

split() без аргумента режет по любым пробелам и сам убирает лишние: " Пермь Казань ".split() даст ['Пермь', 'Казань'].

Предскажите вывод

Что выведет этот код? Сначала ответьте, потом запустите.

print("-".join(["a", "b", "c"]))
  • -a-b-c-
  • [x] a-b-c
  • ['a', 'b', 'c']

Почему: join ставит разделитель только между элементами, не по краям.

Типичные ошибки
  • x = lst.sort(). Метод возвращает None; для результата — sorted(lst).
  • Индекс за пределами. В списке из 7 элементов последний индекс — 6; lst[7] — IndexError. Последний надёжно — lst[-1].
  • append списка. a.append([1, 2]) добавит один элемент-список; добавить несколько — a.extend([1, 2]).
  • Среднее через len пустого списка. sum([]) / len([]) — деление на ноль.

Что запомнить

  • Список — [1, 2, 3]. Индексы и срезы работают как у строк: days[0], days[-1], days[-7:].
  • Список можно менять: lst[0] = …, lst.append(x), lst.remove(x).
  • lst.insert(i, x) — вставить на позицию, lst.extend(other) — добавить все элементы другого списка, lst.pop(i) — удалить и вернуть элемент (без i — последний), lst.index(x) — позиция значения.
  • len, sum, min, max — длина и агрегаты, как COUNT, SUM, MIN, MAX в SQL.
  • sorted(lst) возвращает новый отсортированный список, reverse=True — по убыванию. lst.sort() сортирует сам список и возвращает None.
  • s.split(";") режет строку в список, ", ".join(lst) склеивает список строк в одну строку.

Словари — GROUP BY своими руками

Словарь хранит пары «ключ → значение». С ним можно быстро найти цену по названию, посчитать заказы по напиткам и выручку по городам — то есть сделать GROUP BY без базы данных.

0 из 10

Ключ и значение

В прошлом уроке цены и названия жили в двух списках, и, чтобы найти цену Рафа, мы искали его позицию через index. Есть способ удобнее — словарь (тип dict). Он хранит пары «ключ → значение»:

prices = {"Латте": 210, "Капучино": 190, "Раф": 260}
print(prices["Раф"])
print(len(prices))

Словарь записывается в фигурных скобках, пары разделяются запятыми, ключ от значения — двоеточием. Значение достаётся по ключу в квадратных скобках — как по индексу в списке, только вместо номера название.

Ключи уникальны: у одного ключа одно значение. Ключом обычно служит строка или число, значением может быть что угодно — число, строка, список, другой словарь.

Аналогия

Гардероб в кофейне: по номерку пальто выдают сразу, не перебирая всю вешалку. Номерок — ключ, пальто — значение, у одного номерка одно пальто. Нет такого номерка — гардеробщик разводит руками: это KeyError.

Как в SQL

Словарь похож на таблицу-справочник с первичным ключом: SELECT price FROM menu WHERE name = 'Раф'. Поиск по ключу в словаре работает мгновенно даже на миллионе записей.

Добавить, изменить, удалить

Присваивание по ключу добавляет пару, если ключа не было, и заменяет значение, если был:

prices = {"Латте": 210, "Капучино": 190}
prices["Мокко"] = 240      # новый ключ — добавили
prices["Латте"] = 220      # существующий — заменили
print(prices)

Удалить пару — del:

prices = {"Латте": 210, "Капучино": 190, "Мокко": 240}
del prices["Мокко"]
print(prices)

Если ключа нет

Обращение к несуществующему ключу — ошибка KeyError:

prices = {"Латте": 210, "Капучино": 190}
print(prices["Раф"])

Есть два способа обойтись без ошибки. Проверить заранее через in (проверяются ключи, а не значения):

prices = {"Латте": 210, "Капучино": 190}
print("Раф" in prices)
print("Латте" in prices)

Или использовать метод get: он возвращает значение, если ключ есть, и значение по умолчанию — если нет:

prices = {"Латте": 210, "Капучино": 190}
print(prices.get("Латте", 0))
print(prices.get("Раф", 0))
print(prices.get("Раф"))      # без второго аргумента — None

None — то самое «ничего» из урока про списки. С ним нельзя считать: None + 210 даст ошибку.

prices = {"Латте": 210}
print(prices.get("Раф") + 210)

Поэтому для подсчётов get почти всегда пишут со вторым аргументом: prices.get(key, 0).

Как в SQL

get(key, 0) — как COALESCE(price, 0) после LEFT JOIN: нет совпадения — подставили значение по умолчанию.

Проверьте себя

prices = {"Латте": 210, "Капучино": 190}. Гость заказал «Мокко», которого нет в меню. Как получить цену так, чтобы программа не упала, а неизвестная позиция стоила 0?

  • [x] prices.get("Мокко", 0)

    get возвращает значение по ключу, а если ключа нет — запасное значение из второго аргумента.

  • [ ] prices["Мокко"]

    Квадратные скобки требуют, чтобы ключ был: здесь программа упадёт с KeyError.

  • [ ] prices.get("Мокко")

    Не упадёт, но вернёт None, и следующее сложение с числом даст ошибку.

    Это проверка «есть ли ключ», она даёт True или False, а не цену.

Цикл по словарю

for по словарю идёт по ключам. Чтобы получить сразу ключ и значение, используйте items():

prices = {"Латте": 210, "Капучино": 190, "Раф": 260}
for name, price in prices.items():
    print(f"{name} — {price} ₽")

Ещё есть keys() и values() — только ключи или только значения. Например, самая дорогая и самая дешёвая позиция меню:

prices = {"Латте": 210, "Капучино": 190, "Раф": 260}
print(max(prices.values()), min(prices.values()))

Главный приём: подсчёт по группам

Вот заказы за час — список напитков. Сколько продано каждого? Заводим пустой словарь и для каждого заказа увеличиваем счётчик:

orders = ["Латте", "Раф", "Латте", "Капучино", "Латте", "Раф"]
counts = {}
for drink in orders:
    counts[drink] = counts.get(drink, 0) + 1
print(counts)

Разберём строку counts[drink] = counts.get(drink, 0) + 1: взяли текущий счётчик (или 0, если напиток встретился впервые), прибавили единицу и записали обратно.

Так же считается сумма по группам. Здесь у каждого заказа есть город и сумма:

orders = [["Пермь", 450], ["Казань", 320], ["Пермь", 610], ["Казань", 280], ["Тюмень", 500]]
by_city = {}
for city, amount in orders:
    by_city[city] = by_city.get(city, 0) + amount
print(by_city)
Как в SQL

Первое — SELECT drink, COUNT(*) FROM orders GROUP BY drink. Второе — SELECT city, SUM(amount) FROM orders GROUP BY city. Ключ словаря — это то, что стоит в GROUP BY, а значение — агрегат.

Разберём вместе: подсчёт по шагам

Пять заказов: Латте, Раф, Латте, Капучино, Латте. Строка в цикле: counts[drink] = counts.get(drink, 0) + 1.

шаг drink counts.get(drink, 0) counts после шага
1 Латте 0 (ключа нет) {Латте: 1}
2 Раф 0 {Латте: 1, Раф: 1}
3 Латте 1 {Латте: 2, Раф: 1}
4 Капучино 0 {Латте: 2, Раф: 1, Капучино: 1}
5 Латте 2 {Латте: 3, Раф: 1, Капучино: 1}
  1. get(drink, 0) отвечает «сколько уже насчитали»; для нового напитка — 0.
  2. + 1 — этот заказ.
  3. Присваивание counts[drink] = … создаёт ключ, если его не было, и перезаписывает, если был.

Если написать counts[drink] += 1 без get, уже на шаге 1 будет KeyError: ключа «Латте» ещё нет, прибавлять не к чему.

orders = ["Латте", "Раф", "Латте", "Капучино", "Латте"]
counts = {}
for drink in orders:
    counts[drink] = counts.get(drink, 0) + 1
    print(drink, counts)

Что получилось: одна строка внутри цикла делает то, что в SQL делает GROUP BY drink + COUNT(*). Замените + 1 на + amount — получится SUM(amount) по группам.

Строка таблицы как словарь

В таблице из списков приходилось помнить, что row[1] — это чашки. Если строку хранить словарём, столбцы называются по именам:

orders = [
    {"city": "Пермь", "drink": "Латте", "amount": 450},
    {"city": "Казань", "drink": "Раф", "amount": 320},
    {"city": "Пермь", "drink": "Раф", "amount": 610},
]
for o in orders:
    print(o["city"], o["amount"])

Список словарей — это уже почти таблица pandas. Во второй главе как раз из такой структуры будем создавать DataFrame.

Типичные ошибки
  • KeyError при первом обращении. counts[x] += 1 для нового ключа падает; используйте get(x, 0).
  • Словарь создаётся внутри цикла. Тогда он обнуляется на каждом шаге.
  • Цикл по словарю даёт только ключи. Пары «ключ, значение» — for k, v in d.items():.
  • Ключи с разным регистром. «Латте» и «латте» — разные ключи; нормализуйте названия заранее.

Что запомнить

  • Словарь — {"Латте": 210, "Раф": 260}. Значение по ключу — d["Латте"], добавить или изменить — d["Мокко"] = 240.
  • Нет ключа → KeyError. Безопасно — d.get(key, по_умолчанию). Проверить — key in d.
  • Цикл по парам: for key, value in d.items():.
  • Подсчёт: counts[x] = counts.get(x, 0) + 1. Сумма по группам: sums[k] = sums.get(k, 0) + amount.

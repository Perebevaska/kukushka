Как устроен курс

Каждый урок — это короткие порции теории с примерами и лестница задач в конце.

Все примеры живые: код можно менять и запускать кнопкой «Запустить» или сочетанием Ctrl+Enter. Python работает прямо в браузере — ничего устанавливать не нужно. Первый запуск занимает несколько секунд: браузер загружает Python. Готовность видна в правом верхнем углу страницы: надпись «Python загружается» сменится на «Python готов».

Попробуйте — нажмите «Запустить»:

print("Привет! Это Python.")

Под кодом появился результат. Теперь поменяйте текст в кавычках и запустите ещё раз. Сломать ничего нельзя: кнопка «Вернуть пример» вернёт исходный код.

Понятно объяснено?

Команда print

print — команда, которая выводит на экран то, что стоит в скобках. Это главный способ посмотреть, что происходит в программе.

print("Сеть кофеен «Зерно»")
print(2026)
print(3 + 4)

Обратите внимание на разницу:

  • текст (в программировании его называют строкой) пишется в кавычках: "Зерно". Кавычки подходят и двойные, и одинарные — главное, одинаковые с обеих сторон;
  • числа пишутся без кавычек. Python умеет с ними считать: print(3 + 4) выведет 7.

Что будет, если число взять в кавычки? Запустите:

print(3 + 4)
print("3 + 4")

Во второй строке Python не считает — для него это просто текст из пяти символов.

Как в SQL

print("Привет") — примерно как SELECT 'Привет'; в SQL: попросить систему показать значение. Только в Python без print на экран ничего не попадёт.

Несколько значений сразу

В print можно передать несколько значений через запятую — Python выведет их в одну строку через пробел:

print("Чашек продано:", 120)
print("Кофейня", "на Ленина", "открыта до", 22, "часов")

Пробелы между значениями Python ставит сам. Если нужен другой разделитель, его задают параметром sep (от separator — разделитель):

print("Москва", "Казань", "Пермь", sep=" | ")
print(2026, 10, 6, sep="-")

Так удобно собирать дату, имя файла или строку CSV из отдельных кусочков.

Программа — это строки сверху вниз

Python выполняет команды по очереди, сверху вниз, по одной в строке:

print("1. Открываем кофейню")
print("2. Варим первый кофе")
print("3. Считаем выручку")

Строки, которые начинаются с #, — комментарии. Python их пропускает, они нужны людям: пояснить код или временно «выключить» строку.

# Это комментарий — он ничего не делает
print("Эта строка выполнится")
# print("А эта — нет: она закомментирована")
Совет

Чтобы закомментировать строку в редакторе, поставьте курсор на неё и нажмите Ctrl+/ — или просто допишите # в начало.

Ошибки — это нормально

Ошибаются все: и новички, и опытные разработчики. Разница в том, что опытные читают сообщение об ошибке — оно почти всегда говорит, что не так.

Запустите код с ошибкой:

print("Кофейня открыта)

Сообщение состоит из трёх частей:

  1. Тип ошибки — SyntaxError, то есть «ошибка записи»: Python не смог разобрать код. Здесь — не закрыта кавычка.
  2. Номер строки, где Python споткнулся.
  3. Пояснение. В этом курсе мы добавляем к каждой ошибке объяснение на русском.

Ещё одна частая ошибка — опечатка в имени:

Print("Привет")

NameError значит «не знаю такого имени». Python различает большие и маленькие буквы: print и Print для него — разные слова.

Как в SQL

Это как в Excel: формула =СУМ(A1:A3) вместо =СУММ(A1:A3) даст ошибку #ИМЯ?. В Python то же самое называется NameError.

Частая ошибка

Кавычки «ёлочки» («») и “лапки” (“”) — это текст, а не кавычки для Python. Код пишется только прямыми кавычками " или '. Внутри строки «ёлочки» использовать можно — как в примере с названием сети.

Разберём вместе: что успеет напечататься

Программа из четырёх строк, в третьей — опечатка:

print("Открываем смену")
print("Касса: 0 ₽")
pirnt("Первый гость")
print("Смена идёт")

Пройдём её так, как это делает Python:

  1. Строка 1 — команда понятна, на экране появляется «Открываем смену».
  2. Строка 2 — тоже понятна, появляется «Касса: 0 ₽».
  3. Строка 3 — pirnt: такого имени Python не знает. Он печатает NameError с номером строки 3 и останавливается.
  4. Строка 4 не выполняется вовсе, хотя в ней всё правильно.

Что получилось: на экране две нормальные строки и сообщение об ошибке. Это подсказка, где искать: всё, что напечаталось, — выше места поломки. Исправляем pirnt на print, запускаем снова — выполняются все четыре строки.

Если ошибок несколько, Python сообщает о первой и останавливается. Исправили — запускайте снова. Такой цикл «запустил → прочитал ошибку → поправил» и есть нормальная работа программиста.

Типичные ошибки
  • Print с большой буквы. Python различает регистр: Print — NameError.
  • Незакрытая кавычка или скобка. SyntaxError: Python не смог даже прочитать программу — не выполнится ни одна строка.
  • «Ёлочки» вместо кавычек кода. print(«Привет») — ошибка; снаружи строки — только " или '.
  • Число в кавычках. "120" — это текст из трёх символов, а не число; позже это будет важно для расчётов.

Что запомнить

  • print(...) выводит на экран текст и числа. Несколько значений — через запятую.
  • Текст пишется в кавычках, числа — без кавычек.
  • Python выполняет строки сверху вниз. Всё после # — комментарий, его Python пропускает.
  • Ошибка — это подсказка: тип ошибки + номер строки + что пошло не так. Читайте с конца.

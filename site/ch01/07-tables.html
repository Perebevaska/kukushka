Таблица из списков

Собираем строки в таблицу — список списков — и делаем с ней то, что обычно делает SELECT: выбираем столбец, считаем итоги, фильтруем и добавляем вычисляемые поля.

0 из 10

Строка таблицы — это список

Вот продажи по кофейням за день: город, число чашек, средняя цена чашки. Одну строку такой таблицы можно хранить списком:

row = ["Пермь", 412, 205]
print(row[0], row[1], row[2])

А всю таблицу — списком строк, то есть списком списков:

sales = [
    ["Пермь", 412, 205],
    ["Казань", 538, 198],
    ["Тюмень", 297, 214],
    ["Уфа", 365, 189],
]
print(len(sales))     # сколько строк
print(sales[1])       # вторая строка целиком
print(sales[1][0])    # строка 1, столбец 0

Два индекса подряд читаются слева направо: sales[1] — это список ["Казань", 538, 198], а [0] берёт из него первый элемент.

Как в SQL

Это результат запроса SELECT city, cups, avg_price FROM sales_day — только без названий столбцов. Какой столбец что значит, держим в голове: 0 — город, 1 — чашки, 2 — цена. В pandas у столбцов появятся имена, и станет удобнее. Но устройство «строки × столбцы» то же.

Почему: t[1] — вторая строка ["b", 2], а [0] берёт её первый элемент.

Проход по строкам

Цикл for по таблице выдаёт строки по одной:

sales = [
    ["Пермь", 412, 205],
    ["Казань", 538, 198],
    ["Тюмень", 297, 214],
]
for row in sales:
    print(row[0], "—", row[1], "чашек")

Распаковка строки

row[0], row[1] читать неудобно. Строку можно распаковать сразу в именованные переменные — столько переменных, сколько значений в строке:

sales = [
    ["Пермь", 412, 205],
    ["Казань", 538, 198],
    ["Тюмень", 297, 214],
]
for city, cups, price in sales:
    print(f"{city}: {cups} чашек по {price} ₽")

Если число переменных не совпадёт с длиной строки, будет ValueError: too many values to unpack или not enough values to unpack.

Столбец, итог, фильтр

Вытащить один столбец в отдельный список:

sales = [
    ["Пермь", 412, 205],
    ["Казань", 538, 198],
    ["Тюмень", 297, 214],
]
cups = []
for row in sales:
    cups.append(row[1])
print(cups)
print("Всего чашек:", sum(cups))

Отобрать строки по условию — тот же фильтр из прошлого урока, только в новый список кладём строку целиком:

sales = [
    ["Пермь", 412, 205],
    ["Казань", 538, 198],
    ["Тюмень", 297, 214],
]
big = []
for row in sales:
    if row[1] > 400:
        big.append(row)
print(big)
Как в SQL

Первое — SELECT cups FROM sales и SELECT SUM(cups) FROM sales. Второе — SELECT * FROM sales WHERE cups > 400.

Проверьте себя

В Перми продали 412 чашек по 205 ₽, в Казани — 538 по 198 ₽, в Тюмени — 297 по 214 ₽. Какая «средняя цена чашки по сети» честная?

  • [ ] Среднее трёх цен: (205 + 198 + 214) / 3

    Так у Тюмени с 297 чашками тот же вес, что у Казани с 538. Средняя цена должна учитывать, где чашек продано больше.

  • [x] Вся выручка, делённая на все чашки

    Это средневзвешенная цена: каждая кофейня входит с весом своих продаж. Именно её получит бухгалтер, разделив деньги на чашки.

  • [ ] Цена кофейни, где продали больше всего чашек

    Это цена одной кофейни, остальные две в расчёт не попали.

  • [ ] Медиана цен

    Медиана тоже не учитывает, сколько чашек продано по каждой цене.

Вычисляемый столбец

Добавим к каждой строке выручку = чашки × цена. Строка — список, значит, к ней можно добавить элемент через append:

sales = [
    ["Пермь", 412, 205],
    ["Казань", 538, 198],
    ["Тюмень", 297, 214],
]
for row in sales:
    row.append(row[1] * row[2])
print(sales)

Теперь у каждой строки четыре значения, и выручка лежит в столбце с индексом 3.

Частая ошибка

row.append(...) меняет исходную таблицу: row — не копия, а та же самая строка из sales. Обычно это и нужно. Но если запустить этот код ещё раз (например, после правки), столбец добавится повторно.

Аналогия

Ярлык на рабочем столе: открыли папку через ярлык и положили в неё файл — файл появился в самой папке, а не в копии. row — такой ярлык на строку из sales. Хромает аналогия в одном: у списка может быть сколько угодно «ярлыков», и все они равноправны — главного нет.

Разберём вместе: два индекса — строка и столбец

Таблица продаж — список списков:

sales = [
    ["Пермь", 412, 205],
    ["Казань", 538, 198],
    ["Тюмень", 297, 214],
]
[0] город [1] чашки [2] цена
sales[0] Пермь 412 205
sales[1] Казань 538 198
sales[2] Тюмень 297 214
  1. sales[1] — вся вторая строка: ["Казань", 538, 198].
  2. sales[1][1] — второй элемент этой строки: 538. Первый индекс — строка, второй — столбец, как адрес ячейки «строка, столбец».
  3. sales[1][1] * sales[1][2] — выручка Казани: 538 × 198 = 106 524.
  4. for city, cups, price in sales: раскладывает каждую строку по трём именам — и вместо row[1] можно писать cups.
sales = [["Пермь", 412, 205], ["Казань", 538, 198], ["Тюмень", 297, 214]]
print(sales[1], sales[1][1], sales[1][1] * sales[1][2])
for city, cups, price in sales:
    print(city, cups * price)

Что получилось: список списков — это таблица Excel без заголовков. Работать с ней можно, но номера столбцов приходится помнить. В главе 2 pandas даст столбцам имена — и row[1] превратится в df["cups"].

Красивый вывод таблицы

Чтобы столбцы стояли ровно, в f-строке задают ширину поля: {x:<10} — выровнять по левому краю в 10 символов, {x:>8} — по правому в 8. Числа принято выравнивать вправо, текст — влево:

sales = [
    ["Пермь", 412, 205],
    ["Казань", 538, 198],
    ["Тюмень", 297, 214],
]
print(f"{'Город':<8}{'Чашки':>7}{'Цена':>7}")
for city, cups, price in sales:
    print(f"{city:<8}{cups:>7}{price:>7}")

Слово 'Город' внутри f-строки записано в одинарных кавычках: сама f-строка уже в двойных, и двойная кавычка внутри закончила бы её раньше времени.

Ширину можно совмещать с форматом числа: {revenue:>10,.0f}.

Типичные ошибки
  • Перепутаны индексы. sales[1][2] — цена Казани, а не чашки; держите перед глазами порядок столбцов.
  • Распаковка не на то число имён. for city, cups in sales: при трёх столбцах — ValueError: too many values to unpack.
  • Среднее из средних. Средняя цена по сети — вся выручка / все чашки, а не среднее цен кофеен.
  • Числа из текста остались строками. После split все значения — текст; int(...) обязателен.

Таблица из текста

Со звёздочкой
↑ К теории: Красивый вывод таблицы

Таблица пришла текстом — как из CSV-файла: строки разделены переводом строки, значения — точкой с запятой. Превратите её в список списков table, где чашки и цена — числа.

Что запомнить

  • Таблица — список строк, каждая строка — список значений: table[1][0] — строка 1, столбец 0.
  • Столбец получают циклом по строкам: for row in table: col.append(row[2]).
  • Строку удобно распаковать: city, cups, price = row.
  • Фильтр строк — цикл + if + append(row); вычисляемый столбец — row.append(…).
  • Выравнивание в f-строках: {x:<10} — влево на 10 символов, {x:>8} — вправо.

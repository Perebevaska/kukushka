Обучение сети: обратное распространение ошибки

Как сеть сама находит веса всех слоёв? Тем же градиентным спуском из главы 10. Новое только одно: градиенты для внутренних слоёв считаются «с конца» — от ошибки на выходе назад к входу. Обучаем двухслойную сеть на numpy и смотрим, как она изгибает границу классов.

0 из 8

Данные: два полумесяца

Возьмём учебную задачу, где классы переплетены «полумесяцами» — прямая их не разделит. Это синтетика из sklearn.datasets.make_moons; представьте, что по двум осям — две характеристики гостя после масштабирования, а цвет — ушёл гость или нет.

import matplotlib.pyplot as plt
from sklearn.datasets import make_moons
from sklearn.linear_model import LogisticRegression

X, y = make_moons(400, noise=0.2, random_state=0)
print("логистическая регрессия:", (LogisticRegression().fit(X, y).predict(X) == y).mean())

fig, ax = plt.subplots(figsize=(5, 4))
ax.scatter(X[:, 0], X[:, 1], c=y, cmap="coolwarm", s=12)
plt.show()

Что здесь происходит:

  • make_moons(400, noise=0.2, random_state=0) — 400 точек двух классов в форме полумесяцев, с небольшим шумом.
  • LogisticRegression().fit(X, y).predict(X) == y — проверка на тех же данных: здесь нас интересует не честная оценка, а может ли модель вообще описать форму классов.
  • ax.scatter(..., c=y, cmap="coolwarm") — точки, раскрашенные по классу.

Логистическая регрессия угадывает 87.5 %: прямая отрезает основную массу, но «рожки» полумесяцев ей недоступны.

Понятно объяснено?

Потеря для классификации

Для вероятностей используют логистическую потерю (кросс-энтропию): за уверенно неправильный ответ штраф огромный, за уверенно правильный — почти ноль.

L = -\operatorname{mean}\big(y \cdot \log p + (1 - y) \cdot \log(1 - p)\big)

Здесь y — правильный ответ (1 — ушёл, 0 — остался), p — предсказанная вероятность ухода, \operatorname{mean} — среднее по всем объектам. Для ушедшего гостя работает только первое слагаемое, для оставшегося — только второе.

Посчитаем штрафы для одного гостя, который действительно ушёл (y = 1):

прогноз p штраф -\log p смысл
0.9 0.105 уверенно и верно — почти не штрафуем
0.5 0.693 «не знаю» — средний штраф
0.1 2.303 уверенно и неверно — штраф в 20 с лишним раз больше

Её не придумывали ради красоты: именно её минимизирует логистическая регрессия в sklearn. А главное удобство — градиент по оценке выходного нейрона z (до сигмоиды) получается совсем простым: p - y. «На сколько ошиблись» — и есть направление исправления. Вывод формулы мы пропустим, а численно проверите её сами в задаче «Проверка формулы p − y» в конце урока.

Выход и потеря зависят от задачи: для регрессии — линейный выход и MSE из главы 10, для двух классов — сигмоида и логистическая потеря. Другие варианты (много классов, несколько меток сразу, счётчики) разберём в уроке «Softmax, выход под задачу и мини-батчи».

import numpy as np
y = np.array([1, 0])
p = np.array([0.75, 0.25])
print((p - y).tolist())
  • [0.75, 0.25]
  • [x] [-0.25, 0.25]
  • [0.25, -0.25]

Почему: для первого объекта модель недодала 0.25 (градиент отрицательный — оценку надо поднять), для второго передала 0.25 (оценку надо опустить).

Типичные ошибки
  • Забыли минус. \log p для вероятностей от 0 до 1 отрицателен, и без минуса «потеря» становится тем меньше, чем хуже прогноз — спуск поведёт модель не туда. Проверка: потеря должна быть положительной, а у прогноза «0.5 всем» — около 0.693.
  • Подставили в формулу метки 0/1 вместо вероятностей. Ровно 0 или 1 в np.log дают -inf, и потеря превращается в inf или nan. В формулу идут вероятности predict_proba, а не predict.

Обратный проход

Сеть: H = \mathrm{relu}(X @ W_1 + b_1), p = \mathrm{sigmoid}(H @ w_2 + b_2). Градиенты считаем «с конца»:

  1. выход: d_2 = (p - y) / n — градиент по оценке выходного нейрона для каждого объекта;
  2. веса выхода: \partial L / \partial w_2 = H^\top @ d_2, \partial L / \partial b_2 = \operatorname{sum}(d_2) — как в линейной модели, только признаки — это H;
  3. назад в скрытый слой: ошибка каждого скрытого нейрона = d_2 \times его вес в w_2 — в коде это np.outer(d2, w2): таблица «объекты × нейроны», в клетке (i, j) произведение d_2[i] \cdot w_2[j]; дальше ошибка проходит только через «включённые» нейроны — умножаем на производную ReLU (Z_1 > 0);
  4. веса скрытого слоя: \partial L / \partial W_1 = X^\top @ dH, \partial L / \partial b_1 — сумма dH по объектам.

Здесь n — число объектов, \partial L / \partial w — градиент потери по весу w (на сколько изменится потеря, если чуть сдвинуть вес), H^\top и X^\top — транспонированные матрицы, dH — ошибка скрытых нейронов из шага 3.

Это и есть обратное распространение ошибки (backpropagation): цепное правило дифференцирования, применённое слой за слоем.

Аналогия

Гость получил холодный капучино, и управляющий разбирает цепочку с конца: сначала выдача, потом бариста, потом кофемашина. Доля «вины» каждого звена считается из вины следующего звена и того, насколько сильно его работа на это следующее звено влияла, — поэтому за один проход назад каждый получает свою поправку. Отличие: в сети «вина» — это не оценка, кто виноват, а точное число — направление и размер поправки каждого веса, и считается она по формуле, без разбирательств.

Посмотрим на цепочку на самой маленькой сети: один вход x = 1, один скрытый нейрон с весом w_1 = 0.5 и ReLU, выход с весом w_2 = 2, гость ушёл (y = 1).

Вперёд:

  1. z_1 = x \cdot w_1 = 0.5; h = \mathrm{relu}(0.5) = 0.5;
  2. z_2 = h \cdot w_2 = 1.0; p = \mathrm{sigmoid}(1.0) \approx 0.731.

Назад:

  1. d_2 = p - y = 0.731 - 1 = −0.269 — оценку выхода надо поднять;
  2. градиент по w_2: d_2 \cdot h = -0.269 \cdot 0.5 = −0.134: «увеличь w_2»;
  3. ошибка скрытого нейрона = d_2 \cdot w_2 = -0.538; ReLU пропускает её, потому что z_1 > 0;
  4. градиент по w_1: -0.538 \cdot x = −0.538: «увеличь и w_1».

Шаг спуска вычитает градиенты (умноженные на шаг обучения), поэтому оба веса вырастут, p приблизится к 1. В сети с матрицами то же самое делается для всех нейронов и объектов сразу:

import numpy as np
from sklearn.datasets import make_moons

X, y = make_moons(400, noise=0.2, random_state=0)
rng = np.random.default_rng(0)
hidden = 16
W1 = rng.normal(size=(2, hidden)) * 0.5
b1 = np.zeros(hidden)
w2 = rng.normal(size=hidden) * 0.5
b2 = 0.0
lr = 0.5

for step in range(2000):
    # прямой проход
    Z1 = X @ W1 + b1
    H = np.maximum(0, Z1)
    p = 1 / (1 + np.exp(-(H @ w2 + b2)))
    # обратный проход
    d2 = (p - y) / len(y)
    g_w2, g_b2 = H.T @ d2, d2.sum()
    dH = np.outer(d2, w2) * (Z1 > 0)
    g_W1, g_b1 = X.T @ dH, dH.sum(axis=0)
    # шаг спуска
    W1 -= lr * g_W1
    b1 -= lr * g_b1
    w2 -= lr * g_w2
    b2 -= lr * g_b2
    if step % 500 == 0 or step == 1999:
        loss = -np.mean(y * np.log(p) + (1 - y) * np.log(1 - p))
        print(f"шаг {step}: потеря {loss:.3f}, верных {((p > 0.5) == y).mean():.3f}")

Что здесь происходит:

строка что считает форма
Z1 = X @ W1 + b1 оценки скрытых нейронов (400, 16)
H = np.maximum(0, Z1) ReLU — новые признаки (400, 16)
p = sigmoid(H @ w2 + b2) вероятности (400,)
d2 = (p - y) / len(y) ошибка на выходе, делённая на n (потеря — среднее) (400,)
g_w2 = H.T @ d2 градиент весов выхода (16,)
dH = np.outer(d2, w2) * (Z1 > 0) ошибка каждого скрытого нейрона у каждого объекта; через выключенные ReLU не проходит (400, 16)
g_W1 = X.T @ dH градиент весов скрытого слоя (2, 16)
W1 -= lr * g_W1 и т. д. шаг спуска —

Формы градиентов совпадают с формами весов — так и должно быть: у каждого веса свой градиент.

Потеря падает, доля правильных растёт до 96 % — заметно лучше логистической регрессии. Сеть из 16 скрытых нейронов сама построила изогнутую границу.

Частая ошибка

Начальные веса — случайные и маленькие. Если начать с нулей, все скрытые нейроны получат одинаковые градиенты, обновятся одинаково и навсегда останутся копиями друг друга — сеть фактически будет из одного нейрона. Случайность «разбивает симметрию».

Проверьте себя

Зачем в обратном проходе ошибку скрытого слоя умножают на (Z1 > 0)?

  • [x] Если оценка нейрона отрицательна, ReLU выдаёт ноль при любых небольших изменениях его весов — производная равна нулю, и ошибка через этот нейрон к его весам не проходит

    Это производная ReLU по цепному правилу: 1 там, где нейрон «включён», и 0 там, где выключен.

  • [ ] Чтобы отбросить объекты, на которых сеть ошиблась в меньшую сторону

    Маска строится по оценке нейрона Z1, а не по знаку ошибки. Отрицательные градиенты нужны — они говорят «увеличь вес».

  • [ ] Это защита от переобучения: часть нейронов выключают, чтобы сеть не полагалась на отдельные нейроны

    Такой приём есть — случайно выключать нейроны (dropout, урок «Dropout, BatchNorm и smoke-test»). Но здесь маска не случайна — это точная производная активации, без неё градиенты были бы просто неверными.

  • [ ] Чтобы градиенты не становились слишком большими

    Маска не ограничивает размер градиента, а обнуляет его там, где нейрон выключен; там, где включён, ошибка проходит без изменений.

Сколько нейронов нужно

Число нейронов в скрытом слое — гиперпараметр, как глубина дерева. С одним-двумя нейронами на полумесяцах этого урока сеть угадывает около 88 % — почти как логистическая регрессия (87.5 %), с 16 — уверенно описывает полумесяцы (96 %). Лишние нейроны опасны, когда данных мало: граница начинает обходить отдельные шумные точки — переобучение. На 300 обучающих точках 64 нейрона ещё не вредят, а на 30 точках сеть из 64 нейронов запоминает обучение на 100 % и на новых данных угадывает хуже маленькой — это вы увидите сами в задаче «Сколько нейронов». Защищаются привычно: отложенная выборка, ранняя остановка, регуляризация (урок «Нейросеть в sklearn: MLP»).

Проверьте себя

Все веса сети инициализировали нулями. Что произойдёт при обучении?

  • [x] Все нейроны скрытого слоя получат одинаковые градиенты и останутся одинаковыми — сеть будет работать как один нейрон

    Случайная инициализация нарушает симметрию: каждый нейрон начинает со своих весов и учится своему признаку.

  • [ ] Сеть обучится, просто медленнее

    Симметрия не нарушится никогда: одинаковые нейроны получают одинаковые обновления.

  • [ ] Ошибка деления на ноль

    Деления на веса нет — ошибки не будет, будет бесполезная сеть.

  • [ ] Ничего: нули — хорошее начало

    Для одного нейрона — да, для слоя — нет.

Разберём вместе: что делает шаг обучения

Шаг обучения lr для сети — такой же гиперпараметр, как в главе 10. Слишком маленький — сеть учится медленно и за отведённые шаги не успевает; слишком большой — «перепрыгивает» минимум, и потеря скачет или растёт. На полумесяцах из раздела «Обратный проход» (тот же цикл: 2000 шагов, 16 нейронов):

lr потеря в конце верных
0.05 ≈ 0.25 ≈ 0.90
0.5 ≈ 0.09 ≈ 0.96
5 ≈ 0.09 ≈ 0.97
20 ≈ 0.90 ≈ 0.77

При lr = 0.05 сеть недоучилась — почти как логистическая регрессия. При lr = 20 веса разлетаются: ReLU-нейроны «умирают» (их Z1 становится отрицательной для всех объектов, и градиент через них больше не проходит), сеть ломается. Широкая полоса между — от 0.5 до 5 — работает; выбирают обычно середину и следят за кривой потерь. Таблицу вы получите сами в задаче «Шаг обучения».

Проверка градиентов

Ошибиться в формулах обратного прохода легко, а сеть с неправильными градиентами иногда всё равно как-то учится — и ошибку не заметно. Поэтому градиенты проверяют численно (глава 10): сдвигаем один вес на \varepsilon и смотрим, как меняется потеря. Это делают один раз при написании кода; библиотеки вроде PyTorch считают градиенты автоматически, и этот шаг там не нужен.

Проверим цепочку из примера с одним нейроном: аналитический градиент по w1 должен совпасть с численным.

import numpy as np

def loss(w1, w2, x=1.0, y=1):
    h = max(0.0, x * w1)
    p = 1 / (1 + np.exp(-h * w2))
    return -(y * np.log(p) + (1 - y) * np.log(1 - p))

w1, w2, eps = 0.5, 2.0, 1e-5
p = 1 / (1 + np.exp(-max(0.0, w1) * w2))
analytic = (p - 1) * w2 * 1.0                      # d2 · w2 · x, ReLU пропускает
numeric = (loss(w1 + eps, w2) - loss(w1 - eps, w2)) / (2 * eps)
print(round(analytic, 6), round(numeric, 6))

Что здесь происходит:

  • loss(w1, w2) — потеря сети как функция весов (прямой проход внутри).
  • Численная производная — разность потерь при чуть большем и чуть меньшем w1, делённая на 2\varepsilon (центральная разность из главы 10).
  • Совпадение до 6 знаков означает, что формула обратного прохода верна.
Типичные ошибки
  • Слишком маленький \varepsilon. В примере выше при \varepsilon = 10^{-5} численный градиент совпадает с формулой до 10 знаков после запятой, а при \varepsilon = 10^{-12} — только до трёх: разность двух почти равных потерь тонет в ошибках округления, и верная формула выглядит «неверной». Рабочий диапазон — 10^{-4}…10^{-6}.
  • Проверка в точке излома ReLU. Если у какого-то объекта оценка нейрона z ровно около нуля, сдвиг на \pm\varepsilon перескакивает излом, и численная производная — среднее двух наклонов. Берите случайные веса и проверяйте несколько точек.
  • Численный градиент в цикле обучения. Он требует двух прямых проходов на каждый вес: у сети из раздела «Обратный проход» 2 · 16 + 16 + 16 + 1 = 65 параметров — это 130 прямых проходов на один шаг вместо одного обратного прохода. Проверку делают один раз на маленьком примере, а учат на формуле.

Проверка обратного прохода

Со звёздочкой
↑ К теории: Проверка градиентов

Убедитесь, что формулы обратного прохода верны. Для маленькой сети из заготовки посчитайте аналитический градиент потери по элементу W1[0, 1] (по формулам из теории) и численный — сдвигая этот элемент на ±1e-5 и пересчитывая потерю. Сохраните g_analytic, g_numeric (6 знаков) и rel_err — |a − n| / (|a| + |n|).

Что запомнить

  • Для классификации потеря — логистическая (кросс-энтропия): −mean(y·log p + (1−y)·log(1−p)).
  • Для сигмоиды на выходе с кросс-энтропией градиент по оценке z простой: p − y.
  • Обратное распространение (backprop): градиент выходного слоя → через веса передаётся в скрытый слой → умножается на производную активации → градиенты весов скрытого слоя.
  • Каждый шаг обучения: прямой проход → потеря → обратный проход → шаг спуска по всем весам.
  • Начальные веса — маленькие случайные числа: если все одинаковые, нейроны слоя навсегда останутся одинаковыми.
  • Правильность градиентов проверяют численно, как в главе 10.

Нейрон и слои

Нейросеть звучит загадочно, но её кирпичик вам уже знаком: взвешенная сумма признаков плюс нелинейная «функция активации» — почти логистическая регрессия. Собираем нейрон и маленькую сеть на numpy и разбираемся, зачем нужны слои.

0 из 9

Нейрон — это знакомая формула

Нейрон берёт признаки, считает взвешенную сумму и пропускает её через функцию активации:

z = x_1 w_1 + x_2 w_2 + \ldots + b = x @ w + b, \qquad a = f(z)

Здесь x_1, x_2, \ldots — признаки, w_1, w_2, \ldots — их веса, b — сдвиг, z — взвешенная сумма (оценка), f — функция активации, a — выход нейрона. Если f — сигмоида \dfrac{1}{1 + e^{-z}}, получается логистическая регрессия из главы 6: вероятность от 0 до 1.

Аналогия

Нейрон похож на опытного бариста, который прикидывает, не потеряет ли кофейня гостя: он смотрит на несколько сигналов (давно ли гость заходил, жаловался ли, есть ли у него приложение), каждому придаёт свою важность — это веса, — добавляет собственную склонность «скорее уйдёт» или «скорее останется» — это сдвиг — и по итоговой сумме решает, насколько он уверен, что гость уйдёт. Сигмоида превращает эту сумму в уверенность от 0 до 1. Разница в одном: живой бариста рассуждает как угодно сложно, а нейрон умеет только сложить сигналы с весами и один раз «изогнуть» результат — вся сложность сети берётся из того, что таких нейронов много и они соединены слоями.

import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

x = np.array([45.0, 1.0, 0.0])        # дней с визита, жалоб, есть приложение
w = np.array([0.04, 1.2, -0.6])
b = -2.0
z = x @ w + b
print(round(float(z), 2), round(float(sigmoid(z)), 3))

Посчитаем руками. Гость: 45 дней с визита, 1 жалоба, приложения нет.

  • взвешенная сумма: 45 · 0.04 + 1 · 1.2 + 0 · (−0.6) = 1.8 + 1.2 + 0 = 3.0;
  • плюс сдвиг: z = 3.0 − 2.0 = 1.0;
  • сигмоида: 1 / (1 + e⁻¹) = 1 / (1 + 0.368) ≈ 0.73.

Что здесь происходит в коде:

  • x @ w — скалярное произведение векторов признаков и весов (глава 9): та же взвешенная сумма.
  • b — сдвиг (в логистической регрессии — intercept_).
  • sigmoid(z) превращает любое число в вероятность от 0 до 1.

Оценка z = 1.0, вероятность ухода 0.73. Один нейрон — одна логистическая регрессия. Сила нейросетей появляется, когда нейронов много и они соединены слоями.

Функции активации

Активация добавляет нелинейность — изгиб, без которого любые слои складываются в одну линейную формулу. Самые популярные:

  • сигмоида — сжимает любое число в 0…1, удобна на выходе для вероятности;
  • ReLU (rectified linear unit) — \max(0, z): отрицательное превращает в ноль, положительное пропускает как есть. Простая и быстрая, основная активация скрытых слоёв;
  • tanh — как сигмоида, но от −1 до 1.
import numpy as np
z = np.array([-3.0, -0.5, 0.0, 0.5, 3.0])
print("сигмоида:", (1 / (1 + np.exp(-z))).round(3))
print("ReLU:    ", np.maximum(0, z))
print("tanh:    ", np.tanh(z).round(3))

Что видно в выводе:

z сигмоида ReLU tanh
−3 0.047 0 −0.995
0 0.5 0 0
3 0.953 3 0.995

Сигмоида и tanh «насыщаются»: при больших |z| почти не меняются — это потом затрудняет обучение (градиент почти ноль). ReLU для положительных z растёт без ограничений и не насыщается — одна из причин её популярности.

Типичные ошибки
  • Сигмоида во всех скрытых слоях глубокой сети. Наклон сигмоиды не больше 0.25 (в точке z = 0), а при обратном проходе (урок «Обучение сети: обратное распространение ошибки») наклоны слоёв перемножаются — сигнал ошибки к первым слоям почти не доходит. В скрытых слоях — ReLU, сигмоида — на выходе.
  • ReLU на выходе бинарной задачи. Выход ReLU — от 0 до бесконечности, это не вероятность. Для «уйдёт ли гость» на выходе сигмоида.
  • «Мёртвые» нейроны ReLU. Если у нейрона z < 0 для всех объектов, он всегда выдаёт 0 и больше не учится: наклон в левой половине — ноль. Проверка: доля столбцов скрытого слоя, где все значения нулевые, — (H == 0).all(axis=0).mean().

Слой — матричное умножение

Слой из k нейронов — это k нейронов с разными весами, которые смотрят на одни и те же признаки. Веса слоя удобно сложить в матрицу W (признаки × нейроны), и тогда весь слой для всех объектов сразу — одно умножение из главы 9:

Z = X @ W + b, \qquad A = f(Z)

Здесь X — объекты × признаки, W — признаки × нейроны, b — сдвиги нейронов, Z — оценки всех нейронов для всех объектов, A — выходы слоя после активации.

import numpy as np
rng = np.random.default_rng(0)
X = np.array([[45.0, 1, 0],
              [3.0, 0, 1]])           # два гостя, три признака
W = rng.normal(size=(3, 4)) * 0.1     # слой из 4 нейронов
b = np.zeros(4)
A = np.maximum(0, X @ W + b)          # ReLU
print(A.shape)
print(A.round(3))

Что здесь происходит:

  • X — 2 гостя × 3 признака; W — 3 признака × 4 нейрона: столбец W[:, j] — веса нейрона j.
  • X @ W — матрица 2 × 4: в клетке (i, j) — взвешенная сумма признаков гостя i с весами нейрона j. Правило формы (глава 9): (2 × 3) @ (3 × 4) → (2 × 4).
  • + b — сдвиг каждого нейрона прибавляется ко всем строкам (broadcasting).
  • np.maximum(0, ...) — ReLU поэлементно.

Форма (2, 4): для каждого из двух гостей слой выдал 4 новых числа. Это новые признаки, которые сеть строит сама. Следующий слой смотрит уже на них.

Типичные ошибки
  • Матрица весов «боком». Если создать W формы (4, 3) — нейроны × признаки, — X @ W упадёт: ValueError: matmul: Input operand 1 has a mismatch in its core dimension 0 ... (size 4 is different from 3). Внутренние размеры должны совпасть: (2 × 3) @ (3 × 4). Строк в W столько, сколько признаков, столбцов — сколько нейронов.
  • Сдвиг формы (2,) вместо (4,). Сдвигов столько, сколько нейронов, а не объектов: b = np.zeros(4). Сдвиг по числу объектов либо упадёт, либо (если числа случайно совпадут) прибавится не к тем клеткам.

Зачем больше одного слоя

Классическая задача, которую не решает ни один нейрон: гость уходит, если ровно одно из двух — «давно не был» или «жаловался» (например, жалобщики, которые часто ходят, остаются, потому что их проблему решили). Классы расположены «крест-накрест», и никакая прямая их не разделит. А сеть со скрытым слоем из двух нейронов — разделяет: первый нейрон ловит «хотя бы одно», второй — «оба сразу», выход — «первое, но не второе».

import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]])    # давно не был, жаловался
y = np.array([0, 1, 1, 0])                          # ушёл: ровно одно из двух

W1 = np.array([[20.0, 20.0],
               [20.0, 20.0]])
b1 = np.array([-10.0, -30.0])        # нейрон 1: «хотя бы одно», нейрон 2: «оба»
H = sigmoid(X @ W1 + b1)
w2 = np.array([20.0, -40.0])
b2 = -10.0
out = sigmoid(H @ w2 + b2)
print(H.round(2))
print(out.round(2), "← прогноз; факт:", y)

Разберём по шагам для гостя (1, 0) — давно не был, не жаловался:

  1. Нейрон 1: 20·1 + 20·0 − 10 = 10 → сигмоида ≈ 1.00: «хотя бы одно» — да.
  2. Нейрон 2: 20·1 + 20·0 − 30 = −10 → сигмоида ≈ 0.00: «оба» — нет.
  3. Выход: 20·1.00 − 40·0.00 − 10 = 10 → сигмоида ≈ 1.00: ушёл.

А для гостя (1, 1): нейрон 1 ≈ 1, нейрон 2 ≈ 1 (20 + 20 − 30 = 10), выход 20 − 40 − 10 = −30 → ≈ 0: остался. Скрытый слой построил два новых признака, и в их пространстве классы разделяются прямой.

Аналогия

Это как отчёт в SQL, где по двум флагам нужно отобрать «ровно один из двух». Одним условием вида a·x + b·y > c такой фильтр не написать, но если сначала добавить вычисляемые столбцы «хотя бы один» и «оба» (два CASE WHEN), итоговый фильтр становится простым: «первый столбец да, второй нет». Скрытый слой и есть такие вычисляемые столбцы, только сеть придумывает их сама. Но есть отличие: сеть не знает заранее, какие столбцы нужны, — она подбирает их при обучении, и обычно они не имеют такого понятного смысла.

Веса здесь подобраны руками, чтобы было видно идею. В следующем уроке сеть найдёт такие веса сама.

Заметка

Почему без активации слои бесполезны: (X @ W_1) @ W_2 = X @ (W_1 @ W_2) — это снова одна линейная модель с весами W_1 @ W_2. Нелинейность между слоями — то, что делает «глубину» осмысленной.

Проверьте себя

Зачем между слоями нужна нелинейная активация, например ReLU?

  • [x] Без неё несколько слоёв схлопываются в один линейный слой, и сеть не может нарисовать кривую границу

    (X @ W1) @ W2 = X @ (W1 @ W2). ReLU ломает это равенство — так появляются изгибы границы.

  • [ ] Чтобы сеть быстрее обучалась

    Скорость здесь вторична. Главное — выразительность.

  • [ ] Чтобы выход был от 0 до 1

    Это задача сигмоиды на выходе, а не активаций между слоями.

  • [ ] Чтобы уменьшить число параметров

    Активация не добавляет и не убирает параметры.

Прямой проход

Вычисление прогноза слой за слоем называют прямым проходом (forward pass). Сеть из двух слоёв:

  1. H = \mathrm{relu}(X @ W_1 + b_1) — скрытый слой, новые признаки;
  2. p = \mathrm{sigmoid}(H @ w_2 + b_2) — выход, вероятность.

Всё, что мы знаем о моделях, остаётся в силе: нужны признаки в одном масштабе (глава 7), обучающая и тестовая выборки (глава 6), метрики (глава 7). Новое — только как подбирать веса, когда слоёв несколько. Об этом следующий урок.

До обучения веса сети — маленькие случайные числа, как в примерах этого урока (rng.normal(...) * 0.1). Их масштаб важен: в глубокой сети слишком большие веса раздувают сигнал от слоя к слою, слишком маленькие — гасят. Как подобрать масштаб (инициализации Xavier и He), разберём в уроке «Граф вычислений, инициализация и обрезка градиента», когда уже будет видно и прямой, и обратный проход.

Разберём вместе: сколько параметров у сети

Каждый вес и каждый сдвиг — параметр, который нужно подобрать при обучении. Чем их больше, тем гибче сеть — и тем больше данных нужно, чтобы она не переобучилась.

Сеть «10 признаков → 16 нейронов → 8 нейронов → 1 выход»:

слой веса сдвиги всего
10 → 16 10 · 16 = 160 16 176
16 → 8 16 · 8 = 128 8 136
8 → 1 8 · 1 = 8 1 9
итого 321 
def n_params(sizes):
    total = 0
    for n_in, n_out in zip(sizes[:-1], sizes[1:]):    # пары соседних слоёв
        total += n_in * n_out + n_out                   # веса + сдвиги
    return total

print(n_params([10, 16, 8, 1]))
print(n_params([10, 1]))          # логистическая регрессия
print(n_params([10, 256, 256, 1]))

Что здесь происходит:

  • zip(sizes[:-1], sizes[1:]) — пары «вход слоя, выход слоя»: (10, 16), (16, 8), (8, 1).
  • У каждого слоя n_in · n_out весов и n_out сдвигов.

Что получилось: логистическая регрессия на 10 признаках — 11 параметров, маленькая сеть — 321, а сеть с двумя слоями по 256 нейронов — больше 68 тысяч. На 2400 гостях из guests_churn.csv (глава 7; с ними работаем в уроке «Нейросеть в sklearn: MLP») последняя легко «запомнит» обучающую выборку — вот почему там понадобятся регуляризация и ранняя остановка.

Проверьте себя

Сеть «10 → 16 → 8 → 1» заменили на «10 → 256 → 256 → 1» и обучают на тех же 2400 гостях из guests_churn.csv. Что главным образом изменилось?

  • [x] Параметров стало больше 68 тысяч вместо 321: сеть гибче, но легко «запомнит» обучающих гостей, поэтому без регуляризации и ранней остановки тест может стать хуже

    Гибкость — палка о двух концах: чем больше параметров на те же данные, тем проще подогнаться под шум обучающей выборки.

  • [ ] Сеть гарантированно точнее на тесте: больше нейронов — больше новых признаков

    Больше признаков помогает на обучении, но качество на новых данных проверяют отложенной выборкой — и при избытке параметров оно часто падает.

  • [ ] Параметров стало больше в основном за счёт сдвигов

    Сдвигов всего по одному на нейрон, а весов — n_in · n_out на слой: один слой 256 → 256 даёт 256 · 256 = 65 536 весов.

  • [ ] Число параметров не изменилось: оно зависит только от числа признаков на входе

    Вход тот же (10 признаков), но каждый скрытый нейрон приносит свои веса и сдвиг — параметры складываются по всем слоям.

Скрытый слой как новые признаки

Со звёздочкой
↑ К теории: Зачем больше одного слоя

Сеть из теории можно понять как логистическую регрессию над новыми признаками. Посчитайте скрытый слой H = sigmoid(X @ W1 + b1) (данные «крест» из прошлой задачи) и обучите LogisticRegression() на H вместо X. Сохраните H (округлите до 2 знаков) и acc_on_h — долю правильных ответов на тех же 4 точках.

Что запомнить

  • Нейрон: z = x @ w + b, затем активация a = f(z). С сигмоидой это ровно логистическая регрессия.
  • Популярные активации: сигмоида (0…1), ReLU = max(0, z) (обнуляет отрицательное), tanh (−1…1).
  • Слой — много нейронов сразу: Z = X @ W + b, где у W столько столбцов, сколько нейронов.
  • Без нелинейной активации несколько слоёв схлопываются в один линейный: (X @ W1) @ W2 = X @ (W1 @ W2).
  • Скрытый слой строит новые признаки из старых — поэтому сеть может решать задачи, где классы не разделяются прямой.
  • Прямой проход (forward) — вычисление прогноза слой за слоем.
  • Начальные веса сети — маленькие случайные числа. Их масштаб важен; как его выбрать (Xavier и He), разбираем в уроке «Граф вычислений, инициализация и обрезка градиента».

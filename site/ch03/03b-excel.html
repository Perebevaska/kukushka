Книга Excel: листы, шапка, итоги

В уроке «Типы: из текста в числа и даты» текст превращался в числа и даты, а потери мы научились проверять. Здесь тот же вопрос — как прочитать таблицу, чтобы типы получились правильными, — но для книги Excel.

Финансовый отдел прислал книгу zerno_finance.xlsx — план и факт выручки по кофейням за 2026 год. Директор спрашивает: какая кофейня за девять месяцев сильнее всех отстаёт от плана? Книгу делали для людей: сверху заголовок, внизу строка «Итого», справа комментарии. Человеку это удобно, а pandas примет заголовок за названия столбцов, а «Итого» — за ещё одну кофейню. Поэтому при чтении лишнее отрезают параметрами.

Аналогия

Представьте, что переписываете данные с бумажного бланка в свою таблицу. Шапку бланка («Сеть кофеен „Зерно“, план на 2026 год») вы пропускаете, переносите только нужные графы, а строку «Итого» не переписываете — посчитаете её сами. Параметры чтения говорят pandas то же самое: сколько строк пропустить, какие столбцы взять. Одно отличие: строку «Итого» pandas сам не узнает — её убирают отдельным фильтром.

Как устроен лист «План»

Так лист выглядит в Excel (слева номера строк Excel, сверху буквы столбцов):

    | A                                | B       | C            | D      | E      | … | P
  1 | Сеть кофеен «Зерно»              |         |              |        |        |   |
  2 | План выручки на 2026 год, тыс. ₽ |         |              |        |        |   |
  3 |                                  |         |              |        |        |   |
  4 | Код                              | Кофейня | Город        | Янв    | Фев    | … | Год
  5 | PRM-1                            | Ленина  | Пермь        | 1194.6 | 1144.4 | … | 14087.2
  … | …                                | …       | …            | …      | …      | … | …
 11 | EKB-1                            | Вайнера | Екатеринбург |        |        | … | 2706.6
 12 | Итого                            |         |              | 5733.1 | 5508.9 | … | 70761.0

Разберём по строкам:

  1. Строки 1–3 — заголовок листа и пустая строка. Их нужно пропустить: три строки.
  2. Строка 4 — настоящие названия столбцов.
  3. Строки 5–11 — данные: семь кофеен. У EKB-1 январь–сентябрь пусты — она открывается в октябре.
  4. Строка 12 — «Итого». Это не кофейня, а сумма строк 5–11. Если её оставить, любая сумма по столбцу удвоится: 5733.1 за январь превратится в 11 466.2.

read_excel: какой лист и откуда начинать

Книгу Excel читают функцией pd.read_excel — и прямо здесь, в браузере, и у себя в Jupyter. Сначала полезно узнать, какие в книге листы: sheet_name=None читает все листы сразу и возвращает словарь «имя листа → таблица».

import pandas as pd
book = pd.read_excel("zerno_finance.xlsx", sheet_name=None)   # все листы
print(type(book))
print(list(book))
book["Описание"]

Что здесь происходит:

  • sheet_name=None — «все листы». Результат — не таблица, а словарь (dict): ключи — имена листов, значения — таблицы.
  • list(book) — список ключей словаря, то есть имён листов в порядке вкладок Excel.
  • book["Описание"] — таблица одного листа, обращение по имени, как к значению в любом словаре. На «Описании» только пара строк текста: что за книга и в каких единицах суммы.

Что получилось: в книге три листа — «Описание», «План», «Факт». Данные — на втором и третьем.

Как в SQL

sheet_name=None похоже на просмотр списка таблиц в схеме (SHOW TABLES или information_schema.tables) — с той разницей, что pandas сразу и читает каждую.

Лист как есть и без шапки

Прочитаем лист «План» без лишних параметров — только имя листа:

import pandas as pd
raw = pd.read_excel("zerno_finance.xlsx", sheet_name="План")
print(raw.columns[:4].tolist())
raw.iloc[:4, :4]

Заголовком стала первая строка листа — «Сеть кофеен «Зерно»», остальные столбцы pandas назвал Unnamed: 1, Unnamed: 2… Настоящие названия («Код», «Кофейня») оказались в строке данных с индексом 2. И месяцы — не числа: в столбце Unnamed: 3 лежат вперемешку текст «Янв» и числа, поэтому у него тип object. Так pandas помечает столбец, где лежит смесь текста и чисел и один тип выбрать не удалось; сложить такой столбец по-человечески не выйдет. Пропускаем шапку:

import pandas as pd
plan = pd.read_excel("zerno_finance.xlsx", sheet_name="План", skiprows=3)
print(plan.shape)
print(plan["Янв"].dtype)
plan[["Код", "Янв", "Фев", "Год"]]

Что здесь происходит:

  • sheet_name="План" — какой лист читать. Можно по имени или по номеру с нуля (sheet_name=1 — второй лист). По умолчанию 0 — первый лист, у нас это «Описание»: без этого параметра вместо таблицы получите пару строк текста.
  • skiprows=3 выбросил заголовок, подзаголовок и пустую строку; строка «Код, Кофейня, …» стала названиями столбцов. То же самое можно сказать через header=3: «названия столбцов — в строке с номером 3, если считать с нуля».
  • plan.shape — 8 строк: семь кофеен и «Итого». 16 столбцов: код, название, город, 12 месяцев и «Год».
  • Теперь в столбцах месяцев только числа и пропуски: Янв — float64. В Excel числа хранятся числами, поэтому decimal="," здесь не нужен — запятая в «1194,6» есть только на экране.
  • В последней строке видна «Итого». Пока она в таблице, любые суммы по столбцам неверны.
Предскажите вывод

Что выведет этот код? Сначала ответьте, потом запустите.

import io
import pandas as pd
text = "отчёт за неделю\nкод;сумма\nA;5\nB;7\nИтого;12"
df = pd.read_csv(io.StringIO(text), sep=";", skiprows=1)
print(df["сумма"].sum())
  • 12
  • [x] 24
  • Ошибка KeyError

Почему: skiprows=1 убрал только заголовок отчёта. Строка «Итого» для pandas — обычная строка данных, и sum сложил 5 + 7 + 12. io.StringIO здесь просто превращает строку в «файл», чтобы не создавать его на диске. С листом Excel было бы то же самое: skiprows одинаково работает в read_csv и read_excel.

Строка «Итого»: убрать и сверить

Итоговую строку убирают фильтром по первому столбцу. А раз уж она есть, ею удобно проверить себя: сумма по кофейням должна с ней совпасть.

import pandas as pd
plan = pd.read_excel("zerno_finance.xlsx", sheet_name="План", skiprows=3)
print("сумма с итогом:", plan["Янв"].sum())
body = plan[plan["Код"] != "Итого"]
total = plan.loc[plan["Код"] == "Итого", "Янв"].item()
print("по кофейням:", round(body["Янв"].sum(), 1), "| строка «Итого»:", total)

Что здесь происходит:

  • plan["Код"] != "Итого" — маска «все строки, кроме итоговой»; body — только кофейни.
  • .item() достаёт значение из Series с единственным элементом — получается обычное число.
  • round(..., 1) нужен, потому что сумма дробных чисел даёт хвосты вроде 5733.099999.

Что получилось: с «Итого» январь — 11 466.2 тыс. ₽, без неё — 5733.1, ровно как в итоговой строке. Совпадение — хороший знак: лист прочитан целиком, ни одна кофейня не потерялась при пропуске шапки.

Только нужные столбцы: usecols

На листе «Факт» шапка из четырёх строк (там ещё дата выгрузки), а справа — «Итого» и текстовый «Комментарий». Для сравнения с планом нужны код и месяцы. Их выбирают буквами, как при выделении в Excel:

import pandas as pd
fact = pd.read_excel("zerno_finance.xlsx", sheet_name="Факт", skiprows=4, usecols="A,D:L")
print(fact.columns.tolist())
fact.tail(3)

Что здесь происходит:

  • skiprows=4 — у «Факта» своя высота шапки, на строку больше, чем у «Плана».
  • usecols="A,D:L" — столбец A (код) и диапазон D–L (январь–сентябрь). Остальные столбцы даже не попадают в память.
  • Столбцы можно задать и списком имён: usecols=["Код", "Янв", "Фев"] — код и два месяца. Порядок столбцов в результате — как на листе, а не как в списке.
параметр что делает read_excel read_csv
sheet_name какой лист: имя, номер с нуля, список или None (все) есть нет: в CSV один лист
skiprows сколько строк пропустить сверху есть есть
header в какой строке названия столбцов (с нуля) есть есть
usecols какие столбцы взять имена, номера, буквы "A,D:L" имена, номера
nrows сколько строк данных прочитать есть есть
Потренироваться — задача:3 Сверка с итогом

Тот же лист в CSV

Таблицы из Excel часто приходят и CSV-файлами: учётная система выгружает их как «CSV (разделитель — точка с запятой)». У нас это finance_plan.csv и finance_fact.csv — те же листы «План» и «Факт». При таком сохранении шапка и «Итого» никуда не деваются, и параметры skiprows, header, usecols, nrows у read_csv те же. Добавляются два знакомых по кассе: sep=";" и decimal="," — в CSV числа уже записаны текстом, с русской запятой.

import pandas as pd
months = ["Янв", "Фев", "Мар", "Апр", "Май", "Июн", "Июл", "Авг", "Сен"]
xl = pd.read_excel("zerno_finance.xlsx", sheet_name="Факт", skiprows=4, usecols=["Код"] + months)
csv = pd.read_csv("finance_fact.csv", sep=";", decimal=",", skiprows=4, usecols=["Код"] + months)
print(csv["Янв"].dtype)
print("таблицы совпадают:", xl.equals(csv))

Что здесь происходит:

  • В read_csv буквы столбцов ("A,D:L") не работают — в CSV нет букв, только имена и номера. Поэтому столбцы выбраны списком имён.
  • xl.equals(csv) — True, если у таблиц одинаковые столбцы, типы и все значения. Из книги и из CSV получилось одно и то же.
Работаете в своём Jupyter?

Тот же read_excel работает и там, нужна только библиотека openpyxl — она уже есть в requirements.txt курса, а в своём проекте ставится командой uv add openpyxl. Все шаги этого раздела подряд, на этой же книге, собраны в блокноте ch03-excel.ipynb.

Разберём вместе: план против факта

Возьмём KZN-2 за январь–сентябрь. По плану — 7081.4 тыс. ₽ (сумма девяти месяцев из «Плана»), по факту — 6062.7 тыс. ₽ (то же из «Факта»).

  1. Выполнение плана: 6062.7 / 7081.4 × 100 ≈ 85.6 %.
  2. Отставание: 7081.4 − 6062.7 = 1018.7 тыс. ₽.
  3. В комментарии на листе «Факт» объяснение: в марте кофейня 12 дней была закрыта на ремонт.

Для всех кофеен сразу — тот же расчёт таблицами:

import pandas as pd
months = ["Янв", "Фев", "Мар", "Апр", "Май", "Июн", "Июл", "Авг", "Сен"]
plan = pd.read_excel("zerno_finance.xlsx", sheet_name="План", skiprows=3, usecols=["Код"] + months)
fact = pd.read_excel("zerno_finance.xlsx", sheet_name="Факт", skiprows=4, usecols=["Код"] + months)
p = plan[plan["Код"] != "Итого"].set_index("Код")[months].sum(axis=1)
f = fact[fact["Код"] != "Итого"].set_index("Код")[months].sum(axis=1)
print((f / p * 100).round(1))

Что здесь происходит:

  • set_index("Код") делает код кофейни индексом: так план и факт сопоставятся по коду, а не по номеру строки.
  • [months].sum(axis=1) — сумма по строке, то есть по девяти месяцам каждой кофейни (axis=1 — «вдоль строки»).
  • f / p делится по совпадающим кодам.

Как читать результат: KZN-2 выполнила план на 85.6 % — хуже всех; KZN-1 — на 104.8 %, лучше всех. У EKB-1 вместо числа NaN: план и факт за девять месяцев — по нулю (кофейня ещё не открыта), а 0 / 0 — не число. Это не ошибка расчёта, но в отчёт такую строку не включают: про неё отдельная фраза «открывается в октябре».

Проверьте себя

Лист «Факт» прочитали с skiprows=3 — как «План». Что получится?

  • [x] Заголовком станет пустая строка: столбцы назовутся Unnamed: 0, Unnamed: 1…, а «Код», «Кофейня» окажутся первой строкой данных

    У «Факта» шапка на строку длиннее: три строки текста и пустая. Высоту шапки смотрят на каждом листе отдельно.

  • [ ] pandas сам найдёт строку с названиями столбцов

    Не найдёт: он берёт заголовок ровно из той строки, на которую указали skiprows или header.

  • [ ] Ошибка: столбцов в шапке меньше, чем в данных

    Ошибки не будет — и это хуже: таблица прочитается, просто неправильно.

  • [ ] Ничего страшного: пропустится на строку меньше, и только

    Лишняя строка сверху как раз и становится заголовком, а столбцы месяцев получают тип object: в них вперемешку текст и числа.

Типичные ошибки
  • Одинаковый skiprows для всех листов. Высота шапки на листах бывает разной — у нас 3 и 4 строки. Симптом: столбцы Unnamed: 0, Unnamed: 1… Исправление — посмотреть на лист и задать свой skiprows каждому.
  • Забытая строка «Итого». Суммы удваиваются (11 466.2 вместо 5733.1), а среднее по кофейням включает «кофейню Итого». Исправление — df[df["Код"] != "Итого"] и сверка с итогом.
  • nrows вместо фильтра. nrows=7 отрежет «Итого», но когда в книге появится восьмая кофейня, она молча пропадёт. Фильтр по значению надёжнее, чем по номеру строки.
  • Первый лист по умолчанию. Без sheet_name читается первый лист — часто это титульный лист или описание.
  • Книга через read_csv. pd.read_csv("zerno_finance.xlsx") падает с UnicodeDecodeError: .xlsx — не текст, а упакованный архив. Книгу читают только read_excel.
  • CSV из старого Excel в другой кодировке. Та же UnicodeDecodeError, но файл точно .csv — значит, он сохранён в Windows-1251: pd.read_csv(..., encoding="cp1251").

Числа 3 и 4 для шапок вписывать нельзя — найдите их.

Что запомнить

  • Книга Excel: pd.read_excel("книга.xlsx", sheet_name="План", skiprows=3, usecols="A,D:L"); sheet_name=None — все листы словарём «имя → таблица». Работает и в браузере курса, и в Jupyter (там нужна библиотека openpyxl).

Data Science для аналитиков — как запустить курс
================================================

Курс работает в браузере, Python запускается прямо на странице.
Нужен свежий Chrome, Edge, Firefox или Safari. Интернет не нужен.

Сначала распакуйте архив целиком (не открывайте файлы прямо из архива).

WINDOWS
  Двойной клик по «Курс-Windows.bat».
  Если Windows покажет «Система Windows защитила ваш компьютер» —
  нажмите «Подробнее» → «Выполнить в любом случае».
  Если Python на компьютере нет, файл сам скачает переносной Python
  (около 11 МБ, один раз, в папку runtime — в систему ничего не ставится).

MAC
  Двойной клик по «Курс.command».
  Если macOS не даёт открыть файл («не удалось проверить разработчика»):
  Системные настройки → Конфиденциальность и безопасность → внизу
  «Всё равно открыть». Или в Терминале: bash Курс.command
  Python есть в macOS (при первом запуске система может предложить
  установить «инструменты командной строки» — согласитесь).

LINUX
  В терминале в папке курса: ./Курс-Linux.sh  (или bash Курс-Linux.sh)
  Нужен python3 — он есть почти во всех дистрибутивах.

После запуска откроется браузер с адресом http://127.0.0.1:8000/index.html.
Окно терминала (чёрное окно) не закрывайте, пока учитесь, — это и есть
локальный сервер курса. Закрыли окно — курс остановился.

Прогресс (решённые задачи, код, заметки) сохраняется в папке progress
рядом с курсом. Переносите её вместе с курсом, чтобы не потерять прогресс.

Двойной клик по index.html не подойдёт: без сервера Python в браузере
не запускается.
